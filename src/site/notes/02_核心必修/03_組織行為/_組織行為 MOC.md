# 👥 組織行為 MOC (Organizational Behavior)

> **課程定位**：國立臺灣大學 PMBA 核心必修核心模組  
> **授課教師**：臺大工商管理學系暨商學研究所 戚樹誠 教授  
> **研究核心**：以心理學、社會學與管理學為基石，穿透**個體（Individual）➔ 群體（Group）➔ 組織系統（Organization）**三層次之人性行為規律與領導治理能耐

## 🧭 組織行為三層次分析架構與決策脈絡圖

組織行為（OB）旨在協助高階經理人「**理解人性、預測行為、驅動賦能**」。本學期課程沿著**微觀個體到中觀群體與領導，並貫通至成果驗收**之路徑展開：

```mermaid
flowchart TD
    subgraph L1["第一階段：微觀個體心理與決策 (Module 1 · S01~S04)"]
        I1["導論、價值觀、倫理與性格<br>(M1-1 & M1-2: 大五人格 / MBTI / 黑暗三性格 / 跨文化)"]
        I2["情緒勞動、壓力與有限理性決策<br>(M1-3 & M1-4: AET / COR / 卡特賽車實證 / 認知偏誤)"]
        I1 --> I2
    end

    subgraph L2["第二階段：個體動能、知覺歸因與激勵 (Module 2 · L5~L8)"]
        M2["工作態度、社會知覺與激勵正義<br>(M2-1: 態度與實證研究 / M2-2: 暈輪與凱利歸因 / M2-3: DBF 激勵與組織正義)"]
    end

    subgraph L3["第三階段：中觀群體動力與領導 (Module 3 · S09~S11)"]
        G1["團隊發展、衝突管理與溝通<br>(Tuckman 五階段 / TKI 衝突矩陣 / 心理安全感)"]
        G2["領導理論、權力基礎與組織政治<br>(S09~S11: 權變領導 / 轉換型領導 / 法蘭奇五權力)"]
        G1 --> G2
    end

    subgraph L4["第四階段：成果驗收與綜合考核 (Evaluation · S12~S13)"]
        E1["團體報告與期末綜合考核<br>(S12~S13: 實務個案診斷發表與全學期理論驗收)"]
    end

    L1 --> L2 --> L3 --> L4
```
