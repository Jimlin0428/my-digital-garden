# 👥 組織行為 MOC (Organizational Behavior)

> **課程定位**：國立臺灣大學 PMBA 核心必修核心模組  
> **研究核心**：以心理學、社會學與管理學為基石，穿透**個體（Individual）➔ 群體（Group）➔ 組織系統（Organization）**三層次之人性行為規律與領導治理能耐

## 🧭 組織行為三層次分析架構與決策脈絡圖

組織行為（OB）旨在協助高階經理人「理解人性、預測行為、驅動賦能」。本學期課程沿著**微觀個體到中觀群體與領導，並貫通至成果驗收**之路徑展開：

```mermaid

    subgraph L1["第一階段：微觀個體動能 (Individual Dynamics · S01~S06)"]
        I1["導論、價值觀、倫理與性格<br>(S01~S02: 大五人格 / MBTI / 商業倫理)"]
        I2["情緒、壓力、態度與決策<br>(S03~S04: 認知失調 / 有限理性 / 捷思偏誤)"]
        I3["知覺歸因與工作激勵<br>(S05~S06: 凱利歸因 / 暈輪效應 / 雙因素 / 期望理論)"]
        I1 --> I2 --> I3
    end

    subgraph L2["第二階段：中觀群體動力與領導 (Group Dynamics & Leadership · S07~S11)"]

        G2 --> G4
        G4 --> G3
    end
```

## 📚 課程模組規劃與學習進度看板

### 模組一：微觀個體動能與心理機制 (Individual Dynamics · S01~S06)
- [ ] **S01_導論與價值觀 (10/04)**  
  *OB 本質、從古典機械觀到現代人本觀、跨文化背景下的人性假設、終極價值觀 vs. 工具價值觀。*
- [ ] **S02_倫理與性格 (10/04)**  
  *企業商業倫理決策、大五人格特質（Big Five）、MBTI 職業性格類型、控制信念（內外控）、個人-組織適配度（P-O Fit）。*
- [ ] **S03_性格、情緒與壓力 (10/24)**  
  *性格特質深化、情緒勞動（Emotional Labor）、情緒智商（EQ 五大構面）、工作倦怠預防、職場壓力源與心理韌性調適。*
- [ ] **S04_態度與決策 (10/24)**  
  *態度三要素（ABC 模型）、費斯汀格認知失調理論、工作滿意度與組織公民行為（OCB）、理性決策架構、有限理性與捷思偏差。*
- [ ] **S05_知覺與歸因 (11/07)**  
  *社會知覺選擇性、暈輪效應與刻板印象、凱利歸因模型（一致性/普遍性/特異性）、基本歸因謬誤與自利偏差校正。*
- [ ] **S06_激勵 (11/07)**  
  *內容型與過程型激勵體系：馬斯洛需求層次、赫茲伯格雙因素理論、佛洛姆期望理論、亞當斯公平理論、目標設定理論與工作特性模型（JCM）。*

### 模組二：中觀群體動力、團隊協作與領導 (Group Dynamics & Leadership · S07~S11)
- [ ] **S07_團隊 (11/21)**  
  *塔克曼（Tuckman）團隊發展五階段（形成/動盪/規範/表現/解散）、團隊多元角色搭配、防範社會惰化（Social Loafing）、高績效團隊心理安全感。*
- [ ] **S08_衝突與溝通 (11/21)**  
  *組織人際溝通障礙克服、積極傾聽與非暴力溝通、建設性衝突 vs. 破壞性衝突、Thomas-Kilmann 衝突處理模式（TKI 五大策略）、雙贏協商原則。*
- [ ] **S09_領導 (12/12)**  
  *領導特質論與行為論、費德勒權變模型、赫塞-布蘭查德情境領導（SLT）、交易型領導 vs. 轉換型領導（TL）、僕人式領導。*
- [ ] **S10_權力與政治 (12/12)**  
  *法蘭奇與雷文五大權力基礎（法定/獎賞/強制/專家/參照權力）、建設性組織政治、向上管理策略、跨部門非職權影響力建立。*
- [ ] **S11_領導與課程總結 (12/26)**  
  *當代領導力前沿實踐（教練型領導、賦能授權）、穿透個體到組織系統的三層次行為規律、全課程核心決策脈絡總結。*

### 模組三：成果驗收、實務個案與評量考核 (Evaluation & Case Studies · S12~S13)
- [ ] **S12_團體報告 (01/09)**  
  *各小組實務商業個案／組織診斷專案成果發表（第一階段）、同儕互評與教授講評反饋。*
- [ ] **S13_團體報告與期末考 (01/09)**  
  *各小組實務專案發表（第二階段）、組織行為學全學期理論精華與實務應用綜合期末考核。*

## 🧮 組織行為經典理論矩陣與經理人工具箱

| 分析層次 | 理論 / 模型名稱 | 代表學者 | 經理人管理意涵與分析工具箱 | 實務應用情境 |
| :--- | :--- | :--- | :--- | :--- |
| **個體層次** | **大五人格特質 (Big Five)** | 戈德堡等 | 開放性、嚴謹性、外向性、親和性、情緒穩定性。 | 人才招募甄選、適才適所崗位配置與團隊互補搭配。 |
|  | **歸因理論 (Attribution)** | 凱利 (Kelley) | 透過一致性（Consensus）、特異性（Distinctiveness）、一貫性（Consistency）判斷行為歸因於內因或外因。 | 部屬績效考核、錯誤歸因偏差校正與建設性績效面談。 |
|  | **工作特性模型 (JCM)** | 哈克曼 & 歐德罕 | 技能多樣性、任務完整性、任務重要性、自主性、回饋性。 | 工作豐富化設計（Job Enrichment）、提升員工內在成就動機。 |
| **群體層次** | **團隊發展五階段** | 塔克曼 (Tuckman) | 形成期 ➔ 動盪期 (衝突高發) ➔ 規範期 ➔ 表現期 ➔ 解散期。 | 敏捷專案團隊組建、穿越動盪期阻力與快速凝聚戰鬥力。 |
|  | **TKI 衝突處理矩陣** | 湯瑪斯 & 基爾曼 | 依「堅持度」與「合作度」劃分：競爭、合作、妥協、迴避、遷就。 | 跨部門專案利益衝突協商、供應鏈商務談判策略選擇。 |
|  | **權力五基礎** | 法蘭奇 & 雷文 | 職位權力（法定/獎勵/強制）vs. 個人權力（專家/參照權力）。 | 無實質職權時（如矩陣專案經理）建立個人權威與跨部門影響力。 |
|  | **轉換型領導 (TL)** | 伯恩斯 & 巴斯 | 願景魅力感召、智力啟發、個別化關懷、鼓舞性激勵。 | 企業遭遇危機逆境或重大轉型時，凝聚向心力與重塑文化。 |
| **組織層次** | **文化三層次模型** | 沙因 (Schein) | 1. 外顯表象 (Artifacts) ➔ 2. 宣稱價值觀 (Values) ➔ 3. 深層基本假設 (Assumptions)。 | 企業併購後的文化整合診斷、突破「口惠而實不至」的口號文化。 |
|  | **變革八步驟** | 柯特 (Kotter) | 創造急迫感 ➔ 建立領導聯盟 ➔ 確立願景 ➔ 溝通願景 ➔ 授權賦能 ➔ 創造短期成果 ➔ 鞏固戰果 ➔ 錨定文化。 | 企業數位轉型、全球化組織重組與全面品質變革推動。 |
