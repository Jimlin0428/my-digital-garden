## 🧮 財務管理核心估值公式與決策矩陣

| 決策範疇 | 核心模型 / 公式名稱 | 數學運算表達式 | 經理人管理意涵與判讀準則 |
| :--- | :--- | :--- | :--- |
| **價值評估** | **淨現值 (NPV)** | $\text{NPV} = \sum_{t=1}^n \frac{\text{CF}_t}{(1+r)^t} - \text{CF}_0$ | 投資決策黃金準則。$\text{NPV} > 0$ 代表為股東創造超額價值，應予接受。 |
|  | **內部報酬率 (IRR)** | $\sum_{t=1}^n \frac{\text{CF}_t}{(1+\text{IRR})^t} - \text{CF}_0 = 0$ | 專案實質報酬率。當 $\text{IRR} > \text{WACC}$ 時接受；但互斥專案需防範折現率假設陷阱。 |
|  | **等額年金法 (EAC)** | $\text{EAC} = \frac{\text{PV of Costs}}{\text{PVIFA}_{r, n}}$ | 用於評估壽命不對稱且需持續重置之機器設備，選擇 EAC 最低者。 |
| **資本成本** | **加權平均資金成本 (WACC)** | $w_d r_d (1 - T_c) + w_e r_e$ | 企業整體融資資本成本；亦為公司自由現金流（FCFF）折現之基準貼現率。 |
|  | **資本資產定價模型 (CAPM)** | $r_e = r_f + \beta_e (E(r_m) - r_f)$ | 衡量系統性風險 $\beta$ 下股東所要求的必要報酬率。 |
| **資本結構** | **MM 定理（有公司稅）** | $V_L = V_U + T_c D$ | 負債利息具有稅盾價值（Tax Shield），舉債能提升公司價值直至財務危機成本浮現。 |
|  | **EBIT-EPS 無異點** | $\frac{(\text{EBIT}^* - I_1)(1-T)}{\text{Shares}_1} = \frac{(\text{EBIT}^* - I_2)(1-T)}{\text{Shares}_2}$ | 決定發行股票或舉債融資的臨界獲利門檻；高於無異點舉債對 EPS 有利。 |
| **短期營運** | **放棄現金折扣成本** | $\frac{\text{折扣率}}{1 - \text{折扣率}} \times \frac{365}{\text{信用期} - \text{折扣期}}$ | 例如「2/10, net 30」之隱含年化資金成本高達 $37.24\%$，低於此成本應借款取現折扣。 |
| **風險避險** | **賣買權平價理論 (Put-Call Parity)** | $C + \frac{K}{(1+r)^T} = P + S_0$ | 建立無套利均衡關係；企業建構保護性賣權（Protective Put）避險之基礎。 |
