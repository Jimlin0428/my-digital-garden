# 公允價值 (Fair Value / IFRS 13 評價架構)

## 一、 核心概念與理論源流

### 1. 理論定義：市場參與者的有序脫手價格
**公允價值 (Fair Value)** 是當代全球國際財務報導準則 (IFRS) 與美國會計準則 (US GAAP) 中最根本的計量屬性，也是現代金融工程與資產負債表定價的核心語言。

國際財務報導準則第 13 號 (IFRS 13 Fair Value Measurement) 與美國 ASC 820 對公允價值確立了精確、統一且具法律約束力的權威定義：
> **「在衡量日，市場參與者 (Market Participants) 之間在當前市場條件下的有序交易 (Orderly Transaction) 中，出售一項資產所能收取、或移轉一項負債所必須支付的價格——即『脫手價格 (Exit Price)』。」**

這一定義確立了三大哲學前提：
1. **脫手價格導向 (Exit Price)**：公允價值衡量的是資產「賣出變現」的價格，而非企業當初購入該資產的「進場價格 (Entry Price / 歷史成本)」。
2. **市場參與者視角**：必須基於市場上理性、獨立、具備完整資訊且有意願交易的外部參與者假設，完全排除企業特定管理層的主觀偏好或內部協同綜效。
3. **有序交易假設**：排除被迫清算、強制拍賣、破產拋售或恐慌性擠兌等非正常交易情境。

### 2. 歷史成本 vs. 公允價值之世紀大辯論

```
+---------------------------------------------------------------------------------+
|                       歷史成本與公允價值的世紀哲學抉擇                          |
+---------------------------------------------------------------------------------+
  計量模式              核心優勢 (Pros)                     主要弊端與系統性風險 (Cons)
  =================================================================================
  歷史成本              * **高度客觀、可驗證 (Verifiable)** * **極度滯後，嚴重失真脫節**
  (Historical Cost)     * 基於過往真實發票與現金流憑證      * 在通膨或資產暴跌時，無法反映
  (傳統保守主義會計)    * 不易被人為估值模型主觀操縱        資產的真實當期清償能力
  ---------------------------------------------------------------------------------
  公允價值              * **即時反映市場動態 (Relevance)**  * **順週期性與波動劇烈 (Procyclical)**
  (Fair Value)          * 提供最具決策相關性的當期價值      * 當缺乏活躍市場時，估值模型容易
  (現代資產負債表觀)    * 消除隱藏的未實現巨額虧損          演變為人為操縱的「標至神話」
  =================================================================================
```

## 二、 IFRS 13 公允價值三大輸入值層級 (The Hierarchy)

為了規範評價品質並向資本市場揭示估值的不確定性，IFRS 13 確立了嚴格的 **三層公允價值輸入架構 (Fair Value Hierarchy)**：

```
+---------------------------------------------------------------------------------+
|                       IFRS 13 公允價值三大層級輸入架構                          |
+---------------------------------------------------------------------------------+
  [ 第一層級 (Level 1 Inputs) —— 最客觀透明 ]
  * 定義：在活躍市場中，相同資產或負債於衡量日未經調整的公開報價 (Quoted Prices)。
  * 代表標的：台積電在證交所的盤後收盤價、美國公債即時交易價格、倫敦金屬交易所黃金現貨。
  * 審計特徵：**直接取用，禁止任何模型調整！具備最高等級的客觀可靠性。**
       ▲
       | (流動性遞減、主觀模型介入)
  [ 第二層級 (Level 2 Inputs) —— 可直接或間接觀察 ]
  * 定義：除第一級報價外，該資產或負債可直接或間接觀察到的市場參數與數據。
  * 代表標的：
    - 類似資產在活躍市場的報價（如未上市台積電公司債參考同評級可比債券利差）。
    - 利率交換曲線 (SOFR Swap Curve)、隱含波動率、基差、外匯遠期換匯點。
  * 審計特徵：評價模型標準化，但參數可從公開終端機 (彭博 Bloomberg/路透) 交叉驗證。
       ▲
       | (市場流動性完全枯竭、管理層主觀假設)
  [ 第三層級 (Level 3 Inputs) —— 不可觀察之管理層估值模型 (Mark-to-Model) ]
  * 定義：市場上完全不存在可觀察參數，必須依託企業管理層自身的假設與計量估值模型。
  * 代表標的：未上市新創獨角獸股權估值、不良債權 (NPL)、複雜結構型衍生品、商譽減損之 DCF 評估。
  * 審計特徵：**主觀風險最高！極度仰賴折現率 (WACC) 與永續成長率 (g) 之設定，被稱為「標至神話」。**
```

## 三、 商戰歷史實戰：2008 次貸危機「標至神話」vs. 2023 矽谷銀行 (SVB) 倒閉

### 1. 2008 年華爾街次貸海嘯：從「Mark-to-Market」墮落為「Mark-to-Myth」
在 2007 年次級房貸違約爆發前，華爾街投行（雷曼兄弟、貝爾斯登、美林）資產負債表上充斥著數千億美元的抵押擔保證券 (CDO) 與結構化資產。
- **第二級向第三級的逃逸**：當房市次貸暴雷、二級市場流動性徹底凍結時，這些 CDO 失去了第一級和第二級市場報價。各大投行拒絕按恐慌拋售的折價計提公允價值損失，而是集體將其歸類為 **「第三層級 (Level 3)」資產**。
- **標至神話 (Mark-to-Myth)**：投行 quant 團隊利用專有的黑箱數學模型，人為輸入樂觀的違約率與超低折現率，在電腦螢幕上虛構出這些毒資產「依然價值 95 美分」的假象。然而當資本市場要求強制提現驗證時，神話破滅引發全面清盤，引爆大蕭條以來最嚴重的全球金融海嘯。

### 2. 矽谷銀行 (SVB, 2023)：持有至到期 (HTM) 與公允價值的致命錯配
2023 年 3 月矽谷銀行 (Silicon Valley Bank) 在 48 小時內被擠兌破產，其會計根源正是巧妙利用了會計分類規避公允價值：
- **會計掩耳盜鈴**：在聯準會激進升息前，SVB 將上千億美元吸收的零成本存款，大量買入了 10 年期以上、平均殖利率僅 1.6% 的美國長期國債與房貸抵押債券 (MBS)。
- **藏入 HTM 表外黑箱**：SVB 沒有將其劃入「透過其他綜合損益按公允價值衡量 (FVOCI)」類別，而是全額劃入 **「持有至到期 (Held-to-Maturity, HTM)」**。依據會計準則，HTM 資產按歷史攤銷成本計量，**其因升息導致的數百億美元公允價值浮虧，完全不需在資產負債表與損益表上顯現！**
- **致命代價**：當創投新創擠兌提領現金時，SVB 被迫在市場上緊急拋售這批國債變現，導致這筆「未實現公允價值虧損」瞬間被動轉化為「18 億美元的實質已實現虧損」，一舉擊穿股東權益，引發歷史性擠兌猝死。

## 四、 估值方法三大流派與 IFRS 13 規範之對照

在進行第二級與第三級公允價值計量時，資產評估師通常採用三大經典評價技術：

| 估值技術流派 | 核心評價模型與邏輯 | 最適用之資產類別 | 關鍵參數與潛在陷阱 |
| :--- | :--- | :--- | :--- |
| **市場法 (Market Approach)** | 參考可比上市公司或可比併購交易的估值乘數（P/E, P/B, EV/EBITDA）。 | 流動性尚可的未上市企業少數股權、標準廠房與土地房產。 | 需進行流動性折價 (DLOM) 與控制權溢價調整；可比對象選擇易具主觀偏誤。 |
| **收益法 (Income Approach)** | 將未來預期現金流或利潤，以特定折現率折現為當期現值 (DCF / 股利折現模型)。 | 專利權、特許經營權、複雜債券、[[goodwill_商譽|商譽減損測試]]。 | 對折現率 ($WACC$) 與末期永續增長率 ($g$) 極度敏感；參數變動 1% 估值可能巨震 30%。 |
| **成本法 (Cost Approach)** | 計算當前重新購建或重置具有相同服務能力資產所需的成本，扣除各項折舊損耗。 | 特殊專用機械設備、自建客製化 IT 系統、公共基礎設施。 | 難以衡量資產在商業上的真實獲利能力；容易高估已過時但成本昂貴的設備。 |

## 五、 經理人決策檢核清單 (Executive Checklist)

- [ ] **Level 3 資產佔比安全性預警**：公司持有的金融資產與非流動資產中，歸類為「第三層級 (Level 3)」的比例是否超過總資產的 15%？若是，是否備妥了詳盡的敏感度分析表格以應對證監機構問詢？
- [ ] **公允價值變動對損益表衝擊排查**：列入「透過損益按公允價值衡量 (FVTPL)」的交易性金融資產，在面臨極端黑天鵝市場崩盤時，單季未實現跌價損失是否會直接導致公司財報轉盈為虧？
- [ ] **評價模型的獨立性與利益衝突隔離**：重大非上市股權或無形資產的公允價值評估，是否委託了具備證照的外部獨立第三方會計師事務所或鑑價機構，而非由內部業務部門閉門造車？
- [ ] **債券 HTM 與 AFS 分類的流動性壓力測試**：公司投資組合中的長天期固定收益資產，是否進行了利率驟升 200~300 個基點時的「隱性公允價值浮虧」測算？若遭遇突發流動性擠兌，被迫平倉時是否會打穿資本淨值？
- [ ] **交易對手信用風險調整 (CVA/DVA)**：在評價場外雙邊金融衍生品（如利率交換、貨幣交換）的公允價值時，是否已依照 IFRS 13 規定，將交易對手及本公司自身的違約信用風險 (Credit Valuation Adjustment) 扣除？
