# 水平併購 (Horizontal Mergers & Acquisitions & Market Power Dynamics)

> **【核心決策摘要】**
> **水平併購（Horizontal M&A）** 是指**生產相同或高度替代性產品、在同一目標市場中處於直接競爭關係的兩家企業之間的合併或收購**。水平併購的戰略核心在於**直接消滅市場競爭者、迅速擴大市場份額、實現製造與採購的[[98_商業概念庫/economies-of-scale_規模經濟\|規模經濟（Economies of Scale）]]並提升定價權（Pricing Power）**。然而，水平併購是各國反壟斷監管機關監控最嚴格的交易型態，主管機關普遍採用**赫芬達爾-赫希曼指數（HHI）** 評估市場集中度躍升幅度，對可能導致單方定價壟斷或寡占默契勾結的交易施加嚴厲反對或強制資產剝離（Divestiture）。

---

## 1. 概念核心定義與戰略動機 (Executive Definition & Strategic Drivers)

### 1.1 核心定義
在產業組織學中，水平併購定義為：**處於產業水平橫向維度上直接競逐相同客戶群的同業競爭者，透過法定合併（Merger）或控股收購（Acquisition），整合成單一所有權實體之戰略行為**。

### 1.2 三大核心戰略動機
1. **極速擴張市場份額與定價權（Pricing Power）**：
   在成熟期或存量博弈市場，有機成長（Organic Growth）獲客成本極高。水平併購能在一夜之間將競爭對手的市佔率與忠實客戶整併入自身版圖，大幅弱化買方的議價空間。
2. **獲取規模經濟與範疇經濟（Economies of Scale & Scope）**：
   - 裁撤重複的企業總部行政、法務、人資與財務編制。
   - 合併採購量向上游供應商爭取最頂級的批量折扣（Volume Discounts）。
   - 整合重疊的物流車隊與倉儲網路，推升產能利用率逼近最小效率規模（MES）。
3. **化解破壞性價格戰（Price War Containment）**：
   消滅市場上最具攻擊性的低價擾局者，促成寡占市場的穩定定價格局，改善全產業的投入資本報酬率（[[ROIC_投入資本報酬率 Return on Invested Capital|ROIC]]）。

## 2. 反壟斷監管核心工具：HHI 指數與審查準則 (Antitrust & HHI Framework)

各國反壟斷機構（如美國司法部 DOJ / 聯邦貿易委員會 FTC）在審查水平併購時，均以**赫芬達爾-赫希曼指數（Herfindahl-Hirschman Index, HHI）** 作為判定市場集中度與阻卻競爭的核心量化指標。

### 2.1 HHI 計算公式
$$HHI = \sum_{i=1}^N (s_i)^2$$
其中 $s_i$ 為市場中第 $i$ 家企業的**百分比市場份額（Market Share %）**（例如 20% 記為 20，$20^2 = 400$）。HHI 的取值範圍為 $0$ 至 $10,000$。

### 2.2 水平併購引發的 HHI 增量計算
當市場份額分別為 $s_1$ 與 $s_2$ 的兩家企業合併時，HHI 的淨增加量（$\Delta HHI$）為：
$$\Delta HHI = (s_1 + s_2)^2 - (s_1^2 + s_2^2) = 2 s_1 s_2$$

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                 美國 DOJ / FTC 水平併購審查基準矩陣                         │
├─────────────────────┬───────────────────────────┬───────────────────────────┤
│ 併購後市場集中度區間│ HHI 淨增量 ($\Delta HHI$) │ 反壟斷監管態度與處置方針  │
├─────────────────────┼───────────────────────────┼───────────────────────────┤
│ **低度集中市場**    │ 任意增量                  │ **直接放行**。            │
│ ($HHI < 1,500$)     │                           │ 視為不具顯著反競爭效果。  │
├─────────────────────┼───────────────────────────┼───────────────────────────┤
│ **中度集中市場**    │ $\Delta HHI < 100$        │ 通常放行。                │
│ ($1,500 \le HHI \le 2,500$)│ $\Delta HHI \ge 100$   │ **引發審查關注**，可能要求補充證據。│
├─────────────────────┼───────────────────────────┼───────────────────────────┤
│ **高度集中市場**    │ $\Delta HHI < 100$        │ 輕度關注。                │
│ ($HHI > 2,500$)     │ $100 \le \Delta HHI \le 200$│ **高度疑慮**，需提出強大抗辯證據。│
│                     │ $\Delta HHI > 200$        │ **推定具反競爭性（Presumed Anticompetitive）**，極大機率提起訴訟阻擋或要求重大資產拆售。│
└─────────────────────┴───────────────────────────┴───────────────────────────┘
```

> **PMBA 試算範例**：
> 假設某產業原本由四家企業瓜分：30%、25%、25%、20%。
> 初始 $HHI = 30^2 + 25^2 + 25^2 + 20^2 = 900 + 625 + 625 + 400 = 2,550$（已屬高集中市場）。
> 若前兩大（30% 與 25%）擬進行水平合併：
> $\Delta HHI = 2 \times 30 \times 25 = 1,500$！合併後 $HHI = 4,050$。
> 該交易遠遠突破 $\Delta HHI > 200$ 的紅線，監管機關將依法推定該併購將造成價格壟斷，必遭全面封殺。

## 3. 水平併購的實踐挑戰與整合陷阱 (Challenges & Pitfalls)

1. **同質文化互斥與內部派系內耗**：
   水平併購的兩家公司在市場上往往廝殺數十年，雙方員工抱持深厚敵意。整合過程中，高層職位重疊嚴重，「誰當總經理、誰被裁撤」的權力鬥爭往往癱瘓日常業務。
2. **客戶多元化分流流失（Customer Churn）**：
   企業級（B2B）大客戶普遍奉行「雙供應商政策（Dual-Sourcing Policy）」以維持議價優勢。當其兩大主力供應商宣布合併時，客戶往往為了分散斷供風險，主動將訂單切分轉移給市場第三、第四名廠商。
3. **過度承諾綜效與商譽巨額減損**：
   買方為贏得董事會支持，往往高估關廠與裁員帶來的成本節省金額，並支付了過高的[[acquisition-premium_收購溢價|收購溢價]]。一旦整合成效不如預期，將被迫提列巨額商譽減損（Goodwill Impairment），重創財務報表。
