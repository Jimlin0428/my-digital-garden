# 損益平衡分析 (Break-Even Analysis)

## 📌 概念核心定義

**損益平衡分析 (Break-Even Analysis)**，在管理會計中亦通稱為**成本-數量-利潤分析 (Cost-Volume-Profit Analysis, CVP 分析)**，指管理當局透過拆解企業成本結構中的**固定成本 (Fixed Costs)** 與**變動成本 (Variable Costs)**，深入研究銷售量、產品售價、單位成本與利潤之間相互依存關係的一套系統性決策工具。

損益平衡分析不僅僅是計算「賣多少才能打平保本」，更是企業高階經營團隊進行新產品定價、產能投資規劃、自製或外包 (Make-or-Buy) 決策、以及因應總體經濟下行進行壓力測試 (Stress Testing) 的根本量化基礎。

---

## 🔬 理論架構與數理模型

### 1. 核心假設條件與限制

經典 CVP 損益平衡分析建立在以下四大管理假設之上：
1. **成本性態可分割性**：企業所有成本皆可明確歸類為純固定成本或與業務量成正比的純變動成本。
2. **線性關係假設**：在相關範圍 (Relevant Range) 內，單位售價 ($P$) 與單位變動成本 ($V$) 保持常數，總營收與總變動成本呈線性增長。
3. **產銷平衡假設**：當期生產量等於銷售量，期初與期末存貨無重大變動，排除固定製造費用遞延於存貨之影響。
4. **銷售組合穩定性**：多產品企業中，各產品之間的營收佔比結構 (Sales Mix) 保持固定。

### 2. 目標利潤分析模型 (Target Profit Analysis)

企業經營通常追求具體利潤目標，而非僅僅滿足於保本：

#### (1) 稅前目標營業利益 ($Target\ EBIT$)
達成預期稅前利益所需的目標銷售量 ($Q_T$) 與目標銷售額 ($S_T$)：

$$Q_T = \frac{F + \text{Target EBIT}}{P - V} = \frac{F + \text{Target EBIT}}{CM}$$

$$S_T = \frac{F + \text{Target EBIT}}{CMR}$$

#### (2) 稅後目標淨利 ($Target\ Net\ Income$)
考量公司所得稅率 ($t$) 時，稅後淨利必須先還原為稅前營業利益：

$$Q_T = \frac{F + \frac{\text{Target Net Income}}{1 - t}}{P - V}$$

### 3. 敏感度分析與營運彈性 (Sensitivity & Scenario Analysis)

當市場環境突變時，經理人需快速評估各變數對損益平衡點 ($BEP$) 的彈性係數：

$$\text{Sensitivity of BEP to Price (P)} = \frac{\partial Q_{BEP}}{\partial P} = -\frac{F}{(P - V)^2} < 0$$

$$\text{Sensitivity of BEP to Fixed Cost (F)} = \frac{\partial Q_{BEP}}{\partial F} = \frac{1}{P - V} > 0$$

- **售價 ($P$) 提高**：邊際貢獻擴大，BEP 呈非線性劇烈左移（保本難度大幅下降）；
- **固定成本 ($F$) 增加**：BEP 呈線性右移，推高保本門檻。

## 📊 決策應用矩陣：自製 vs. 外包之跨期成本轉折

損益平衡分析常被用於決定企業是否該「自購設備自行生產」或「全數委外代工 (Outsourcing)」：

```
總成本 ($)
   ▲                                              方案 A (自建產線): 高固定/低變動
   │                                           ／
   │                                        ／    方案 B (委外代工): 零固定/高變動
   │                                     ／    ／
   │                       【成本無差異點 Q*】
   │                             ╱ ＼ ／
   │                          ／   ／ ＼
   │                       ／  ／
固定成本 (F_A) ────┼─────／
   │             ／
   └────────┴─────────────────────────────────────► 產銷量 (Q)
           Q* (Indifference Point)
```

| 決策情境 | 低於成本無差異點 ($Q < Q^*$) | 高於成本無差異點 ($Q > Q^*$) |
| :--- | :--- | :--- |
| **最佳決策選擇** | **選擇方案 B：外包代工** | **選擇方案 A：自建產線** |
| **決策邏輯** | 產量不足以攤提龐大的自建產線固定折舊，外包可消除固定成本曝險。 | 產量規模足夠龐大，低單位變動成本優勢將完全超越固定折舊負擔。 |

## 🏢 企業實戰案例：Adobe 轉向雲端訂閱制 (SaaS) 的 CVP 質變

### 1. 商業轉型背景與痛點
2012 年前，Adobe 採取傳統套裝軟體買斷制（如 Photoshop CS 一套售價高達 600~1,000 美元）。其 CVP 特性為：單價極高，每隔 18~24 個月推出新版本，研發與行銷固定成本極高，新版上市當季營收暴增，隨後迅速萎縮。若新版市場反響平平，銷量跌破損益平衡點，將造成當期重大虧損。

### 2. 訂閱制轉型帶來的 CVP 根本性重構
2013 年，Adobe 毅然宣布停止發行傳統套裝，全面轉向 Creative Cloud 訂閱制（每月 30~50 美元）：
1. **初期痛苦期（J-Curve 效應）**：轉型初期，高單價買斷現金流消失，每月微薄的訂閱費無法立即覆蓋固定成本，導致 2013-2014 年營業利潤率劇降至歷史低點。
2. **平滑固定成本與超高終身價值 (LTV)**：隨著百萬用戶持續累積，年經常性營收 (ARR) 成為高度可預測的「基底流量」。
3. **邊際貢獻率趨近 100%**：雲端軟體每增加一個訂閱用戶，新增的變動伺服器成本幾乎為零。
4. **成果**：Adobe 徹底跨越了傳統軟體的週期性損益平衡陷阱，毛利率維持在 88%~90%，營業利益率突破 35%，市值暴增十倍。

## ⚠️ 經理人常見盲點與治理陷阱

1. **盲信「線性假設」忽略產能極限瓶頸**：在現實中，當銷售量接近產能上限時，加班費、機台磨損與委外急單會使單位變動成本急劇飆升，打破線性假設，使利潤不增反減。
2. **將「沉沒成本 (Sunk Costs)」誤計入決策固定成本**：在評估是否承接特殊低價訂單時，已發生的舊廠房折舊屬於無關沉沒成本，只要訂單售價大於「增額變動成本 (Incremental Variable Cost)」，該訂單即可產生正向邊際貢獻。
3. **忽視多產品線「銷貨組合 (Sales Mix) 劣化」危機**：總銷售量雖然超越原本預測的 BEP，但業務團隊全靠促銷低利潤的毛三到四低階款衝量，導致公司「銷量創新高，利潤卻大幅虧損」。

## 🎯 高階經理人決策檢核清單

- [ ] 公司的各項成本是否已按現代作業基礎成本制 (ABC) 精準分離為固定與變動成本？
- [ ] 本年度預計達成的目標淨利，需要全公司達到多少銷售額才能覆蓋稅務與固定負擔？
- [ ] 當遭遇供應鏈原物料上漲 10% 或終端價格戰降價 5% 時，公司的損益平衡銷售額將推高幾成？
- [ ] 公司的自製或外包決策，是否經過產銷量無差異點 ($Q^*$) 的嚴謹量化測算？
- [ ] 業務團隊的佣金考核制度，是以「合約總金額 (Revenue)」還是「邊際貢獻總額 (Contribution Margin)」為激勵基準？
