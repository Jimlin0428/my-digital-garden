# 現金比率 (Cash Ratio & Ultimate Liquidity Defense)

> **【核心決策摘要】**
> **現金比率（Cash Ratio）** 是公司流動性分析中**最保守、最嚴苛的極限償債能力指標**。現金比率以**企業帳面上的現金及約當現金（加上短期高流動性有價證券）為分子，除以流動負債（Current Liabilities）**。相較於流動比率（包含變現緩慢的存貨）與速動比率（包含仍具違約風險的應收帳款），現金比率假設**存貨完全無法賣出、應收帳款一毛錢也收不回來的極端危機情境**，檢驗企業僅憑口袋裡的真金白銀能立刻償還多少比例的到期負債。一般成熟企業現金比率維持在 **20% 至 30%** 即可視為具備足夠的極限安全墊。

---

## 1. 核心公式與三大流動性比率嚴苛度對照 (Formula & Comparison)

$$\text{Cash Ratio} = \frac{\text{現金及約當現金} + \text{流動性金融資產 (Marketable Securities)}}{\text{流動負債 (Current Liabilities)}} \times 100\%$$

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                 三大流動性指標嚴苛度梯隊對照表                              │
├──────────────┬──────────────────────────────────────────┬───────────────────┤
│ 指標名稱     │ 包含之分子資產範疇                       │ 實務適用情境      │
├──────────────┼──────────────────────────────────────────┼───────────────────┤
│ **流動比率** │ 現金 + 短期投資 + 應收帳款 + 存貨 + 預付 │ 正常營運常態檢驗  │
│ (Current)    │ (範圍最寬鬆，包含最難變現的存貨)         │ (基準 > 1.5~2.0)  │
├──────────────┼──────────────────────────────────────────┼───────────────────┤
│ **速動比率** │ 現金 + 短期投資 + 應收帳款               │ 剔除存貨變現風險  │
│ (Quick)      │ (剔除存貨與預付費用，聚焦速動資產)       │ (基準 > 1.0)      │
├──────────────┼──────────────────────────────────────────┼───────────────────┤
│ **現金比率** │ **純現金及約當現金 + 高流動性國債金融資產**│ **極端危機抗壓測試**│
│ (Cash Ratio) │ (最嚴苛，假設客戶全部倒閉不還錢的極端情境)│ (基準 > 0.2~0.3)  │
└──────────────┴──────────────────────────────────────────┴───────────────────┘
```
