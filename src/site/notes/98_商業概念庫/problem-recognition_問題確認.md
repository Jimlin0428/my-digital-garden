# 問題確認 (Problem Recognition / Need Recognition)

## 一、 核心概念與理論源流

### 1. 理論奠基：消費者購買決策歷程的啟動樞紐
**問題確認 (Problem Recognition / Need Recognition)** 是經典消費者行為學與行銷科學中五階段決策歷程（EKB 模型 / 霍華德-謝思模型）的第一步與總發動機。

在菲利普·科特勒 (Philip Kotler) 與恩格爾 (James F. Engel) 的理論架構中，問題確認被嚴格定義為：
> **「消費者感知到其自身的『實際狀態 (Actual State)』與所渴望的『理想狀態 (Desired State)』之間存在足夠顯著的落差，進而產生內在心理張力 (Tension) 與動機匱乏感，驅使個體啟動後續[[98_商業概念庫/information_資訊搜尋\|資訊搜尋]]與決策行為的認知觸發點。」**

購買行為的本質並非消費商品本身，而是消費者試圖消除現實與理想之間落差的「解題行動」。

---

### 2. 需求落差與喚起閾值數理拓撲

```
+---------------------------------------------------------------------------------+
|                         問題確認之狀態落差與閾值喚起模型                        |
+---------------------------------------------------------------------------------+
  心理狀態維度
       ^
       |   【理想狀態 (Desired State)】
       |   * 渴望擁有的健康、社會地位、效率、美感或生活型態
       |   =======================================================
       |      ▲                                               ▲
       |      |                                               |
       |      | 狀態感知落差 (Perceived Gap, Delta S)          |
       |      |                                               |
       |      v                                               v
       |   ------------------------------------------------------- < 喚起閾值線 (Threshold Theta)
       |   * 當感知落差 Delta S > Theta 時，問題確認被正式觸發，啟動購買動機！
       |   =======================================================
       |   【現實狀態 (Actual State)】
       |   * 當前的生理需求、設備折舊損壞、庫存耗盡或時間短缺
       v
```

數學形式化表達為：
$$\text{Perceived Need Gap} = |S_{\text{desired}}(t) - S_{\text{actual}}(t)| > \theta_{\text{threshold}}$$
- 若落差小於喚起閾值 ($\Delta S \le \theta$)，消費者會選擇容忍或忽略該狀態，決策歷程終止於萌芽期。
- 企業行銷與產品創新的戰略本質，即在於透過干預 $S_{\text{desired}}$（拉高理想預期）或凸顯 $S_{\text{actual}}$（揭露潛在現實危機），打破平衡使 $\Delta S > \theta$。

## 二、 雙重刺激來源與問題分類矩陣

### 1. 內生刺激 vs. 外生刺激
驅動狀態轉移的觸發機制分為兩大維度：
1. **內部刺激 (Internal Stimuli)**：源於個體內部的生理或心理驅力。
   - 生理失衡：飢餓、口渴、疾病疼痛、日常消耗品（如咖啡豆、衛生紙）庫存告罄。
   - 心理變化：對當前穿搭的厭倦、自我實現慾望、生活階段躍遷（如大學畢業、結婚生子）。
2. **外部刺激 (External Stimuli)**：源於外部商業環境與社會互動的觸發。
   - 行銷刺激：廣告看見新款旗艦手機的影像畫質、社群媒體網紅推薦、店面香氣與櫥窗展示。
   - 社會刺激：看見同事升遷購買進口名車引發的「同儕攀比壓力 (Peer Pressure)」、法規強制更新（如安全法規更迭）。

### 2. 主動型問題 vs. 被動型問題矩陣

```
+---------------------------------------------------------------------------------+
|                       主動型 vs. 被動型問題與策略應對                           |
+---------------------------------------------------------------------------------+
  問題類型          消費者當前認知狀態                    行銷經理人最適策略路徑
  =================================================================================
  主動型問題        消費者在日常生活中已經清楚意識到      * **無需教育問題本身**
  (Active Problem)  該痛點存在 (如：iPhone 螢幕破裂)      * 聚焦於證明本品牌為「最佳解方」
                                                          * 爭奪[[plan-evaluation_方案評估|考量集 (Consideration Set)]]首位
  ---------------------------------------------------------------------------------
  被動型問題        問題客觀存在，但消費者目前**毫無意識** * **必須首先喚醒問題意識 (Problem Awakening)**
  (Inactive Problem)或認為不重要 (如：網路勒索軟體威脅)   * 進行市場教育，拉大現實與理想差距
                                                          * 創造出新需求品類，定義遊戲規則
  =================================================================================
```

## 三、 商戰歷史實戰：蘋果 iPad 創造被動需求 vs. 李施德霖發明「口臭病」

### 1. 史蒂夫·賈伯斯 (Steve Jobs)：將「被動型未知需求」轉化為百億美元品類
2010 年蘋果發布初代 iPad 之前，市場普遍質疑：「智慧型手機螢幕已經越來越大，筆記型電腦已經足夠輕薄，誰會需要第三種平板設備？」
- **洞察潛在落差**：賈伯斯坐在沙發上親自展示：在瀏覽全版網頁、閱讀電子雜誌、隨意翻看家庭相簿與輕鬆觀賞影片時，智慧型手機螢幕太小令人疲勞，筆記型電腦過於笨重且鍵盤阻礙了親密感。
- **創造理想狀態**：賈伯斯精準定義了一種全新的休閒生活型態（沙發與床頭的流暢沉浸體驗），使全球數億消費者瞬間意識到：「原來我現有的設備組合存在如此巨大的體驗痛點！」iPad 在發售首年便狂賣 1500 萬台，憑空創造出一個巨型消費電子帝國。

### 2. 李施德霖 (Listerine)：將外科消毒劑包裝為社交救命稻草
在 1920 年代以前，李施德霖主要作為外科手術消毒水與地板清潔劑販售，銷量平平。
- **重新定義問題確認**：傑拉德·蘭伯特 (Gerard Lambert) 翻閱醫學辭典，找到了一個冷僻拉丁名詞「慢性口臭 (Halitosis)」。
- **製造恐懼與社交焦慮**：李施德霖發起了一場歷史性的廣告戰役，刊登經典海報：「即使是你最好的朋友，也不會當面告訴你有口臭！——難道這就是你始終無法步入婚姻禮堂的原因？」這將一個原本無人關注的生理現象，瞬間包裝為足以毀滅社交與愛情生涯的重大隱形危機。李施德霖的年利潤在短短 7 年內由 11 萬美元暴增至 400 萬美元以上。

## 四、 問題確認在 B2B 組織採購與 B2C 消費場景之對照

| 比較維度 | B2C 個人消費問題確認 | B2B 企業採購問題確認 |
| :--- | :--- | :--- |
| **觸發起點** | 生理衝動、情感慾望、生活型態追求、廣告刺激。 | 產能瓶頸、設備故障停工、原物料短缺、合規法規更迭。 |
| **理性與情緒佔比** | 高度受衝動、情緒投射與社會同儕認同影響。 | 極度理性；受限於明確的成本效益 (ROI) 與規格書約束。 |
| **發起者角色** | 通常為消費者個人或家庭單一成員。 | 由生產工程師、倉管專員或採購部門正式提出需求請購單。 |
| **問題複雜度** | 相對單一，決策週期可能僅需數秒至數天。 | 涉及跨部門利益相關者，可能需耗時數月進行可行性論證。 |

## 五、 經理人決策檢核清單 (Executive Checklist)

- [ ] **問題屬性精確診斷**：我們的新產品所解決的痛點，在顧客心智中屬於「主動型問題」還是「被動型問題」？我們的行銷預算是否浪費在向不需要教育的客群重複解說痛點？
- [ ] **痛點緊迫感量化評估**：顧客當前的現實狀態 ($S_{\text{actual}}$) 與理想狀態 ($S_{\text{desired}}$) 差距，是否足以打破其維持現狀的慣性閾值 ($\theta_{\text{threshold}}$)？
- [ ] **行銷刺激觸發點埋設**：在目標客戶日常最容易產生匱乏感的情境場域（如通勤時、深夜失眠時、季度財務結算時），我們是否精準佈署了高轉化的外部刺激觸點？
- [ ] **恐懼訴求 (Fear Appeal) 的道德邊界**：若使用焦慮或恐懼喚起問題意識，是否給予了具體、可立即執行、且合乎倫理的解決路徑，而非引發顧客心理防衛性關閉？
- [ ] **第一階段與後續階段鏈接**：當顧客被成功喚起問題意識後，我們能否在 3 秒內為其提供無縫切換至[[information_資訊搜尋|資訊搜尋]]與解答的便捷通道（如一鍵搜尋、線上客服或試用登入）？
