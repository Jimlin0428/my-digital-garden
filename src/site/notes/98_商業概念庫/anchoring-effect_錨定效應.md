# 錨定效應 (Anchoring Effect)

## 一、 核心概念與理論源流

### 1. 理論奠基：啟發式與認知偏差
**錨定效應 (Anchoring Effect)**，又稱**錨定與調整啟發式 (Anchoring and Adjustment Heuristic)**，由行為經濟學奠基人阿莫斯·特沃斯基 (Amos Tversky) 與丹尼爾·康納曼 (Daniel Kahneman) 於 1974 年在《科學》（*Science*）期刊發表的經典論文《不確定狀況下的判斷：啟發式與偏差》（*Judgment under Uncertainty: Heuristics and Biases*）中首次提出。

該理論指出：人類在對未知數值進行估計與判斷時，往往會不自覺地過度依賴**最先接收到的初始資訊（即「錨點 Anchor」）**。決策者隨後雖然會基於更多事實進行調整，但這種心理調整通常是**不充分的 (Insufficient Adjustment)**，使得最終的估計值或決策結論產生系統性地偏向最初錨點的現象。

特沃斯基與康納曼在其經典實驗中，讓受試者旋轉一個刻意設計為只會停在 10 或 65 的幸運輪盤，隨後詢問受試者「非洲國家在聯合國所佔的比例是多少？」。結果顯示：
- 看到輪盤數字為 10 的組別，預估中位數僅為 **25%**；
- 看到輪盤數字為 65 的組別，預估中位數高達 **45%**。
這項研究震撼了學術界，證明了即使錨點數字**完全隨機且與決策標的毫無因果關係**，大腦仍會不由自主地被其牽引。

```
【錨定效應心智歷程】
初始刺激 (隨機數字 / 報價 / 歷史指標) ──> 設定認知錨點 (Anchor)
                                                │
                                                ▼
                                    啟動心理調整 (Adjustment)
                                                │
                                      [調整不足 Insufficient]
                                                ▼
                                    最終判斷偏向初始錨點
```

## 二、 決策架構與數理機制

### 1. 錨定指數 (Anchoring Index, AI) 衡量模型
在量化決策心理學中，學者格林與卡尼曼 (Green et al., 1998) 提出了**錨定指數 (Anchoring Index, AI)** 用以衡量錨點對最終判斷的扭曲程度：

設實驗或商務談判中設定了高低兩個錨點 $A_{\text{high}}$ 與 $A_{\text{low}}$，受測群體給出的估計值中位數分別為 $E_{\text{high}}$ 與 $E_{\text{low}}$：

$$
\text{Anchoring Index (AI)} = \frac{E_{\text{high}} - E_{\text{low}}}{A_{\text{high}} - A_{\text{low}}}
$$

- 若 $\text{AI} = 0$，表示決策者完全理性客觀，未受初始錨點任何影響。
- 若 $\text{AI} = 1$，表示決策者的判斷完全被錨點百分之百拉動。
- 在大量的房地產估價、二手車拍賣與企業併購實證研究中，專業估價師與資深高階經理人的 $\text{AI}$ 通常仍高達 **0.30 至 0.50**，顯示專業經驗並不能完全免疫錨定效應。

### 2. 商業情境中的常見錨點形態對照

| 應用場景 | 錨點機制 (Anchor) | 受影響之決策行為 | 企業實例 / 行為結果 |
| :--- | :--- | :--- | :--- |
| **定價心理學** | 製造商建議零售價 (MSRP) / 原價劃線 | 消費者對「折價幅度」產生超額價值感 | 零售電商標註「原價 \$9,900，特價 \$4,900」促成衝動購買 |
| **商務併購談判** | 賣方首先開出的「要約收購價 (Opening Ask)」 | 買方的還價與盡職調查價值區間被錨定 | 賣方高開 30%，買方通常只能在其下緣小幅拉鋸 |
| **高階薪資談判** | 過去前一份工作的薪資水準 | 新雇主核薪的參考基底，造成薪資黏性 | 跨國企業針對外部空降高管要求薪資歷史，限制加薪上限 |
| **資本預算預測** | 去年度實際營收或歷史基期數字 | 預算編列採取「增量預算 (Incremental)」 | 預算會議圍繞歷史數字上下浮動 5%，無法推動零基預算改革 |

## 三、 企業真實實務個案

### 1. 史蒂夫·賈伯斯 (Steve Jobs) 發表 iPad 的世紀定價錨定
2010 年蘋果公司發表初代 iPad 時，賈伯斯在舊金山芳草地藝術中心的發表會上演繹了商學院最經典的錨定行銷：
- **植入超高錨點**：賈伯斯在台上大螢幕打出巨大的「**\$999**」字樣，並引用眾多科技媒體與分析師的猜測：「許多人預期這台劃時代的設備售價將高達 999 美元。」
- **粉碎錨點創造震撼**：賈伯斯持續演講一分鐘，加深全場對 \$999 的心理定錨。隨後大螢幕上一枚巨大的印章重重砸碎了 \$999，並揭曉真實起售價僅為「**\$499**」。
- **決策效果**：消費者原本對一台沒有實體鍵盤、介於手機與筆電之間的未知產品缺乏價值標準。透過先錨定 \$999，\$499 瞬間被大腦感知為「極致划算、半價取得」，促成初代 iPad 首年銷量突破 1,500 萬台。

### 2. 雅虎 (Yahoo!) 拒絕微軟 446 億美元收購案的歷史錨定悲劇
2008 年 2 月，微軟提出以每股 31 美元（總價約 446 億美元，溢價達 62%）全現金收購雅虎。雅虎共同創辦人楊致遠與董事會深陷歷史錨定：
- **致命錨點**：雅虎高層深陷於 2000 年網路泡沫時代雅虎市值曾突破 1,200 億美元的歷史記憶，以及分析師給出的每股 40 美元「潛在獨立價值」錨點。
- **後果**：雅虎董事會強烈抵抗，要求微軟將報價提高至每股 37 美元以上，微軟最終憤而撤回要約。隨著 2008 年金融海嘯爆發與 Google 全面壟斷搜尋廣告，雅虎股價崩跌至 10 美元以下；最終於 2016 年以僅 48 億美元將核心業務賤賣給 Verizon，蒸發了近 400 億美元的股東價值。

## 四、 經理人反思與行動檢核清單

```
                               經理人去錨定 (De-anchoring) 防禦框架
┌─────────────────────────┬─────────────────────────┬─────────────────────────┐
│     1. 識別隱性錨點     │     2. 反向思考重構     │     3. 制度隔離程序     │
│ 標記首個報價與歷史數據  │ 強制尋找支持相反結論證據│ 採用盲審與零基預算機制  │
└─────────────────────────┴─────────────────────────┴─────────────────────────┘
```

### Executive Decision Checklist
- [ ] **談判主動出擊**：在具備充分估值基礎的商務談判中，我們是否敢於「先發制人提出第一個合理且雄心勃勃的報價」，將談判錨定在對我方有利的區間？
- [ ] **警惕對手先發定錨**：當對方提出極端報價時，我們是否立即要求對方撤回報價或重置談判基準，堅決避免在對方的錨點基礎上進行微調？
- [ ] **零基預算檢驗**：年度預算編列時，部門是否習慣性將「去年預算」作為自動錨點？是否針對重大專案推行「[[capital-budgeting_資本預算|零基資本預算 (Zero-Based Budgeting)]]」？
- [ ] **反向情境構思 (Consider the Opposite)**：在重大投資審查前，團隊是否刻意提出「若市場規模僅有預期的一半，真實估值是多少？」以打破樂觀財務模型錨點？
- [ ] **盲審機制落實**：在評估關鍵供應商技術方案或高階人才招募時，是否隱去品牌名稱與過往薪資歷史，使評審委員基於客觀客製化指標給分？
