# 附加價值與定價權 (Added Value & Pricing Power)

## 一、 核心定義與本質
- **附加價值（Added Value）**在競合理論與賽局定價中，衡量單一參與者對全體價值網絡所帶來的**不可替代之獨特貢獻**。
- **代數定義公式**：
  $$\text{Added Value}_i = V(\text{包含所有參與者在內之網絡總價值}) - V(\text{剔除參與者 } i \text{ 後剩餘之網絡總價值})$$
  若某企業退出網絡，整體市場總價值絲毫未減（對手可完美替代），則該企業的附加價值為零。

---

## 二、 價值創造 vs. 價值獲取鐵律

```text
【價值獲取上限定理】

  任何企業在賽局談判中所能分得的最大經濟利潤，
  絕對無法超越其自身為該網絡所貢獻的「附加價值 (Added Value)」！

  利潤分配份額 (Profit Captured) ≤ 自身附加價值 (Added Value)
```

1. **商品化陷阱（Commoditization Trap）**：
   - 若企業僅生產標準規格品，市場上存在多家可替代供應商，則單一企業的 Added Value 趨近於零，其利潤率必然受制於完全競爭的微利邊界；
2. **構築附加價值的核心路徑**：
   - 掌控獨家專利 IP、專屬客戶關係、難以複製的工藝良率或網絡效應，使「沒有你，整個生態系就無法運轉」。

---

## 三、 實務案例對標
- **台積電（TSMC）於半導體網絡之極致附加價值**：
  若全球 AI 晶片生態系剔除台積電，先進製程產能將瞬間短缺 90% 以上，全球科技巨頭損失高達兆美元。因此，台積電享有巨大的 Added Value，賦予其在供應鏈中絕對的定價權與高達近 60% 的結構性毛利率。
