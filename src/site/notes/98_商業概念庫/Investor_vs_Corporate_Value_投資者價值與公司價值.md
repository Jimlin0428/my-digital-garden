# 投資者價值與公司價值 (Investor vs. Corporate Value)

## 一、 核心概念與兩階段投資旅程
企業財務策略的終極任務，是促成「投資者價值」與「公司價值」的完美收斂：
1. **投資者價值（Investor Value / 資本市場端）**：
   - 著眼於投資人為承擔特定風險所要求的**必要報酬率（Required Return）**，直接由公開市場之「**股價（Stock Price）**」與本益比所體現。
2. **公司價值（Corporate Value / 企業營運端）**：
   - 基於公司當前的經營模式、競爭優勢與未來資本支出專案，能否產生**超越資本成本的「未來預期自由現金流量現值（NPV of Cash Flows）」**。

## 二、 價值脫節的市場修正機制
- 若公司投資收益無法達到資本市場的必要報酬率（預期收益現值 < 必要報酬），股價必將遭受下修；
- 反之，當管理層展現極高的資本配置紀律（$ROIC > WACC$），公司價值持續擴張，必將推升資本市場的投資者價值，形成正向飛輪。
