# 凱利共變歸因模型與跨文化歸因 (Kelley's Covariation Model & Cross-Cultural Attribution)

> [!NOTE] 核心概念精粹
> **凱利共變模型（Kelley's Covariation Model）** 由社會心理學家哈羅德·凱利（Harold Kelley, 1967）提出，用以規範管理者如何理性判斷他人的行為成因究竟來自**「內在特質（能力、努力、動機）」**還是**「外在情境（任務難度、制度缺陷、運氣）」**。透過審查**獨特性、共通性與一致性**三項維度，主管能有效避免落入[[98_商業概念庫/fundamental-attribution-error_基本歸因謬誤\|基本歸因謬誤（FAE）]]。

---

## 一、 凱利三維度共變判斷矩陣

當員工 A 在特定事件（例如「專案 X 延誤交付」）表現失常時，經理人應依序檢核以下三個共變指標：

| 歸因維度 | 核心診斷提問 | 觀察結果 ➔ 指向「外在情境歸因」 | 觀察結果 ➔ 指向「內在特質歸因」 |
| :--- | :--- | :--- | :--- |
| **1. 獨特性<br>(Distinctiveness)** | 員工 A 在「其他類似任務」上是否也表現不佳？ | **高獨特性**：他在其他專案都表現優異，唯獨專案 X 出錯（問題在專案本身） | **低獨特性**：他無論接手什麼專案都經常延誤（問題在個人習慣或能力） |
| **2. 共通性 / 共識度<br>(Consensus)** | 「其他同事」面對與專案 X 相同的情境時，是否也出現同樣問題？ | **高共通性**：幾乎所有接手類似案件的同事都延誤（問題在系統或資源瓶頸） | **低共通性**：別人都順利準時完成，只有他延誤（問題在個人執行力） |
| **3. 一貫性<br>(Consistency)** | 員工 A 過去面對「專案 X 這類任務」時，是否每次都出錯？ | **低一貫性**：他過去做這類專案都準時，僅這一次失常（可能為偶發外力事件） | **高一貫性**：他每次碰到這類任務就必然延誤（穩定之個人短板或態度問題） |

## 二、 跨文化歸因差異與雙重文化認同（Bicultural Identity Switching）

人類的歸因習慣並非絕對客觀，而是深受文化價值觀塑形：
1. **西方個人主義 vs. 華人情境導向**：
   - 西方個人主義文化習慣將事件成敗高度聚焦於「個體行動者」（如將企業興衰全數歸功或歸咎於 CEO 個人），因此較容易產生強烈的[[98_商業概念庫/fundamental-attribution-error_基本歸因謬誤\|基本歸因謬誤]]。
   - 華人文化強調關係脈絡、上下倫理與整體和諧，在推論因果時較能兼顧外部情境與環境約束。
2. **雙重文化認同切換（Bicultural Identity Switching）**：
   - 具備跨文化成長或留學經驗的個體，大腦中同時儲存了兩套文化心智腳本。
   - **環境線索誘發實驗**：在研究室實驗中，當受試者處於懸掛中國水墨畫、擺設茶具與播放中樂的空間時，會自動啟動華人情境歸因思維；反之，當受試者處於西方文化線索環境中，則會切換至個人主義歸因模式。這顯示跨國組織的辦公環境與語言切換，能實質改變員工的決策歸因框架。

---

## 三、 經理人歸因校正檢核清單

- [ ] **先查共通性與獨特性，再談個人責任**：部屬未達標時，先橫向比對同儕基準（Consensus）與歷史表現（Distinctiveness），避免直覺式的[[98_商業概念庫/fundamental-attribution-error_基本歸因謬誤\|基本歸因謬誤]]。
- [ ] **區分「偶發失誤」與「長期慣性」**：對低一貫性的偶發錯誤給予改善空間與情境排障；對高一貫性且低獨特性的問題，啟動針對性培訓或職務調整。
- [ ] **覺察跨文化團隊的歸因摩擦**：外派主管或跨國專案團隊在覆盤失敗時，應主動協調西方「個人當責」與東方「系統脈絡」的歸因落差。
