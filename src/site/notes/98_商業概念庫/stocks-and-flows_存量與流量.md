# 存量與流量 (Stocks and Flows)

## 📌 概念核心定義

**存量與流量 (Stocks and Flows)**，源自系統動力學 (System Dynamics, 由麻省理工學院 Jay Forrester 開創) 與總體經濟學，是理解任何複雜動態系統運作本質的核心基石，更是**企業財務報表體系結構的根本哲學支柱**：
- **存量 (Stock / Accumulation)**：指在**特定時間時點 (Point in Time)** 上所累積的實體或非實體資源之狀態量（例如：2026 年 12 月 31 日資產負債表上的現金餘額、存貨總額、機器設備價值、股東權益）。存量具有記憶性與慣性，無法在瞬間憑空改變。
- **流量 (Flow / Rate of Change)**：指在**一段時間跨度 (Period of Time)** 內流入或流出系統的變動量或速率（例如：綜合損益表上的年度營業收入、年度淨利，以及現金流量表上的年度營業活動現金流 CFO）。

```
        流入量 Inflow (流量)                     流出量 Outflow (流量)
      (例: 銷貨收現、新增融資)                 (例: 營業費用付現、資本支出)
               │                                         ▲
               ▼                                         │
        ┌─────────────────────────────────────────────────────┐
        │                     【存量 Stock】                  │
        │               (例: 銀行存款、庫存資產)              │
        │                                                     │
        │               積蓄水位 Current Level                │
        └─────────────────────────────────────────────────────┘
```

## 🔬 理論架構與數理模型

### 1. 系統動力學之浴缸微積分模型 (Bathtub Calculus)

存量是歷史流入量與流出量的積分累積，其數學形式表述為：

$$\text{Stock}(t) = \text{Stock}(t_0) + \int_{t_0}^{t} [\text{Inflow}(s) - \text{Outflow}(s)] \, ds$$

其瞬時變動率為淨流量：

$$\frac{d\text{Stock}(t)}{dt} = \text{Net Flow}(t) = \text{Inflow}(t) - \text{Outflow}(t)$$

#### 動態行為法則：
1. **若 $\text{Inflow} > \text{Outflow}$**：存量水位上升（即使流入量自身在遞減，只要依然大於流出量，存量就持續上升）。
2. **若 $\text{Inflow} < \text{Outflow}$**：存量水位下降。
3. **若 $\text{Inflow} = \text{Outflow}$**：系統達到**動態平衡 (Dynamic Equilibrium)**，存量保持恆定。

### 2. 財務報表的三大板塊：存量與流量的有機循環

現代會計四大報表本質上就是一套極度嚴密的「存量-流量互動模型」：

```
【期初資產負債表】                【期間動態流量表】                 【期末資產負債表】
  (期初時點存量)                    (一段時間之流量)                   (期末時點存量)
┌──────────────┐                 ┌──────────────┐                 ┌──────────────┐
│  資產存量     │ ──────────────►│ 綜合損益表   │───────────────► │  資產存量     │
│  負債存量     │  (營運資金投入) │ 現金流量表   │ (淨利轉保留盈餘)│  負債存量     │
│  權益存量     │                 │ 權益變動表   │ (淨現金累積)    │  權益存量     │
└──────────────┘                 └──────────────┘                 └──────────────┘
  Time: t_0                        Period: [t_0, t_1]               Time: t_1
```

- **資產負債表 (Balance Sheet)**：典型的**靜態存量表**，記錄特定日期的資源水位；
- **綜合損益表 (Income Statement)**：反映經營期間經營成果的**效益流量表**；
- **現金流量表 (Cash Flow Statement)**：反映特定期間流過企業管道的**現金流量表**；
- **權益變動表 (Statement of Changes in Equity)**：調節股東權益存量增減的**資本流量表**。

## 📊 商業世界中的存量-流量典型維度對照

| 商業管理領域 | 存量概念 (特定時點狀態) | 流量概念 (一段期間變動率) | 管理核心挑戰 |
| :--- | :--- | :--- | :--- |
| **企業財務** | 現金及約當現金餘額、總負債餘額 | 營業活動現金流 (CFO)、自由現金流 (FCF) | 防止「流量斷流」導致「存量耗盡」的黑字倒閉。 |
| **供應鏈與庫存** | 倉庫現有成品與在製品庫存量 (Stock) | 每日出貨率 (Burn Rate)、供應商補貨率 | 平衡安全庫存存量與資金佔用成本。 |
| **數位商業/SaaS** | 活躍訂閱用戶總數 (Subscriber Base) | 新客獲取率 (CAC)、用戶流失率 (Churn Rate) | 當流失流量大於獲客流量時，平台用戶存量萎縮。 |
| **人力資本** | 組織人才庫規模、研發核心智慧資本 | 新人招募入職率、核心骨幹離職率 | 打造組織學習記憶，避免關鍵知識存量隨員工離職流失。 |

## 🏢 企業實戰案例：矽谷銀行 (SVB) 的存量幻覺與流量擠兌崩塌

### 1. 商業背景與「資產存量」的美化假象
2023 年初，矽谷銀行 (Silicon Valley Bank, SVB) 的資產負債表看似無比健康：
- 總資產存量高達 **2,090 億美元**；
- 其中持有巨額「無違約風險」的美國公債與機構不動產抵押貸款證券 (MBS)。
- 管理階層誤以為只要債券存量規模龐大，銀行就堅不可摧。

### 2. 存量定價盲點與極速「流量擠兌」
1. **升息導致資產存量市值大幅縮水**：聯準會激進升息，SVB 持有的長天期低息債券產生高達 150 億美元的未實現帳面損失（隱藏於持有至到期或 OCI 存量中）。
2. **數位時代的超音速現金流出流量**：創投基金圈在社群媒體與通訊軟體上警示風險，引發科技新創公司集體提款。
3. **破產臨界點**：短短 **42 小時內，高達 420 億美元** 的現金流量從 SVB 瘋狂流出！
- **治理啟示**：**任何靜態資產存量，在面臨極端單向的負向流量衝擊時，都顯得不堪一擊**。SVB 資產雖無信用違約風險，但嚴重缺乏短期變現流動性，最終在流量巨浪拍打下瞬間滅頂。

## ⚠️ 經理人常見盲點與治理陷阱

1. **混淆存量與流量概念（以流量指標除以存量指標忘記取平均）**：在計算總資產週轉率 ($TAT$) 或存貨週轉率 ($IT$) 時，分子是整年度的「營收/成本流量」，分母若只取期末單一時點的「資產存量」，在季節性波動大的產業中會產生嚴重失真，正確做法必須採用「平均資產存量」。
2. **「營收高速成長」引發的營運資金黑洞陷阱**：許多高成長新創公司誤以為營收流量翻倍代表公司安全，卻不知營收流量爆發伴隨著應收帳款與存貨存量的倍增，龐大的營運資金存量佔用將現金流量徹底吸乾，引發成長型破產。
3. **誤將非現金資產存量視為可立即支付薪資的現金**：廠房設備與品牌商譽帳面價值再高，若無法在幾天內產生正向的現金流入流量，依然無法挽救即將到期的銀行借款違約。

## 🎯 高階經理人決策檢核清單

- [ ] 公司的管理儀表板 (Dashboard) 是否同時清晰呈現關鍵「存量指標」與「流量指標」？
- [ ] 財務團隊在進行財務比率計算時，是否嚴格遵循「流量與存量匹配法則」（存量取期初期末平均值）？
- [ ] 公司的現金存量能夠支撐當前每月的淨現金流出流量（即 Burn Rate 燒錢速度）幾個月？
- [ ] 在評估事業部擴張時，是否同時測算了營收流量擴大所需的營運資金存量增量？
- [ ] 是否針對關鍵智慧資產（技術專利、專案代碼、客戶關係）建立系統化沉澱機制，防止知識隨人員流動而流失？
