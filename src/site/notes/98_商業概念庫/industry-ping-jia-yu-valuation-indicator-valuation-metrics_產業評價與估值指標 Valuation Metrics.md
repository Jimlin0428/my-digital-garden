# 產業評價與估值指標 Valuation Metrics

## 📌 概念定義
針對不同產業之資本結構、資產重輕與成長階段，投資人與經理人選用之企業價值評價量化指標陣列。

---

## 📊 核心估值指標矩陣

| 評價指標 | 全稱 | 適用產業類型 | 核心優勢 |
| :--- | :--- | :--- | :--- |
| **ROIC** | Return on Invested Capital | 全產業 / 本業專注型 | 衡量投入資本之真實獲利效率 |
| **EV/EBITDA** | Enterprise Value / EBITDA | 資本密集 / 重資產 / 併購 | 排除資本結構、稅率與折舊干擾 |
| **P/E** | Price-to-Earnings Ratio | 穩定獲利企業 | 最普遍之相對本益比評價法 |
| **P/B** | Price-to-Book Ratio | 金融業 / 週期重資產 | 股價淨值比估值法 |
