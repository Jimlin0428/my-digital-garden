# PARTS 賽局變革架構 (The PARTS Framework)

## 一、 核心定義與本質
- **PARTS 框架**由 Adam Brandenburger 與 Barry Nalebuff 提出，主張賽局並非不可改變的外在宿命。企業高階決策者可以透過主動操縱**五大戰略槓桿（PARTS）**，徹底重寫商業遊戲規則，將不利賽局轉化為優勢格局。

---

## 二、 PARTS 五大變革槓桿解構

```text
【PARTS 賽局變革五大支柱】

  P (Players 參與者)   ──▶ 改變賽局成員：引進互補者、培育替代供應商、引導破壞者退出
  A (Added Value 附加價值) ──▶ 提升自身不可替代性：Added Value ＝ V(All) － V(All－i)
  R (Rules 規則)       ──▶ 重寫合約條款：最惠國待遇 (MFN)、帶走或付款 (Take-or-Pay)
  T (Tactics 戰術/認知)──▶ 塑造對手預期心理：釋放可信擴產訊號、維持策略模糊性
  S (Scope 範疇)       ──▶ 調整市場邊界：鏈結跨界賽局 (跨產業生態)、切割風險賽局
```

### 各要素實戰操作方針：
1. **Players（參與者）**：
   - 增加互補者：引進外部第三方開發者共建生態；
   - 培育第二供應商（Second Source）：避免被單一供應商勒索敲竹槓。
2. **Added Value（附加價值）**：
   - 公式：$\text{Added Value}_i = V(\text{包含所有參與者之總價值}) - V(\text{剔除參與者 } i \text{ 後之總價值})$；
   - 企業所能分配到的利潤上限，恆等於其附加價值。若自身缺乏獨特性，附加價值為零，利潤亦歸零。
3. **Rules（規則）**：
   - 善用交易合約：導入「最惠客戶條款（MFN）」或「首拒權（ROFR）」，從體制上確保自身交易條件優於同業。
4. **Tactics（戰術）**：
   - 資訊揭露管理：在法說會宣布高額研發投入或長期產能承諾，引導對手打消進攻念頭。
5. **Scope（範疇）**：
   - 擴大範疇：將單純硬體買賣與雲端軟體訂閱賽局結合（跨界包夾）；
   - 切割範疇：設立獨立子公司或防火牆，隔離特定高風險爭訟市場。
