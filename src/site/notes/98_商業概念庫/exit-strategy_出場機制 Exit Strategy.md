# 出場機制 (Exit Strategy)

## 一、 核心定義與意涵
- **出場機制 (Exit Strategy)** 是創投資本與創業團隊在商業計畫初期即行規劃的資本變現管道，指投資人與創辦人將其所持股權轉換為流動性現金或可交易資產的終局方式。

## 二、 四大主流出場路徑
1. **首次公開發行 (IPO)**：
   - 於公開資本市場掛牌上市（如 Nasdaq、台灣創新板 TIB、證交所主板）。
   - 具有最高流動性與聲譽效應，能獲取最高估值乘數，但面臨嚴格的監管、財報揭露與閉鎖期（Lock-up Period）。
2. **策略性併購 (M&A / Trade Sale)**：
   - 將公司出售給大型科技產業巨頭（如 Google、Microsoft、台積電 CVC 策略收購）。
   - 出場速度快、流動性一次到位，是全球 90% 以上新創企業的主要退出途徑。
3. **二次份額交易 (Secondary Sale)**：
   - 早期投資人將股份轉售給後續輪次的大型私募股權基金 (PE) 或後期創投。
4. **清算與重組 (Liquidation)**：
   - 企業經營未達預期，處分剩餘資產依受償順序清算出場。
