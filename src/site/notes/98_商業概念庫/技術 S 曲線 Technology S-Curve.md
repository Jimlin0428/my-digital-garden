# 技術 S 曲線 Technology S-Curve

## 📌 概念定義
**技術 S 曲線**（Technology S-Curve）描述了一項新技術在生命週期中，「累積研發資源/時間投入」與「技術效能產出」之間的非線性 S 型演進軌跡。

```mermaid
flowchart LR
    A["胚胎期 (Embryonic)
研發投入高 / 效能突破慢"] --> B["成長期 (Growth)
關鍵突破 / 效能快速陡升"]
    B --> C["成熟期 (Mature)
物理極限 / 邊際收益遞減"]
    C -.->|[[雙軌轉型 Dual Transformation]]| D["新 S 曲線 (Discontinuity)
破壞式創新交替"]
```

---

## 📈 三大演進階段

1. **胚胎期（Embryonic Phase）**：技術尚不成熟，研發投入高但效能提升緩慢。
2. **成長期（Growth Phase）**：主導設計（Dominant Design）確立，效能隨累積經驗爆發性成長。
3. **成熟飽和期（Mature Phase）**：接近物理與工程極限，再投入大量資金也僅能獲得微小進步（邊際遞減）。
