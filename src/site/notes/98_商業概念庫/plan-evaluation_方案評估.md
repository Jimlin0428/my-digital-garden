# 方案評估 (Alternative Evaluation)

## 一、 核心概念與理論源流

### 1. 理論定義：從龐大市場清單到最終購買選擇的過濾漏斗
**方案評估 (Alternative Evaluation)** 是消費者購買決策歷程的第三個核心階段。在經過[[98_商業概念庫/problem-recognition_問題確認\|問題確認]]與[[98_商業概念庫/information_資訊搜尋\|資訊搜尋]]後，消費者面對蒐集到的各家品牌與產品規格，運用特定的心理評估法則進行比對、權衡與淘汰，進而形成最終購買意圖。

消費者行為學對其嚴謹定義為：
> **「消費者依據個人的價值觀、偏好結構與預算約束，確立一組客觀或主觀的『評價準則 (Evaluative Criteria)』，並將這些準則應用於由候選品牌構成的『考量集 (Consideration Set)』，透過特定決策啟發式規則評估各方案效用，最終排定優先順序的心理演算過程。」**

---

### 2. 品牌集合層次漏斗架構 (Hierarchy of Brand Sets)

並非市場上的所有品牌都能進入消費者的評估雷達，品牌在消費者心智中經歷層層篩選：

```
+---------------------------------------------------------------------------------+
|                       品牌集合層次過濾漏斗模型 (Brand Sets)                     |
+---------------------------------------------------------------------------------+
  [ 全市場總集合 (Universal Set / All Brands in Market) ]
  * 市場上存在的所有品牌 (包含國內外數百個品牌)
       |
       v
  [ 知曉集 / 意識集 (Awareness Set) ] <------------- [ 不知曉集 (Unawareness Set) ]
  * 消費者聽說過、有基本印象的品牌                    * 從未聽聞、在心智中不存在的品牌
       |
       +-----------------------+-----------------------+
       |                       |                       |
       v                       v                       v
  【考量集 (Consideration Set)】 [ 惰性集 (Inert Set) ]   [ 排斥集 (Inept Set) ]
  * **正式納入評估比較的 3-5 個強者**  * 既無好感亦無惡感，    * 曾有負面體驗或醜聞，
  * 具備實質被購買機會的品牌清單     備選備胎方案            消費者堅決拒絕考慮的黑名單
       |
       v
  [ 最終選擇 (Final Choice / Purchase Decision) ]
```

> [!IMPORTANT]
> **行銷的核心殘酷法則**：
> 若一個品牌未能成功擠入消費者的 **「考量集 (Consideration Set)」**，則後續的一切降價促銷、規格升級或廣告推廣均毫無意義——因為在消費者的心智競技場中，該品牌根本沒有上場比賽的資格。

## 二、 數理決策法則：補償性模型 vs. 非補償性模型

消費者在評估考量集中的方案時，主要採用兩大類截然不同的決策規則：

### 1. 補償性決策模型 (Compensatory Models)
- **核心哲學**：產品的各屬性之間可以互相補償——某個屬性上的劣勢（如價格昂貴），可以被另一個屬性上的卓越優勢（如性能極致、續航超長）所抵消。
- **代表模型：費許賓多屬性態度模型 (Fishbein Multi-Attribute Model)**
  $$A_j = \sum_{i=1}^{n} w_i \cdot B_{ij}$$
  其中：
  - $A_j$ 為消費者對方案 $j$ 的總體態度/效用得分。
  - $w_i$ 為消費者對第 $i$ 個評估準則賦予的相對權重 ($\sum w_i = 1$)。
  - $B_{ij}$ 為消費者認為方案 $j$ 在第 $i$ 個屬性上的表現評分。
  消費者將計算出各品牌總分，並選擇總分最高者 ($j^* = \arg\max A_j$)。該模型通常適用於高涉入度、高理性的大型採購（如購買房地產、B2B 設備採購）。

---

### 2. 非補償性決策模型 (Non-compensatory Models)
在快節奏生活或資訊超載情境下，消費者往往缺乏計算總效能的認知資源，轉而採用啟發式直覺法則。在此類模型中，**某個核心屬性的缺陷，絕不可被其他屬性的優點所補償**：

```
+---------------------------------------------------------------------------------+
|                       四種典型非補償性決策啟發式規則                            |
+---------------------------------------------------------------------------------+
  決策法則          判定邏輯與操作機制                                  典型消費者心理口吻
  =================================================================================
  1. 聯集法         所有重要屬性都必須達到**最低門檻**；                「只要有一項不達標，
  (Conjunctive)     任何一項不及格者立即淘汰出局。                      立刻淘汰！」
  ---------------------------------------------------------------------------------
  2. 分離法         只要在**某一特定單一屬性**上達到極致卓越，          「只要這款相機夜拍最強，
  (Disjunctive)     即可直接中選，其餘平庸缺陷概不追究。                重量再重我也買！」
  ---------------------------------------------------------------------------------
  3. 字典編纂法     將屬性按重要性排序 (第1優先、第2優先...)；          「我只看價格，選最便宜的；
  (Lexicographic)   在第 1 優先屬性上得分最高者勝出；若打平再比第 2。   若同價再看外觀。」
  ---------------------------------------------------------------------------------
  4. 逐項淘汰法     依屬性重要性順序，逐一設定最低門檻進行過濾，        「第一輪先砍掉低於 3 星的，
  (EBA, Tversky)    直到最後只剩下唯一生還品牌為止。                    第二輪再砍掉運費不免的。」
  =================================================================================
```

## 三、 商戰歷史實戰：特斯拉的非補償性突圍 vs. 戴森吸塵器的溢價定價

### 1. 特斯拉 (Tesla)：運用「字典編纂法」顛覆百年豪華車考量集
傳統豪華車（雙 B、奧迪、保時捷）在方案評估中構築了基於多屬性補償模型的厚重護城河：真皮內裝手工縫線、V8 引擎排氣聲浪、百家實體經銷維修網絡。
- **重塑評價準則權重**：特斯拉進入市場時，若按傳統百項指標綜合評分，其組裝公差瑕疵與內裝簡陋將在補償模型中慘敗。
- **鎖定非補償性第一屬性**：特斯拉將新一代科技菁英的評價準則重新洗牌，將 **「OTA 自動軟體更新與智慧駕駛體驗」** 拔高為字典編纂法的第一維度（重要性權重 $w_1 = 80\%$）。在第一維度上，傳統油車得分近乎為零，特斯拉直接橫掃奪冠，以非補償性路徑打破了傳統車廠的考量集壁壘。

### 2. 戴森 (Dyson)：分離法 (Disjunctive) 打造極致高溢價神話
在戴森氣旋吸塵器問世前，市場吸塵器均使用集塵紙袋，消費者在評估方案時遵循聯集法：價格在 100 美元以內、吸力尚可、噪音別太大。
- **分離式單點打爆**：詹姆士·戴森 (James Dyson) 研發出雙氣旋無袋技術，並將售價定在令人咋舌的 400 美元以上（高達競品 4 倍）。
- **心智擊穿**：戴森在行銷中極致聚焦於一個單點——**「吸力永不衰減 (No Loss of Suction)」**。對於痛恨集塵袋堵塞發臭的高端消費者而言，這一卓越屬性觸發了分離法評估：「只要能徹底解決吸力衰減與清理紙袋的痛苦，價格比別人貴 4 倍我也買單！」

## 四、 補償性 vs. 非補償性評估情境適配與行銷戰略矩陣

| 維度 | 補償性決策主導場景 | 非補償性決策主導場景 |
| :--- | :--- | :--- |
| **產品與品類特性** | 高涉入度、高單價、客製化複雜產品（如 B2B ERP、企業購車、購屋）。 | 快速消費品 (FMCG)、時間壓力下的購買、高度標準化產品。 |
| **消費者認知狀態** | 擁有充裕時間、認知精力旺盛、具備分析性人格。 | 時間緊迫、認知超載、面臨過多微小差異的選項疲勞。 |
| **優勢品牌的戰略** | **全面無短板防守**：維持各項屬性均衡發展，防止出現任何致命扣分項。 | **突出第一賣點**：在單一核心優勢上做到極致（如安全之於富豪、越野之於 Jeep）。 |
| **挑戰者品牌的戰略** | **改變屬性權重**：透過教育市場，將對手擅長屬性的重要性 $w_i$ 貶低。 | **設定淘汰門檻**：推廣特定標準（如食品無添加、0蔗糖），將傳統對手全部踢出局。 |

## 五、 經理人決策檢核清單 (Executive Checklist)

- [ ] **考量集入選率實證查核**：在目標市場的隨機抽樣調查中，本品牌進入顧客「考量集 (Consideration Set)」的比率是多少？是否存在高知名度但高排斥率的致命尷尬？
- [ ] **主導決策法則透視**：我們的目標客群在掏錢的那一刻，採用的是「多屬性均衡打分（補償性）」，還是「只要一處不爽立刻換家（聯集法）」？
- [ ] **最低致命門檻 (Cutoff) 清查**：本產品是否存在某項隱蔽的硬傷（如續航力低於同業均值、售後保固僅有一年），導致在消費者的第一輪篩選中就被系統性過濾淘汰？
- [ ] **差異化賣點 (POD) 銳度檢驗**：在非補償性評估場景中，我們是否具備一項「只要顧客在意該維度，我們就絕對天下第一」的標籤化屬性？
- [ ] **對手評價準則的解構破壞**：當競爭對手在特定指標（如算力、主頻）上大幅領先時，我們能否在行銷上成功將顧客注意力引導至全新維度（如功耗比、生態豐富度）？
