# 成長機會現值 (Present Value of Growth Opportunities, PVGO)

## 一、 核心定義與本質

- **成長機會現值 (PVGO)** 是公司理財與股權估值理論中的核心概念，用於衡量**市場賦予企業未來所有潛在再投資擴張專案所能創造的超額淨現值（NPV）加總**。
- **股價內在價值二分法**：
  在財務評價架構下，一家企業的每股內在價值（$P_0$）可明確拆解為「**零成長靜態資產價值**」與「**成長機會動態期權價值**」兩大維度：
  $$\text{企業股價 } (P_0) = \frac{\text{EPS}_1}{r_e} + \text{PVGO}$$
  - **$\frac{\text{EPS}_1}{r_e}$（零成長靜態現金牛價值）**：假設企業不再進行任何資本支出與擴張，將每期盈餘全額發放股利（$b = 0$），在股權資金成本 $r_e$ 下折現之永續年金價值。
  - **$\text{PVGO}$（成長機會現值）**：企業將保留盈餘再投資於具備經濟利潤之專案時，扣除投入成本後所創造之超額現值。

---

## 二、 數理推導與估值模型聯立

### 1. PVGO 基礎估算公式
$$\text{PVGO} = P_0 - \frac{\text{EPS}_1}{r_e}$$

### 2. 結合戈登成長模型 (Gordon Growth Model / DDM) 推導
若企業保留盈餘比率為 $b$（即股利發放率為 $1 - b$），再投資回報率為 $\text{ROE}$，其永續成長率為 $g = b \times \text{ROE}$。由 [[98_商業概念庫/dividend-discount-model_股利折現模型\|DDM 模型]]：
$$P_0 = \frac{D_1}{r_e - g} = \frac{\text{EPS}_1 (1 - b)}{r_e - b \times \text{ROE}}$$

將其代入基礎拆解式推導可得：
$$\text{PVGO} = \frac{\text{EPS}_1 (1 - b)}{r_e - b \times \text{ROE}} - \frac{\text{EPS}_1}{r_e} = \frac{\text{EPS}_1 \cdot b (\text{ROE} - r_e)}{r_e (r_e - g)}$$

### 3. 本益比 (P/E Ratio) 之二元分解
將原式等號兩側同除以 $\text{EPS}_1$，可推導出前瞻本益比的內部結構：
$$\frac{P_0}{\text{EPS}_1} = \frac{1}{r_e} + \frac{\text{PVGO}}{\text{EPS}_1}$$
- 前瞻本益比本質上由兩部分組成：
  1. **無成長基礎倍數**（$\frac{1}{r_e}$）：僅反映資金成本與基本無風險利率水準。
  2. **成長溢價乘數**（$\frac{\text{PVGO}}{\text{EPS}_1}$）：市場對管理層再投資創造超額回報的信任度與估值溢價。

---

## 三、 價值創造之判讀準則（價值創造 vs. 價值毀滅）

由公式 $\text{PVGO} \propto (\text{ROE} - r_e)$，可清楚判別企業擴張政策對股東價值的真實影響：

| 條件判別 | PVGO 狀態 | 資本配置決策本質 | 經理人最佳決策建議 |
| :--- | :---: | :--- | :--- |
| **$\text{ROE} > r_e$** | **$\text{PVGO} > 0$** | **價值創造 (Value Creation)**<br>再投資收益率高於資本成本，投入越多資本，股東財富增加越多。 | 提高保留盈餘比例 $b$，擴大資本支出投入擴張專案。 |
| **$\text{ROE} = r_e$** | **$\text{PVGO} = 0$** | **價值中立 (Value Neutral)**<br>專案僅獲得要求回報，營收規模放大但無法推升每股股價。 | 資本支出或發放股利對股東價值無差別。 |
| **$\text{ROE} < r_e$** | **$\text{PVGO} < 0$** | **價值毀滅 / 盲目擴張陷阱 (Value Destruction)**<br>再投資報酬低於資本折現率，保留盈餘實際上在摧毀股東財富。 | 應立即終止擴張，將現金 100% 透過股利或[[04_主題選修/10_創業與企業財務策略/02_模組筆記/Module_1_創新思維與商業模式/M1-2_白板決策鏈與財務價值三角#4-課堂白板推導專題三資本三階進化與返還政策股利-vs-庫藏股\|庫藏股回購]]返還股東。 |

## 四、 產業實務與經理人策略意涵

1. **高成長科技股 vs. 成熟現金牛企業**：
   - **高成長企業（如 AI 晶片、先進封裝半導體、高階軟體 SaaS）**：股價通常有 60%～80% 以上由 PVGO 構成，反映高本益比；市場對任何成長率指引下修極度敏感。
   - **成熟防禦型企業（如公用事業、傳統電信、低階成熟代工廠）**：PVGO 趨近於 0 甚至為負，股價幾乎由當前穩定息收支撐，評價以高殖利率與淨值比為基準。
2. **與 7 Powers 及經濟護城河的動態共振**：
   - 根據經濟學均值回歸規律，超額利潤終將引來新競爭者侵蝕。唯有具備 [[98_商業概念庫/economic-moat_經濟護城河\|經濟護城河]] 與「7 Powers（規模經濟、網絡效應、高轉換成本、獨佔資源等）」的企業，才能長期維持 $\text{ROE} > r_e$ 的利差，確保 PVGO 價值不會快速蒸發。
