# 商業計畫書 (Business Plan, BP)

## 📌 概念核心定義

**商業計畫書 (Business Plan, 簡稱 BP)** 是一份全面、系統化且結構嚴謹的戰略性文件，用以深入闡述一家新創企業或成熟公司內部新事業部，**在特定時間跨度內（通常為 3 至 5 年），「我們是誰、我們要去哪裡、我們如何抵達目標、需要多少資源，以及預期創造何種財務與社會回報」的完整行動綱領**。

在現代管理與創業投資領域，商業計畫書扮演著雙重核心角色：
1. **外部融資與利害關係人對齊溝通**：它是創業者向創投基金 (VC)、銀行、政府補助機構與戰略合作夥伴展示商業可行性、團隊執行力與風險防禦機制的「盡職調查通行證」；
2. **內部戰略推演與營運壓力測試**：著名創投教父 Don Valentine 曾言：「撰寫計畫書最重要的價值，並非計畫書本身，而是**迫使創業者坐在桌前，用最嚴格的邏輯、數字與事實，拷問自己商業構想中的每一個漏洞**。」

## 🔬 理論架構：商業計畫書之標準十大模組

一份符合機構投資人標準的完整商業計畫書，通常包含以下十大核心模組：

```
                    【商業計畫書標準結構模組】
┌─────────────────────────────────────────────────────────────┐
│ 01. 執行摘要 (Executive Summary) ◄── (決定生死的第一道關卡) │
├─────────────────────────────────────────────────────────────┤
│ 02. 公司願景與核心使命 (Company Description & Mission)      │
│ 03. 市場機會與痛點分析 (Market Opportunity & Industry)     │
│ 04. 產品、服務與智慧財產 (Product/Service Offering & IP)    │
│ 05. 目標客群與競爭格局分析 (Customer Segments & Competitive)│
│ 06. 進入市場戰略與銷售通路 (GTM Strategy & Marketing)       │
│ 07. 生產、交付與營運規劃 (Operations & Milestone Roadmap)   │
│ 08. 組織架構與關鍵團隊 (Management Team & Governance)       │
│ 09. 財務預測與損益平衡分析 (Financial Model & Projections)  │
│ 10. 融資需求與資金用途規劃 (Funding Request & Exit Strategy)│
└─────────────────────────────────────────────────────────────┘
```

### 1. 執行摘要 (Executive Summary)：決定命運的 3 分鐘
- 雖然置於計畫書首頁，但必須在全書完成後**最後撰寫**。
- 篇幅嚴格控制在 1 至 2 頁內。必須在 3 分鐘內回答五大靈魂問題：
  1. 你解決了什麼痛點？
  2. 你的解決方案為何具備壓倒性優勢？
  3. 市場有多大？
  4. 你的團隊為什麼能贏？
  5. 本輪融資多少、預計達成何種里程碑？

### 2. 財務預測模型 (Financial Model) 的底層邏輯
- 嚴格拒絕「自上而下 (Top-Down)」的拍腦袋預測（如：全中國有 14 億人，我們只要拿到 1% 市場份額就有 1,400 萬客戶）；
- 必須採取**「自下而上 (Bottom-Up)」**的運算推導：
  $$\text{Revenue} = \text{銷售漏斗點擊數} \times \text{轉化率} \times \text{每客單價 (ARPU)} \times \text{留存回購率}$$
- 提供 3~5 年完整的損益表 (P&L)、資產負債表與現金流量表預測，並清晰標註**損益平衡點 ($BEP$)** 與現金跑道最低點 (Trough)。

## 📊 傳統厚重計畫書 vs. 精實動態計畫書 (Living Document)

隨著科技迭代加速，現代創業學界對商業計畫書的形式產生了深刻的典範轉移：

| 評估維度 | 傳統靜態商業計畫書 (Traditional BP) | 現代精實商業計畫書 (Lean Living Document) |
| :--- | :--- | :--- |
| **文件長度** | 30 至 60 頁厚重裝訂報告，圖表繁複。 | 10 至 15 頁核心文件，搭配精準 [[98_商業概念庫/pitch-deck_募資簡報\|pitch-deck_募資簡報]]。 |
| **底層假設** | 假設環境穩定、預測準確，計畫一旦寫成即全力執行。 | 假設一切皆為「未驗證假設」，隨時準備進行樞軸轉向。 |
| **運作工具** | 靜態 Word/PDF 報告、厚重財務模型。 | 結合 [[98_商業概念庫/business-model_商業模式\|business-model_商業模式]] 畫布 (BMC) 與持續迭代看板。 |
| **適用情境** | 銀行大額貸款、政府重大基礎建設採購、跨國併購。 | 高科技新創天使輪至 A 輪股權融資、敏捷專案孵化。 |

## 🏢 企業實戰案例：亞馬遜 1997 年傳奇商業計畫書與第一封致股東信

### 1. 傑夫·貝佐斯 (Jeff Bezos) 的創業推演
1994 年，貝佐斯在華爾街對沖基金 D.E. Shaw 擔任副總裁，看見全球網路以每年 2,300% 的驚人速度增長。他並未盲目辭職，而是撰寫了嚴密的商業計畫書：
- **為什麼選擇圖書？** 他深入分析了數十個商品品類，發現圖書具有全世界最龐大的 SKU（當時全球超過 300 萬種圖書），任何實體書店受限於貨架空間最多只能陳列數萬本，只有網路電商能打造「無窮庫存的萬種書店 (Earth's Biggest Bookstore)」。
- **財務架構設計**：在計畫書中，他精準預言了負現金循環週期 ($CCC < 0$) 的威力——顧客下單即用信用卡付款，而供應商結算期為 60 天，亞馬遜可以用供應商的營運資金無息擴張！

### 2. 成果與長遠影響
1997 年亞馬遜上市時，貝佐斯將計畫書中的核心承諾提煉為歷史性的《1997 致股東信》：**「一切圍繞長期價值 (It's All About the Long Term)」**。他拒絕迎合華爾街短期的每股盈餘預測，而是將所有現金流重新投入伺服器與物流中心，徹底驗證了商業計畫書作為「長期戰略定海神針」的偉大力量。

## ⚠️ 經理人常見盲點與治理陷阱

1. **「計畫即現實」的教條主義**：將商業計畫書當作不可更改的神聖教條，當市場環境已發生劇變、真實顧客反饋證明假設破滅時，依然機械式照本宣科執行，走向滅亡。
2. **過度依賴「曲棍球桿效應 (Hockey Stick Projections)」**：財務預測永遠是「前兩年微幅虧損，第三年營收與淨利突然以 90 度垂直飆升」，缺乏切實的進入市場 (GTM) 與獲客成本數據支撐，被經驗豐富的投資人一眼識破並直接丟入垃圾桶。
3. **厚重包裝掩蓋核心邏輯空白**：花費數十萬聘請顧問公司美化排版，通篇充斥宏觀產業大數據，卻說不清「產品究竟如何解決單一客戶的具體痛點」以及「第一批 100 個付費客戶從哪裡來」。

## 🎯 高階經理人決策檢核清單

- [ ] 商業計畫書的「執行摘要」是否能在 3 分鐘內抓住投資人與合作夥伴的眼球？
- [ ] 我們的市場規模計算，是基於真實客群單價自下而上 (Bottom-Up) 推導，還是粗放的全球人口比例？
- [ ] 財務預測中的營運開銷與招募計畫，是否與產品研發里程碑保持嚴密的時間軸同步？
- [ ] 我們是否在計畫書中坦誠披露了主要潛在風險（如法規障礙、巨頭競爭），並提供了務實的應變避險方案？
- [ ] 創辦團隊是否能脫稿、自信且邏輯嚴密地回答投資人針對計畫書中任何一行財務假設的質詢？
