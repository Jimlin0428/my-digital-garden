# 資本結構股權表動態演變 (Cap Table Evolution)

## 一、 核心概念與本質
- **Cap Table（Capitalization Table）**：記錄公司所有股東出資明細、證券類別、持股數、完全稀釋持股比例與期權池的動態總帳冊。
- **完全稀釋原則（Fully Diluted Basis）**：計算持股比率時，必須計入所有已核准之員工期權池（ESOP）、可轉換工具（SAFE / CB）轉換後之總股數。

## 二、 創投談判暗礁：期權池洗牌陷阱（The Option Pool Shuffle）
- **陷阱本質**：VC 要求在「投前估值（Pre-Money）」中設立或擴大 10%~15% 的 ESOP 期權池。
- **實質結果**：
  - 這 15% 的稀釋**完全由原始創始人單獨承擔**，VC 的新資金絲毫不承擔期權池稀釋；
  - 實質上等同於**變相壓低了實際投前估值**。
  - *解法*：爭取「投後設立期權池」或依據未來 12 個月精確招聘計畫擬定合理的期權額度。

## 三、 融資多輪演化常規
從 Seed 輪 ➔ A 輪 ➔ B 輪 ➔ C 輪 ➔ IPO，創始團隊持股比例常由 100% 稀釋至 15%~25%；然而，若企業估值持續倍增，創始人所持股份的「絕對市值」將實現幾何級數暴增。
