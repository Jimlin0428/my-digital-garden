# 實質選擇權估值模型 (Real Options Valuation Model)

## 一、 核心定義與本質
- **實質選擇權（Real Options）**是將金融市場的選擇權定價理論（如 Black-Scholes 或二項樹模型），應用於企業實體資本投資、新創經營與退場決策中的前沿評價工具。
- **本質與哲學**：
  傳統 DCF / NPV 假定管理層在決策後「坐以待斃」，低估了重大專案的真實價值。**實質選擇權承認：在面臨極高不確定性時，經理人擁有的「動態應變與經營彈性（Managerial Flexibility）」具備巨大經濟價值**。

$$\text{專案真實總價值 (Expanded NPV)} = \text{傳統靜態淨現值 (Static NPV)} + \text{實質選擇權溢價 (Option Premium)}$$

---

## 二、 三大核心實質選擇權類型

```text
【三大實質選擇權決策維度】

  1. 時機/延遲選擇權 (Option to Delay / Timing)
     • 相當於美式買權 (Call Option)：有權等待市場明朗化後再做巨額投資
  
  2. 規模擴張選擇權 (Option to Expand)
     • 相當於買權 (Call Option)：小規模試水成功後，有權加碼擴充產能

  3. 放棄/退出選擇權 (Option to Abandon / Exit)
     • 相當於賣權 (Put Option)：遭遇逆風時，有權清算資產回收殘值或中止虧損
```

## 三、 實務案例對標：星宇航空疫情決策實證
- **背景情境**：
  星宇航空（STARLUX）開航初期即遭逢 COVID-19 全球航線封鎖。傳統航空公司依固定承諾大量接收客機將面臨巨額維護折舊與現金斷裂；
- **實質選擇權具體操作**：
  1. **執行「時機／延遲選擇權」**：星宇並無貨運機隊，果斷將後續數十架客機交付時程往後遞延兩年，保全核心現金跑道；
  2. **執行「擴張選擇權」**：2022 年底各國解封、旅運需求爆發時，立即重啟新機交付並全力開闢北美與東南亞長程航線；
- **創投核心啟發**：
  **「如果沒有退出的機制，對於新創而言就沒有投資的價值！」** 退出選擇權（賣權）為投資人鎖定了下檔最大虧損，是高風險早期融資不可或缺的定價基石。
