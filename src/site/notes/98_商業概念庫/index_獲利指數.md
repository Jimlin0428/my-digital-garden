# 獲利指數 (Profitability Index, PI)

## 📌 概念核心定義

**獲利指數 (Profitability Index, 簡稱 PI)**，在資本預算與公共工程經濟學中亦常被稱為**現值指數**或**效益成本比 (Benefit-Cost Ratio, BCR)**，指一項投資專案在未來所產生的**全體預期現金流入現值總額，與初始現金投資支出現值之比率**。

如果說淨現值 (NPV) 衡量的是專案為股東創造財富的**「絕對金額規模」**，那麼獲利指數 (PI) 衡量的則是企業每投入一塊錢資本所能創造現金回報的**「資本配置相對效率 (Capital Efficiency)」**。在企業面臨剛性資本預算上限、無法投資所有正淨現值專案的**資本限額 (Capital Rationing)** 情境下，獲利指數是實現有限資本價值最大化的終極排序工具。

---

## 🔬 數理模型與核心計算公式

### 1. 獲利指數標準計算公式

$$PI = \frac{\text{未來現金流入現值總額 (PV of Future Cash Flows)}}{\text{初始投資金額 (Initial Investment } I_0)} = \frac{\sum_{t=1}^{n} \frac{CF_t}{(1 + WACC)^t}}{I_0}$$

### 2. 獲利指數與淨現值 (NPV) 的數學鏈接關係

由於淨現值定義為 $NPV = \text{PV of Inflows} - I_0$，因此獲利指數可直接轉化為：

$$PI = \frac{NPV + I_0}{I_0} = 1 + \frac{NPV}{I_0}$$

由此公式可推導出絕對的決策邊界準則：

```
┌─────────────────────────────────────────────────────────────┐
│ 【獲利指數 (PI) 核心決策判準】                              │
│                                                             │
│  • PI > 1.0  ⟺  NPV > 0  ──► 接受專案 (創造超額股東財富)    │
│  • PI = 1.0  ⟺  NPV = 0  ──► 損益打平 (剛好覆蓋資本成本)    │
│  • PI < 1.0  ⟺  NPV < 0  ──► 拒絕專案 (摧毀資本價值)        │
└─────────────────────────────────────────────────────────────┘
```

> [!NOTE]
> 獲利指數大於 1.0 的超額部分（即 $PI - 1$），精確代表了**「每投入 1 美元初始資本所產生的淨現值增額 (NPV per Dollar Invested)」**。例如 $PI = 1.35$，代表每投入 100 元，扣除資本成本後能替股東創造 35 元的淨財富。

## 📊 資本限額 (Capital Rationing) 下的 PI 排序優化機制

假設某跨國集團總部在當年度設定了嚴格的 **1,000 萬美元** 資本支出上限 (CapEx Ceiling)，現有五個可行的獨立候選專案：

| 專案代號 | 初始投資 ($I_0$) | 未來現金流入現值 | 淨現值 (NPV) | 獲利指數 ($PI$) | PI 優先順序 | 是否採納？ |
| :--- | :--- | :--- | :--- | :--- | :---: | :---: |
| **專案 A** | \$2,000,000 | \$3,000,000 | \$1,000,000 | **1.50** | **第 1 名** | ✅ 採納 (累積花費 \$2M) |
| **專案 B** | \$3,000,000 | \$4,200,000 | \$1,200,000 | **1.40** | **第 2 名** | ✅ 採納 (累積花費 \$5M) |
| **專案 C** | \$5,000,000 | \$6,500,000 | \$1,500,000 | **1.30** | **第 3 名** | ✅ 採納 (剛好滿額 \$10M) |
| **專案 D** | \$8,000,000 | \$9,600,000 | \$1,600,000 | **1.20** | 第 4 名 | ❌ 預算不足割捨 |
| **專案 E** | \$4,000,000 | \$4,400,000 | \$400,000 | **1.10** | 第 5 名 | ❌ 預算不足割捨 |

- **PI 排序組合收益**：採納專案 A + B + C，總投資剛好 1,000 萬美元，**創造總 NPV = \$1.0M + \$1.2M + \$1.5M = \$3,700,000**；
- **盲目按 NPV 排序的下場**：若經理人單看 NPV 絕對值，會優先選擇 NPV 最高的專案 D (\$1.6M) + 專案 A (\$1.0M)，總投資 1,000 萬美元，創造的總 NPV 僅有 **\$2,600,000**！
- **治理啟示**：在資本限額下，**PI 排序法多創造了整整 110 萬美元（42%）的股東財富！**

## 🏢 企業實戰案例：輝瑞 (Pfizer) 新藥管線研發的資本限額篩選

### 1. 商業背景
新藥研發涉及極其漫長的臨床試驗（一期、二期、三期），每種藥物研發成本動輒數億至十幾億美元。即使如輝瑞這般的製藥巨頭，每年可分配於新藥臨床推進的研發預算也是有限的剛性配額。

### 2. 獲利指數在庫存管線的應用
輝瑞研發委員會每年面對數十個通過臨床一期的候選分子化合物：
- 腫瘤新藥、罕見疾病藥物、心血管慢性病藥物各自具備不同的臨床成功機率與市場專利期營收；
- 財務團隊將臨床成功機率調整後的預期未來現金流折現，除以當前臨床二/三期所需的初始研發預算，為每一個新藥專案計算出專屬的 **PI 指數**；
- **成果**：透過 PI 排序，輝瑞將寶貴的臨床資源集中配置於高 PI 的前瞻標靶藥物與 mRNA 疫苗平台，最大化了每億美元研發資本的產出效益。

## ⚠️ 經理人常見盲點與治理陷阱

1. **在「互斥專案」中誤用 PI 進行二選一**：
   - 專案 X：投資 1 萬元，賺 2 萬元，$PI = 2.0, NPV = 1$ 萬元；
   - 專案 Y：投資 1,000 萬元，賺 1,500 萬元，$PI = 1.5, NPV = 500$ 萬元。
   - 若只能二選一，盲目選擇高 PI 的專案 X 將讓股東痛失 499 萬元的實體淨財富！**互斥專案永遠以 NPV 為唯一準繩！**
2. **忽略「資本分割不可分性 (Lumpiness of Capital)」**：在現實中，專案往往是不可分割的實體（如無法只蓋半座晶圓廠）。若按 PI 排序選到最後，剩餘預算不足以支應下一個專案，可能需要結合整數規劃手動微調組合。
3. **分母界定混亂**：將多期持續發生的營運資金投入誤計入分母的初始投資，導致 PI 人為失真。分母應嚴格限定為期初的淨資本承諾。

## 🎯 高階經理人決策檢核清單

- [ ] 本年度董事會是否有設定剛性的總體資本支出 (CapEx) 預算上限？
- [ ] 財務團隊在提交投資候選名單時，是否同時列報了各專案的 NPV 與獲利指數 (PI)？
