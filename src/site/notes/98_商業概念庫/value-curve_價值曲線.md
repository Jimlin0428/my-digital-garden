# 價值曲線 (Value Curve & Strategy Canvas)

## 一、 核心定義與本質

- **價值曲線 (Value Curve)** 是藍海策略理論（W. Chan Kim & Renée Mauborgne）中的核心診斷與策略行動工具。
- **策略草圖 (Strategy Canvas) 結構**：
  - **橫軸（X 軸）**：產業傳統競逐的「**關鍵競爭要素與投資指標**」（Key Factors of Competition）。
  - **縱軸（Y 軸）**：買方在各競爭要素上所獲得的「**給付水準**」（Offering Level，由低到高）。
- **本質**：將抽象的商業定位「視覺化」，精準刻劃出一家企業或整個產業標竿在各競爭維度上的資源配置與承諾強度。

---

## 二、 核心思維：打破取捨，實現「價值創新」

傳統邁克爾·波特（Michael Porter）的競爭戰略主張：企業必須在「[[98_商業概念庫/cost-leadership-strategy_成本領導策略\|成本領導]]」與「[[98_商業概念庫/differentiation-strategy_差異化策略\|差異化]]」之間進行嚴格的權衡取捨（Trade-off），否則將落入進退維谷（Stuck in the middle）。

**價值曲線則追求「價值創新 (Value Innovation)」**：
- **打破價值與成本的必然取捨（Value-Cost Trade-Off）**。
- 一邊透過剔除與壓低不必要的傳統要素來**大幅降低成本結構**；另一邊透過拉升與創造全新要素為買方**大幅躍升感知價值**。
- 達成「低成本」與「高差異化」雙輪驅動，開闢競爭對手難以模仿的全新藍海市場空間。

```
       【降低成本 (Cost Down)】
        消減同業過度競爭要素
               ▲
               │
        【價值創新 (Value Innovation)】 ──▶ 同時實現「高差異化」與「低成本」
               │
               ▼
       【提升價值 (Value Up)】
        創造前所未見的顧客效用
```

## 三、 分析操作工具：四項行動架構 (ERRC 矩陣)

重塑一條具備突破性價值的曲線，必須透過「四項行動架構 (Four Actions Framework)」嚴格檢視產業要素：

| 行動構面 | 核心策略提問 | 商業目的與成本效益 |
| :--- | :--- | :--- |
| **消除<br>(Eliminate)** | 產業中哪些被視為理所當然、但顧客其實不再重视或已過度供給的要素？ | **歸零不必要投入**，直接砍除繁重的固定與變動成本。 |
| **降低<br>(Reduce)** | 哪些要素因同業惡性軍備競賽而被過度設計，可以大幅降至產業平均以下？ | **壓制營運負擔**，避免陷入規格通膨的同質化紅海。 |
| **提升<br>(Raise)** | 哪些要素應大幅拉升至遠超產業標準的水準，以徹底解決顧客核心痛點？ | **構築卓越體驗**，釋放被壓抑的買方需求與滿意度。 |
| **創造<br>(Create)** | 產業從未提供過、能開拓新需求與吸引「非顧客 (Non-customers)」的全新要素是什麼？ | **開闢全新藍海**，確立定價權與第一品牌心智佔有率。 |

---

## 四、 優秀價值曲線的三大檢驗特徵

一條能夠有效指導企業獲利成長的價值曲線，必須通過三大質化檢驗標準：

1. **焦點 (Focus)**：曲線 profile 不會平均鋪平於所有維度，而是將資本重押在少數 2~3 個核心差異化要素上。
2. **差異化 (Divergence)**：曲線形狀與傳統同業或產業平均曲線顯著脫鉤，呈現截然不同的高低起伏，而非平行的規格升級。
3. **令人信服的標語 (Compelling Tagline)**：策略草圖清晰易懂，能直觀轉化為一句簡潔有力、直擊客戶心智的市場價值主張（Value Proposition）。

## 五、 經典實證對標案例

### 1. 太陽馬戲團 (Cirque du Soleil)
- **消除**：動物表演、明星小丑、三環舞台（消滅高昂保險、動物飼育與天價片酬成本）。
- **降低**：驚險刺激與純喧鬧趣味。
- **提升**：單一帳篷環境質感與舒適座椅。
- **創造**：戲劇故事情節、精緻藝術舞蹈、原創現場交響音樂，成功將目標顧客由兒童轉向願意支付百老匯高票價的成人與企業商務客。

### 2. 西南航空 (Southwest Airlines)
- 與傳統樞紐輻射航網巨頭（Delta / United）對標：
  - **消除**：餐飲服務、座位預劃、貴賓室、跨航空行李直掛。
  - **降低**：票價（降至接近汽車旅行水準）。
  - **提升**：班機起飛頻率、友善服務態度。
  - **創造**：二級機場點對點直飛（如同搭乘長途客運般便捷），大幅縮短地面週轉時間（Turnaround Time < 25 分鐘）。
