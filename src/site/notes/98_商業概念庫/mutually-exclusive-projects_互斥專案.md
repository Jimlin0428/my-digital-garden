# 互斥專案 (Mutually Exclusive Projects)

## 📌 概念核心定義

在資本預算與長期策略決策中，**互斥專案 (Mutually Exclusive Projects)** 指一組**在物理工程、地理空間、商業定位或法律合約上具備「排他性 (Exclusivity)」的投資方案**。在這組備選專案中，**一旦採納了其中一個方案，其餘所有方案將自動被排除放棄（即「非 A 即 B」、「二選一或多選一」的零和選擇）**。

與獨立專案只需評估「自身賺不賺錢（通過/否決）」不同，互斥專案的核心任務在於**「比較與最優排序 (Ranking)」**。在評估互斥專案時，財務管理理論中最著名的世紀衝突——**淨現值法 (NPV) 與內部報酬率法 (IRR) 的排序衝突**——將全面浮出水面，直接拷問企業高階管理層對於「股東財富最大化」底層本質的認知。

---

## 🔬 理論架構：NPV 與 IRR 的排序衝突根源

在評估互斥專案時，經常出現「專案 A 的 NPV 高於專案 B，但專案 B 的 IRR 卻遠高於專案 A」的矛盾窘境。引發此衝突的兩大根本工程經濟原因為：

```
                    【互斥專案排序衝突的兩大根源】
                               │
         ┌─────────────────────┴─────────────────────┐
【根源一：投資規模差異 (Scale Difference)】   【根源二：現金流時序差異 (Timing Difference)】
 專案 A: 投入 $1,000, 賺 $2,000 (IRR=100%)    專案 A: 前期微量現金流入，後期爆發式巨額流入
 專案 B: 投入 $100, 賺 $300 (IRR=200%)        專案 B: 前期迅速回收現金，後期幾無流入
       │                                            │
       ▼                                            ▼
 規模小的 B 報酬率極高，但創造財富極小        折現率變動會引發貼現敏感度巨震
 (賺 200 元 vs. 賺 1,000 元的本質差距)        (由 [[fisher-intersection_費雪交叉點]] 觸發逆轉)
```

### 1. 衝突仲裁之鐵律：NPV 永遠具備最高仲裁權

當互斥專案的 NPV 與 IRR 給出相反的推薦時，**管理團隊必須 100% 無條件選擇 NPV 最高的專案！**
- **股東財富的實質度量**：股東在資本市場上消費或再投資的是**「實體貨幣的絕對增量 (Dollars of Wealth)」**，而非單純的「百分比率 (Percentage Rate)」；
- **再投資報酬率假設 (Reinvestment Rate Assumption)**：
  - **IRR 法則的致命缺陷**：IRR 隱含假設專案收回的中期現金流能以**極高的「IRR 本身」**進行再投資（這在現實中幾乎不可能長期達成）；
  - **NPV 法則的客觀理性**：NPV 假設中期現金流僅以**市場客觀的「資本成本 (WACC)」**進行再投資，符合資本市場真實供需。

### 2. 差額現金流量分析 (Incremental Cash Flow Analysis)

為了讓 IRR 能正確應用於互斥專案，財務長必須將兩專案相減，構造「差額專案 (Project $\Delta = A - B$)」：

$$CF_{\Delta, t} = CF_{A, t} - CF_{B, t}$$

計算差額內部報酬率 ($IRR_\Delta$)：
- 若 $IRR_\Delta > WACC$，代表「額外增加的投資規模或時間等待」所獲得的邊際回報超過資金成本，應選擇規模較大或期限較長的**專案 A**；
- 此 $IRR_\Delta$ 在數理上恰好等於兩專案的**費雪交叉點 ([[fisher-intersection_費雪交叉點]])**！

## 📊 互斥專案決策衝突圖解 (NPV Profile)

```
淨現值 NPV ($)
   ▲
   │  NPV 曲線 (專案 A - 規模大/長天期/高利率敏感)
   │  ＼
   │     ＼
   │        ＼     NPV 曲線 (專案 B - 規模小/短天期/低利率敏感)
   │           ＼   ／
   │            【★ 費雪交叉點 (Crossover Rate r*)】
   │             ／ ＼
   │          ／       ＼
   │       ／             ＼
   0 ────┴─────────┴───────┴──────────────► 折現率 (Discount Rate r)
       WACC_1     r*      IRR_B    IRR_A
     (NPV_A>NPV_B)     (NPV_B>NPV_A)
```

- **當 $WACC < r^*$ 時**：資本成本低廉，應選擇淨現值較高的**專案 A**（此時 IRR 指標失效）；
- **當 $WACC > r^*$ 時**：資本成本高昂，市場偏好早期快速回本，應選擇**專案 B**。

## 🏢 企業實戰案例：波音公司新機型產線決策的互斥博弈

### 1. 商業情境
波音公司在評估西雅圖長榮工廠的重大產能配置時，面對同一塊有限組裝廠房與特定工程團隊，面臨兩項互斥專案：
- **方案 A（全面研發全新中型客機 NMA）**：需投入 150 億美元資本支出，技術難度極高，預期生命週期長達 25 年，計算得出 $IRR = 14\%, NPV = 60\ \text{億美元}$。
- **方案 B（針對現有 737 MAX 進行航電小幅升級改款）**：僅需投入 25 億美元，快速投產，計算得出 $IRR = 28\%, NPV = 28\ \text{億美元}$。

### 2. 經理人的互斥抉擇與治理教訓
- 若單純看投資報酬率，方案 B 的 IRR 高達 28%，看似極其誘人；
- 但方案 A 的 NPV 創造的股東財富增額（60 億美元）是方案 B（28 億美元）的兩倍以上！
- 當時波音高層過度聚焦於短期的資本回報率與回本速度，放棄了全新的架構研發，選擇了妥協改款，最終埋下了後續軟體系統與產線品管的歷史性危機。

---

## ⚠️ 經理人常見盲點與治理陷阱

1. **落入「高 IRR 幻覺」而放棄巨額財富**：經理人受限於短視考核，偏愛選擇投資僅需 1,000 萬元但 IRR 高達 80% 的微型專案，而否決了投資 2 億元、IRR 為 25% 但能為公司帶來數千萬元純利潤的宏大專案。
2. **忽視「生命週期長度不對稱」的致命比較錯誤**：當專案 A 耐用年限為 3 年，專案 B 耐用年限為 10 年時，直接比較兩者的累計 NPV 是完全錯誤的！必須採用**等額年金法 ([[equivalent-annual-annuity_等額年金法]])** 或重置鏈模型進行標準化歸一處理。
3. **沉沒成本干擾互斥決策**：在評估自建廠房還是租賃現有廠房時，將過去五年花費於地質探勘的已發生款項計入自建成本，扭曲了兩者的真實增額效益。

## 🎯 高階經理人決策檢核清單

- [ ] 本組專案的排他性是源於物理資源限制、市場容量上限，還是內部工程帶寬的局限？
- [ ] 當財務團隊報告 NPV 與 IRR 排序衝突時，我們是否堅定貫徹了「以淨現值 (NPV) 最大化為唯一準繩」的原則？
- [ ] 我們是否針對這兩項專案進行了「差額現金流量分析」，並精準計算出費雪交叉點 ($r^*$)？
- [ ] 公司的實際加權平均資本成本 (WACC)，究竟座落於費雪交叉點的左側還是右側？
- [ ] 互斥專案的耐用年限是否一致？若不一致，是否已採用等額年金法 (EAA) 消除年限偏誤？
