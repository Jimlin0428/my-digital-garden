# 三方競合賽局模型 (Three-Player Coopetition Game)

## 一、 核心定義與本質
- **三方競合賽局模型（Three-Player Game）**分析由三個關鍵實體構成之競合網絡在利益衝突、策略聯盟與權力制衡下的動態演化。
- **結構穩定性法則（Structural Balance Theory）**：
  網絡穩定性取決於各節點之間關係符號（$+$ 代表合作，$-$ 代表競爭）的連乘積。

---

## 二、 平衡型 vs. 失衡型結構

```text
【三方競合網絡結構對比】

    【平衡型架構 A】                   【平衡型架構 B】                   【失衡型架構 (結構脆弱)】
       廠商 A                            廠商 A                            廠商 A
       /    \                            /    \                            /    \
     +       +                         -       -                         +       +
     /   +    \                        /   +    \                        /   -    \
  廠商B ─── 廠商C                   廠商B ─── 廠商C                   廠商B ─── 廠商C
  (三方全體合作，聯盟穩固)           (敵人的敵人是朋友，聯手抗敵)       (左右逢源，B與C聯手排擠A)
```

1. **平衡型網絡（穩固均衡）**：
   - 形態一：全體合作（$+, +, +$），乘積為正；
   - 形態二：兩大競爭者共同與第三方互補者合作（$-, -, +$），乘積為正（「敵人的敵人就是朋友」）；
2. **失衡型網絡（脆弱崩解）**：
   - 代工大廠（A）試圖同時為兩大敵對巨頭（B 與 C）代工，乘積為負（$+ , +, -$）；B 與 C 擔心技術機密外洩，將聯手施壓或自建產能。

## 三、 實務案例對標
- **Marvell、Lumentum 與 NVIDIA 之光通訊三角賽局（Class 8 即時案例）**：
  Marvell 擬收購光引擎大廠 Lumentum 整合矽光子（CPO）；此舉引發大客戶 NVIDIA 警惕，三方在晶片架構、光模組採購與系統整合控制權上展開了典型的三方平衡與制約博弈。
