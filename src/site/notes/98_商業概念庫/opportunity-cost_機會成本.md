# 機會成本 (Opportunity Cost & Economic Value Architecture)

> **【核心決策摘要】**
> **機會成本（Opportunity Cost）** 是經濟學與商業決策中最基石的概念，指在面對稀缺資源與多項互斥方案（Mutually Exclusive Options）時，**為了採取某特定行動方案所放棄的所有替代選擇中，「價值最高者（Highest-Valued Alternative Forgone）」之預期收益**。機會成本體現了「天下沒有白吃的午餐」的資源配置本質。在公司理財中，**會計利潤（Accounting Profit）僅計入顯性成本（Explicit Costs），而經濟利潤（Economic Profit）則必須全額扣除包含資本機會成本的隱性成本（Implicit Costs）**。在資本預算決策中，任何被指派給新專案的既有廠房、土地、產能或高階人力，皆必須按其最佳替代用途之市場變現值或外部租金計入[[98_商業概念庫/zeng-e-cash-flow_增額現金流量\|增額現金流量]]，絕非免費資源。

---

## 1. 概念核心定義與經濟利潤模型 (Executive Definition & Economic Profit)

### 1.1 核心定義
機會成本被嚴格定義為：**將稀缺資源（資本、勞動力、土地、時間、管理注意力）配置於特定用途時，所犧牲的次佳替代用途（Next-Best Alternative）之淨收益**。

```
                  ┌────────────────────────────────────────────────────────┐
                  │              會計利潤 vs. 經濟利潤對照圖譜             │
                  └───────────────────────────┬────────────────────────────┘
                                              ▼
        ┌────────────────────────────────────────────────────────────────────────┐
        │ 企業總營業收入 (Total Revenue: $1,000 萬)                              │
        ├────────────────────────────────────────────────────────────────────────┤
        │ 顯性成本 (Explicit Costs: 原料、工資、租金、利息) ──▶ $700 萬          │
        ├────────────────────────────────────────────────────────────────────────┤
        │ 📊 【會計利潤 (Accounting Profit)】 = $1,000 萬 - $700 萬 = $300 萬     │
        ├────────────────────────────────────────────────────────────────────────┤
        │ 隱性成本 / 機會成本 (Implicit Costs: 股東權益機會成本、廠房租金放棄) ─▶ $350萬 │
        ├────────────────────────────────────────────────────────────────────────┤
        │ 📉 【經濟利潤 (Economic Profit)】 = $300 萬 - $350 萬 = -$50 萬 ❌      │
        │    (實質上正在毀滅股東資本價值，資本回報低於外部市場機會成本)          │
        └────────────────────────────────────────────────────────────────────────┘
```

### 1.2 會計利潤 vs. 經濟利潤公式
$$\text{Accounting Profit} = \text{Revenue} - \text{Explicit Costs}$$
$$\text{Economic Profit} = \text{Revenue} - (\text{Explicit Costs} + \text{Implicit Opportunity Costs})$$

- 若 $\text{Economic Profit} > 0$：企業創造了**超額經濟租金（Economic Rents）**，資源配置優於市場平均。
- 若 $\text{Economic Profit} = 0$：企業獲得**正常利潤（Normal Profit）**，資本報酬率恰好等於外部投資機會的必要報酬率（即 $ROIC = WACC$）。
- 若 $\text{Economic Profit} < 0$：即便會計帳面獲利，企業實質上正在浪費資源，應考慮清算或重組。

## 2. 資本預算與戰略決策中的機會成本實踐 (Capital Budgeting Applications)

高階管理層在評估重大資本支出時，最常忽視以下三大隱性機會成本：

1. **閒置資產再利用的「非零成本」原則**：
   - *常見誤區*：專案經理向董事會呈報：「我們使用公司五年前買下但目前閒置的廠房，因此該專案無廠房成本。」
   - *PMBA 規範校準*：若該廠房當前可按市場行情以每年 2,000 萬元出租，或以 3 億元出售，則在專案的增額現金流評估中，**必須將放棄的租金或處分收入列為專案的現金流出（機會成本）**。
2. **營運資金（NWC）與資本成本（WACC）**：
   - 投入存貨與應收帳款的每一塊錢淨營運資金，皆無法用於購買無風險國債或發放股利。[[wacc_加權平均資本成本|WACC（加權平均資本成本）]]的本質，即為企業全體投資人（股東與債權人）在同等風險水準下要求之**最低機會成本**。
3. **管理層注意力與組織帶寬稀缺（Executive Bandwidth）**：
   - 企業推動一項中型併購或創新專案，往往佔用 CEO 與核心團隊 40% 的時間。此時最沉重的機會成本並非顧問費，而是高層無暇顧及本業核心防線，導致主力市場遭競品侵蝕的潛在損失。

## 3. 機會成本 vs. 沉沒成本 對照解析 (Opportunity vs. Sunk Costs)

| 比較維度 | 機會成本 (Opportunity Cost) | 沉沒成本 (Sunk Cost) |
| :--- | :--- | :--- |
| **時間維度** | **面向未來（Forward-Looking）** | **屬於過去（Backward-Looking）** |
| **現金流屬性** | 放棄的最佳未來潛在現金流入 | 已經發生、無法逆轉的歷史現金流出 |
| **決策相關性** | **100% 絕對相關**（必須嚴格計入） | **0% 完全無關**（必須堅決剔除） |
| **高階決策指引** | 每一項資產的投入都必須戰勝其市場次佳用途 | 勿因「已投入太多心血」而向無效專案追加資源 |
