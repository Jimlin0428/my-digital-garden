# 期望理論 (Expectancy Theory / VIE Theory)

> [!NOTE]
> **核心概念精粹**：期望理論（Expectancy Theory / VIE Theory），是由耶魯大學組織心理學大師維克多·弗魯姆（Victor H. Vroom）於 1964 年在《工作與激勵》中確立的經典認知型激勵模型。弗魯姆主張：個體是否願意全力以赴投入工作，取決於三大心理變數的連乘積——**期望值（Expectancy, $E \to P$）**、**關聯性／工具性（Instrumentality, $P \to R$）**與**效價（Valence, $V$）**。乘數效應決定了：**只要其中任何一項心理感知趨近於零，整體的激勵動機將徹底歸零！**

---

## 一、 學理公式與三大心理變數乘數模型

弗魯姆徹底打破了「給錢就能激勵一切」的機械行為主義假定，將激勵建立在精密的**個體認知預期**之上：

$$\text{Motivation Force (動機力量 } M) = \text{Expectancy (期望值 } E) \times \text{Instrumentality (工具性 } I) \times \text{Valence (效價 } V)$$

### 期望理論三大變數深度定義

| 變數符號 | 變數名稱與心理提問 | 心理感知範疇與數值區間 | 經理人管理破局關鍵 |
| :--- | :--- | :--- | :--- |
| **$E$ (Expectancy)** | **努力 $\to$ 績效期望值**<br>「如果我全力以赴，我真的能達成這個目標嗎？」 | **機率感知 ($0 \le E \le 1$)**。<br>若目標設定過高被視為天方夜譚，$E \to 0$。 | 培訓賦能、提供必要資源、排除外在不可抗力障礙、合理設定 SMART 目標。 |
| **$I$ (Instrumentality)** | **績效 $\to$ 獎酬工具性**<br>「如果我達成了目標，公司真的會兌現諾言獎勵我嗎？」 | **相關性感知 ($0 \le I \le 1$ 或 $-1 \le I \le 1$)**。<br>若制度不公或畫大餅不兌現，$I \to 0$。 | 建立透明客觀的審計考核、領導者言行一致、說到做到堅守承諾（誠信）。 |
| **$V$ (Valence)** | **獎酬 $\to$ 個人目標效價**<br>「組織發給我的這份獎勵，是我內心真正想要的嗎？」 | **偏好強度 (負值 $\sim 0 \sim$ 正值)**。<br>若是部屬毫無興趣的獎品，$V \to 0$ 甚至為負。 | 了解員工客製化需求，提供彈性福利菜單（如升遷、出國培訓、特休假或現金）。 |

## 二、 乘數效應（Multiplier Effect）引發的激勵猝死陷阱

期望理論最重要的管理學洞見在於其**「乘法法則（Multiplicative Rule）」**而非加法：

$$\text{若 } E = 0 \text{ 或 } I = 0 \text{ 或 } V = 0 \implies \text{Motivation } M = 0$$

```carousel
![期望理論激勵猝死案例](/images/expectancy_theory_fails.png)
<!-- slide -->
### 陷阱 1：$E \to 0$（目標不切實際，部屬徹底躺平）
- **情境**：在景氣衰退時期，銷售主管強行要求業務團隊「下季營收翻倍，否則無獎金」；
- **心理機制**：即便獎金高達數百萬元（$V$ 極高），且公司從不賴帳（$I$ 極高），但業務員心知肚明「無論自己多拼命，客觀上絕對不可能達成」（$E = 0$）；
- **結果**：團隊陷入集體習得性無助（Learned Helplessness），全員放棄抵抗直接躺平。
<!-- slide -->
### 陷阱 2：$I \to 0$（信任崩塌，老闆畫餅成空）
- **情境**：工程師沒日沒夜加班一年完成艱難專案，年底公司營收大好，老闆卻以「大環境艱困、共體時艱」為由，將原本承諾的乾股分紅降為一盒水果禮盒；
- **心理機制**：員工對自己能力有信心（$E$ 高），但對「績效能否換取回報」的信任徹底粉碎（$I = 0$）；
- **結果**：核心技術骨幹在農曆年後集體跳槽至競爭對手。
<!-- slide -->
### 陷阱 3：$V \to 0$（給錯獎勵，熱臉貼冷屁股）
- **情境**：公司對年度最佳員工的獎勵是「與董事長共進午餐」或「一面印有公司標誌的精美錦旗」；
- **心理機制**：基層年輕員工背負房貸與生活壓力，最渴望的是實質現金獎金或彈性帶薪假；對他們而言，和威嚴的董事長吃午餐不是獎勵，而是如坐針氈的懲罰（$V \le 0$）；
- **結果**：激勵力量歸零，甚至引發內部嘲諷。
```

## 三、 經典企業實戰案例：微軟銷售團隊的「雲端轉型激勵重組」

- **轉型痛點**：2014 年納德拉推動微軟轉向雲端 Azure 時，傳統業務團隊習慣販售每套數十萬美元的高額套裝軟體（Windows / Office 永久授權），極度抗拒推銷每月幾百美元的雲端訂閱；
- **期望理論精準手術**：
  - **修復 $E$（期望值）**：為業務員配備專業的「雲端架構解決方案專家（CSA）」陪同拜訪客戶，降低業務員因不懂底層技術而無法簽單的恐懼（提升 $E$ 至 0.8 以上）；
  - **修復 $I$（工具性）**：建立全自動即時業績儀表板，客戶每消耗 1 美元雲端算力，提成佣金次月準時入帳，消除審批遲延（建立 $I = 1.0$ 的鋼鐵信任）；
  - **拉滿 $V$（效價）**：將雲端業務的佣金比率設定為傳統軟體的 3 倍，並與快速晉升掛鉤（極大化 $V$）；
- **成果**：全體銷售軍團在半年內自發全員轉型，推動 Azure 營收實現連續數年超過 50% 的爆發性增長。

## 四、 經理人期望激勵模型審計檢核表（Executive Decision Checklist）

在制定年度考核指標、銷售提成方案或激勵專案前，領導者應依序檢驗下列問題：

- [ ] **期望值賦能檢驗（Expectancy Feasibility Check）**：
  - 我們指派給部屬的績效目標，在客觀上是否有至少 70%~80% 的達成可能性？我們是否提供了足夠的工具、預算與培訓，讓部屬發自內心相信「只要我全力以赴，我就能做到」？
- [ ] **承諾兌現信譽審計（Instrumentality Credibility Audit）**：
  - 歷史上記錄中，公司是否有過「以各種合約細節苛扣或延遲發放承諾獎金」的不良前科？員工是否普遍相信「考核結果與獎勵兌現具有絕對透明的因果關係」？
- [ ] **彈性獎酬菜單設計（Cafeteria-Style Valence Maximization）**：
  - 我們的激勵手段是否過於單一陳舊？我們是否提供了多元彈性的獎勵選項（如額外帶薪年假、領導高階專案的機會、職稱晉升、現金獎勵），由員工根據個人生命週期偏好自主選擇？
- [ ] **全流程即時反饋閉環（Real-Time Feedback Loop）**：
  - 員工能否即時看見自己的努力向績效轉化的進度？還是必須苦等一年到年底才能得知自己是否達標？（反饋週期越長，期望值與工具性越容易衰減）。
