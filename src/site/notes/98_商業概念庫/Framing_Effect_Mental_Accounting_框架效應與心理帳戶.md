# 框架效應與心理帳戶 (Framing Effect & Mental Accounting)

## 一、 核心定義與理論本質
- **框架效應（Framing Effect）**由 Amos Tversky 與 Daniel Kahneman 於 1981 年「亞洲疾病問題」中提出，指同一個客觀問題，僅僅因為語言描述的「表述架構（正面獲利 vs. 負面損失）」不同，就會徹底逆轉決策者的風險偏好。
- **心理帳戶（Mental Accounting）**由理查·塞勒（Richard Thaler，諾貝爾經濟學獎得主）開創，指人們在心理上會根據財富的來源、形式與用途，將金錢劃分到不同的虛擬帳戶中進行非理性管理，打破了古典經濟學「金錢具備完全可替代性（Fungibility）」的基本假設。

## 二、 理論模型：展望理論 (Prospect Theory) S型價值函數

```
        價值感受 V(x)
              ▲
              │                 獲利領域 (Gains)
              │               ┌───────────────────
              │              /  【風險規避】(Risk Averse)
              │             /   • 凹函數：邊際效用遞減
              │            /    • 寧取確定的 1,000 元，
              │           /       不賭 50% 機率得 2,000 元
──────────────┼──────────/────────────────────────────► 客觀得失 (x)
 損失領域     /│
 (Losses)    / │
 【風險追逐】/  │
 (Risk-    /   │
  Seeking)/    │
 ────────/     │
 • 凸函數      │
 • 損失痛苦斜率是獲利的 2~2.5 倍！(損失厭惡 Loss Aversion)
 • 面對確定損失 1,000 元，寧賭一把 50% 賠 2,000 元但 50% 沒事！
```

## 三、 商業運作機制與動態意涵
1. **框架操控（Framing Manipulation）**：
   - 宣傳「手術成功率 90%」➔ 大多數病患欣然接受（獲利框架，擁抱確定性）；
   - 宣傳「手術死亡率 10%」➔ 大多數病患恐慌拒絕（損失框架，激發恐懼）。
2. **心理帳戶的非理性分割**：
   - **意外之財帳戶（House Money）**：年終獎金或彩券中獎，花起來毫無節制；
   - **辛苦血汗帳戶**：本薪收入一分一毫錙銖必較；
   - 課堂教授案例：弄丟 200 元現金會心疼一整天，但若遺失 200 元演唱會門票，往往會在門口毫不猶豫再掏錢買一張。

## 四、 實務案例與產學實證
- **卡特賽車中出賽派的「賭徒心態」**：個案描述一直在強調「不出賽必定損失百萬贊助、面臨解散」，這將所有學員強行塞入了**「極端損失框架」**！在損失框架下，人類大腦會下意識轉變為**「極端風險追逐者（Risk Seeking）」**，哪怕只有一絲希望，也寧願賭一把發動機會不會爆掉。
- **企業變革的溝通話術**：推動數位轉型時，若強調「做轉型能增加 10% 利潤」（獲利框架），各部門多半冷漠觀望；若強調「不轉型三年內將流失 30% 現有核心客戶並被市場淘汰」（損失框架），全員的急迫感與變革動力將瞬間飆升。

## 五、 投資決策與高階經理人啟示
1. **警惕套牢時的「賭徒加碼」陷阱**：散戶在虧損時最容易被損失框架支配，拒絕認賠止損，反而向下攤平，這本質上是在追求高風險以企圖扳平損失。
2. **決策前強制進行「雙向框架轉換」**：高階經理人在拍板重大專案前，必須將提報案以「獲得框架」和「失去框架」分別重寫一遍，檢驗自己的結論是否僅是由文字修辭所催眠的產物。
