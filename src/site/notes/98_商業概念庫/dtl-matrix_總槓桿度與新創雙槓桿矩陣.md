# 總槓桿度與新創雙槓桿矩陣 (Degree of Total Leverage, DTL)

## 一、 核心定義與本質
- **總槓桿度（Degree of Total Leverage, DTL，或稱 DCL）**衡量企業銷售量（$Q$）微幅變動時，所引發每股盈餘（EPS）變動的百分比敏感度。
- **本質與數理連動**：
  總槓桿是**「營業風險（營運槓桿 DOL）」**與**「財務風險（財務槓桿 DFL）」**的乘數結合。它反映了企業從頂層營收到底層股東淨利所承受的總體經營與融資波動性。

$$\text{DTL} = \text{DOL} \times \text{DFL} = \frac{\% \Delta \text{EPS}}{\% \Delta Q}$$

---

## 二、 代數推導與公式架構
設產品單價為 $P$、單位變動成本為 $V$、現金固定成本為 $FC$、利息費用為 $I$：

$$\text{DOL} = \frac{\text{邊際貢獻}}{\text{營業利益}} = \frac{Q(P - V)}{Q(P - V) - FC}$$

$$\text{DFL} = \frac{\text{營業利益}}{\text{稅前利益}} = \frac{\text{EBIT}}{\text{EBIT} - I} = \frac{Q(P - V) - FC}{Q(P - V) - FC - I}$$

相乘得出總槓桿度核心公式：

$$\text{DTL} = \frac{Q(P - V)}{Q(P - V) - FC - I}$$

---

## 三、 新創雙槓桿矩陣與斜率風險判讀

```text
【新創 vs. 產業平均雙槓桿風險斜率】

  營運槓桿 (DOL)
   ▲
   │            / 新創企業斜率 (極度陡峭，高固定研發與租金成本)
   │           /
   │          /
   │         /  / 產業成熟企業平均斜率
   │        /  /
   │       /  /
   │      /  /
   └─────┴──┴────────────────────────────────► 財務槓桿 (DFL)
```

- **新創致命陷阱**：
  新創企業早期固定研發與人事成本佔比極高，本業營運槓桿（DOL）天生龐大；若此時創辦人又貿然舉借高額固定利息債務（拉高 DFL），總槓桿 DTL 將呈指數級放大。稍遇市場需求降溫，企業將以不可逆速度墜入破產清算。
