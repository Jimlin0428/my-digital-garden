# Philip Kotler 五個產品層次模型 (Five Product Levels)

> **商管核心價值**：產品不僅是有形實體，更是層層包裹的顧客價值載體。科特勒五層模型引導經理人從「顧客核心痛點」出發，逐層構建基本功能、期望標準、擴增服務與未來演進，是產品差異化與打造超額定價溢價的架構指南。

---

## 一、 核心定義與五層架構

```text
               ┌────────────────────────────────────────────────────────┐
               │ 5. 潛在產品 (Potential Product)：未來的轉型與新可能     │
               │  ┌──────────────────────────────────────────────────┐  │
               │  │ 4. 擴增產品 (Augmented Product)：超越期望的附加服務│  │
               │  │  ┌────────────────────────────────────────────┐  │  │
               │  │  │ 3. 期望產品 (Expected Product)：起碼認定具備 │  │  │
               │  │  │  ┌──────────────────────────────────────┐  │  │  │
               │  │  │  │ 2. 基本產品 (Basic Product)：有形實體 │  │  │  │
               │  │  │  │  ┌────────────────────────────────┐ │  │  │  │
               │  │  │  │  │ 1. 核心產品 (Core Benefit)：利益│ │  │  │  │
               │  │  │  │  └────────────────────────────────┘ │  │  │  │
               │  │  │  └──────────────────────────────────────┘  │  │  │
               │  └──────────────────────────────────────────────────┘  │
               └────────────────────────────────────────────────────────┘
```

1. **核心產品 (Core Benefit)**：顧客購買該產品所追求的最根本利益或想要解決的終極問題（如化妝品追求「美麗與自信」；口紅不是買化學物質）。
2. **基本產品 (Basic Product)**：將核心利益具體化為最起碼的有形實體結構或功能規格（如洗衣機的馬達與清洗槽）。
3. **期望產品 (Expected Product)**：顧客在購買時，習慣上認定「理所當然應具備」的屬性與條件（如乾淨飯店床單、無異味、安靜低噪音）。
4. **擴增產品 (Augmented Product)**：超越顧客預期、能將自身與競爭同業鮮明區隔的額外服務與附加價值（如保固承諾、到府安裝、AppleCare+）。**此層為打造 10%~20% 溢價的核心**！
5. **潛在產品 (Potential Product)**：該產品在未來可能經歷的所有演化、技術整合與全新功能延展（如 AI 影像辨識髒污自動投放洗劑）。

---

## 二、 產業實務與經理人決策

- **工業品 vs. 消費品**：在純工業產品中，基本產品常高度趨近於核心產品（如規格符合之晶圓）；而在消費品中，擴增產品與潛在產品往往是決定品牌忠誠度與定價特權的關鍵。
- **溢價打造階梯**：企業若僅停留在第 1~3 層，只能陷入同質化價格戰；唯有持續深耕第 4 層（擴增服務）並佈局第 5 層（潛在轉型），才能建立結構性護城河。
