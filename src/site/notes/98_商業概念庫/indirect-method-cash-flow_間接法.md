# 間接法 (Indirect Method)

> **【概念導航與對齊】**
> **間接法（Indirect Method）** 是全球 98% 以上上市公司編制「營業活動現金流量表（CFO）」的法定標準方法。其核心在於從損益表的**會計淨利（Net Income）** 出發，反向加回非現金費用（如 D&A、SBC）、剔除非營業損益，並調整各項**非現金流動資產與流動負債變動額（$\Delta\text{Operating Working Capital}$）**，以揭示會計利潤與真實硬現金之間的轉化效率。
