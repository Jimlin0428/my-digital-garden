# 成長機會現值 (Present Value of Growth Opportunities, PVGO)

## 一、 核心定義與數理拆解
- **核心定義**：在資本市場評價架構下，企業每股股價（$P_0$）可解構為「**靜態零成長現金牛年金價值**」與「**動態未來再投資成長機會現值（PVGO）**」：
  $$P_0 = rac{	ext{EPS}_1}{r_e} + 	ext{PVGO}$$
  - $rac{	ext{EPS}_1}{r_e}$：假設企業不再進行任何資本擴張，將每期盈餘 100% 發放股利時的永續年金現值；
  - $	ext{PVGO}$：企業未來所有預期淨現值（$NPV > 0$）擴張專案的超額回報加總現值。

## 二、 價值創造之判讀準則
$$	ext{PVGO} \propto (	ext{ROE} - r_e)$$

| 條件判別 | PVGO 狀態 | 資本配置本質 | 經理人行動指引 |
| :--- | :---: | :--- | :--- |
| **$	ext{ROE} > r_e$** | **$	ext{PVGO} > 0$** | **價值創造 (Value Creation)** | 再投資收益高於資本成本，保留盈餘擴張能為股東創造財富。 |
| **$	ext{ROE} = r_e$** | **$	ext{PVGO} = 0$** | **價值中立 (Value Neutral)** | 營收規模放大但無法推升股價，資本支出與分紅無異。 |
| **$	ext{ROE} < r_e$** | **$	ext{PVGO} < 0$** | **價值毀滅 (Value Destruction)** | 盲目擴張正在摧毀股東價值！應立即停止投資，將現金返還股東。 |

## 三、 本益比（P/E Ratio）結構剖析
$$rac{P_0}{	ext{EPS}_1} = rac{1}{r_e} + rac{	ext{PVGO}}{	ext{EPS}_1}$$
- 高科技成長股（如台積電、輝達）的高本益比，本質上反映的是市場對其未來巨額 PVGO 的信心溢價。
