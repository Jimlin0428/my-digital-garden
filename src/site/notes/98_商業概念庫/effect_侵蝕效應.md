# 侵蝕效應 (Erosion Effect / Cannibalization)

## 📌 概念核心定義

在資本預算與新產品投資決策中，**侵蝕效應 (Erosion Effect)**，在行銷策略與組織經濟學中亦常稱為**自我蠶食 (Cannibalization)** 或**附帶副作用 (Incidental Cash Flow Effects)**，指企業在推出一項全新的產品、開闢新通路或設立新門市時，**由於分流了原本屬於企業內部既有老產品或現有通路的顧客，導致現有業務的銷售量、營業收入與現金流量發生實質萎縮的負向外溢衝擊**。

侵蝕效應是增額現金流分析 (Incremental Cash Flow Analysis) 中最微妙但也最致命的關鍵維度。若財務團隊在評估新專案時忽視侵蝕效應，會產生**盲目樂觀的虛假高估**；然而，若機械式地將所有被分流的營收全數作為新產品的懲罰成本，又會引發**因恐懼自我蠶食而拒絕創新、最終被外部競爭對手全盤顛覆**的悲劇。

```
【侵蝕效應的兩面刃機制】

   【情境 A：內部無謂內耗 (自傷)】                 【情境 B：防禦性主動蠶食 (救贖)】
  外部無威脅，新產品純粹搶奪舊產品利潤          外部對手正以破壞性技術猛烈侵蝕舊市場
               │                                            │
               ▼                                            ▼
  【侵蝕應全額計為新專案成本減項！】            【侵蝕不應計為成本！因為不自蠶食，】
  (例: 可口可樂推出微幅改裝罐分流原味)          【也會被對手徹底蠶食！(例: iPhone 替代 iPod)】
```

## 🔬 資本預算中的侵蝕現金流判定模型

在計算新專案的淨現值 (NPV) 時，侵蝕現金流量是否應作為「現金流出減項」，取決於一個核心反事實假設 (Counterfactual Question)：

> [!IMPORTANT]
> **「如果我們今天『不推出』這項新產品，原本老產品的這部分銷售額，未來是否能夠繼續百分之百保留？」**

### 1. 嚴格增額現金流修正公式
$$CF_{\text{project}, t} = CF_{\text{new}, t} - \Delta CF_{\text{old}, t}^{\text{Erosion}}$$

其中：
- $\Delta CF_{\text{old}, t}^{\text{Erosion}}$ 為舊產品因新產品上市所**實質損失的邊際貢獻 (Contribution Margin)**，而非單純的營收數字！

$$\Delta CF_{\text{old}, t}^{\text{Erosion}} = (\Delta Q_{\text{old}} \times \text{Unit } CM_{\text{old}}) \times (1 - t)$$

### 2. 兩大決策情境判定矩陣

| 市場競爭態勢 | 如果不推出新產品，舊產品營收會如何？ | 侵蝕效應的財務處理 | 經理人策略決策指引 |
| :--- | :--- | :--- | :--- |
| **情境一：封閉寡占 / 無迫切外部威脅** | 舊產品銷售將持續維持穩定，客戶無處可去。 | **必須 100% 扣除侵蝕成本！** 計入新專案的現金流減項。 | 仔細計算新舊產品的邊際貢獻差額，若新產品毛利較低，應暫緩推出。 |
| **情境二：激烈動態競爭 / 面臨顛覆威脅** | 即使我不做，**競爭對手也會在半年內推出同類產品搶光客戶！** | **0% 扣除！侵蝕效應不應懲罰新專案！** | **「與其被別人打死，不如自己主動革命！」** 毫不猶豫推動自我蠶食。 |

## 🏢 企業實戰案例：Apple iPhone 對 iPod 的傳奇自我蠶食

### 1. 商業背景
2005 年，蘋果公司的 iPod 音樂播放器如日中天，佔全公司總營收的 **近 50%**，是全球科技界最具統治力的消費電子圖騰。

### 2. 賈伯斯的戰略決策與侵蝕哲學
Steve Jobs 敏銳預見到：隨著 3G 網路與智慧型手機技術成熟，未來的行動手機必定會內建高品質音樂播放功能，屆時消費者將不再願意隨身攜帶兩台設備。
- **內部質疑**：財務與行銷團隊擔憂，研發具備音樂播放功能的手機 (iPhone) 將直接毀掉每年創造數十億美元暴利的 iPod 事業部；
- **賈伯斯的世紀決策**：**「如果你不主動自我蠶食，別人就會跑來蠶食你 (If you don't cannibalize yourself, someone else will)!」**
- **成果**：2007 年 iPhone 問世後，iPod 銷量迅速萎縮並最終走入歷史；但 iPhone 創造了每年超過 2,000 億美元的營收帝國，使蘋果躍升為全球市值最高的科技巨擘。如果當年因為恐懼侵蝕而放棄 iPhone，蘋果早已隨 iPod 的淘汰而淪為歷史塵埃。

## ⚠️ 經理人常見盲點與治理陷阱

1. **「拿營收當損失」的會計計算錯誤**：在計算侵蝕金額時，直接扣除舊產品的「銷貨收入 (Revenue)」，忘記了舊產品銷量減少時，其「變動成本 (Variable Costs)」也同步減少！正確做法只能扣除**「損失的邊際貢獻 (Contribution Margin)」**。
2. **事業部穀倉利益 (Silo Mentality) 阻礙公司整體價值最大化**：老產品事業部主管為了保衛自己的年度 KPI 獎金與部門預算，強烈反對新產品專案立項，甚至在通路端暗中抵制新產品鋪貨。
3. **忽視「協同效應 (Synergy Effect)」的正向互補**：只看新產品對舊產品的單向分流，忽視了新產品可能帶動品牌整體關注度，進而反向拉動高階配件或互補服務的銷量增長。

## 🎯 高階經理人決策檢核清單

- [ ] 本專案預期的客群，有多少比例是來自於市場全新客戶，有多少比例是從現有舊產品分流而來？
- [ ] 若我們主動放棄或推遲該專案，外部競爭對手是否能在 6 至 12 個月內推出替代產品吃掉該市場？
- [ ] 侵蝕成本計算中，財務模型是否嚴格採用「邊際貢獻 (CM)」而非「全額營收」？
- [ ] 新產品的單位利潤率是否高於舊產品？整體的產品組合淨現金流是否呈實質增長？
- [ ] 公司的管理獎酬機制，是否避免了各事業部因自我蠶食而引發的內部政治內耗？
