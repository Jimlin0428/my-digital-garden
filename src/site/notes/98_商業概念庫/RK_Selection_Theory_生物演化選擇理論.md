# 生物演化選擇理論：R 策略 vs. K 策略 (r/K Selection Theory)

## 一、 核心定義與本質
- **r/K 選擇理論（r/K Selection Theory）** 源於演化生態學，描述物種在面對不同環境變動性與資源約束時，所演化出的兩種根本性繁殖與生存策略。
- **商管映射**：企業在不確定環境下的產品開發節奏、資本配置模式以及組織能耐培育，高度契合 r 策略與 K 策略的二元劃分。

## 二、 核心理論架構與全維度對比
| 比較維度 | R 策略 (r-selection / 擴張型) | K 策略 (K-selection / 承載型) |
| :--- | :--- | :--- |
| **生物學表徵** | 高產卵量、低存活率、壽命短、發育極快、體型小 | 低產仔數、高存活率、壽命長、精心撫育、體型龐大 |
| **環境適應條件** | **高不確定性、高波動、不可預期之動態環境** | **低不確定性、資源穩定但高度擁擠之飽和環境** |
| **產品與研發戰略** | 快節奏推出多種款式試錯，重視速度與週轉 | 聚焦極少數經典核心，追求極致品質與長銷壽命 |
| **典型商業實例** | **Zara 快時尚**：每週推出數百款，快速去留驗證 | **愛馬仕 (Hermès)**：數十年聚焦柏金包與工藝傳承 |
| **資本投資映射** | **創投基金 (VC)**：廣泛投資數十家新創，博取非對稱肥尾回報 | **企業創投 (CVC) / 策略聯盟**：精準入股供應鏈少數戰略夥伴 |
| **能耐與人才結構** | **專才 (Specialist)**：面對高變動前沿需專屬性技術資產攻堅 | **通才 (Generalist)**：面對成熟穩定體系以通才降低協調整合成本 |

## 三、 期望報酬率加權模型
$$\text{期望報酬 } E(R) = \sum_{i=1}^{n} (P_i \times R_i)$$
- 在高不確定性環境下，單一專案成功機率 $P_i$ 極低，企業採 R 策略擴大嘗試基數 $n$，以捕捉潛在極高報酬 $R_i$。
