# 價值網絡模型 (The Value Net)

## 一、 核心定義與本質
- **價值網絡模型（The Value Net）**由哈佛商學院亞當·布蘭登伯格（Adam Brandenburger）與耶魯管理學院貝利·奈勒波夫（Barry Nalebuff）於 1996 年在《競合策略》（*Co-opetition*）中正式提出。
- **本質與範式躍遷**：
  徹底顛覆了傳統波特五力分析與單向線性價值鏈（Value Chain）的對抗假設。價值網將產業參與者劃分為**「二維十字雙軸結構」**，揭示了商業世界中**「交易關係（縱軸）」**與**「評價關係（橫軸）」**的交織共生，確立了企業與外部夥伴「既競爭又合作」的動態生態。

---

## 二、 雙軸四方五位架構

```text
                            顧客 (Customers)
                                ▲
                                │  縱軸：交易流向 (Transactions)
                                │  (資源投入與產品服務購買)
          競爭者                │                互補者
       (Competitors) ◀──────── 企業 ────────▶ (Complementors)
 (降低他人對你的評價)         (The Firm)         (提高他人對你的評價)
                                │
                                │  橫軸：心智與評價影響 (Valuation & Perception)
                                │  (競合策略核心基石)
                                ▼
                           供應商 (Suppliers)
```

1. **縱軸（交易流向）**：
   - **顧客（Customers）**：購買、使用產品或為產出支付對價的參與者；
   - **供應商（Suppliers）**：提供原料、零組件、專業勞務或專利授權等生產要素的參與者。
2. **橫軸（評價與心理流向）**：
   - **競爭者（Competitors）**：該參與者的存在，會使**顧客對你的產品評價降低**，或使**供應商對供給你資源的意願降低**；
   - **互補者（Complementors）**：該參與者的存在，會使**顧客對你的產品評價提高**，或使**供應商供給資源給你的吸引力提高**。

---

## 三、 實戰判定矩陣與角色動態雙重性

| 角色類別 | 顧客觀點 (Customer Perspective) | 供應商觀點 (Supplier Perspective) | 策略應對方針 |
| :--- | :--- | :--- | :--- |
| **互補者 (Complementor)** | 同時擁有或消費 A 與 B，會**提高**對自身產品之評價（願付價格 WTP 上升）。 | 同時供應原料給 A 與 B，會**提高**供應原料給自身企業之誘因與規模經濟。 | **全力扶植與策略聯盟**，共同做大市場總蛋糕（Grow the Pie）。 |
| **競爭者 (Competitor)** | 擁有或消費 A，會**降低**對自身產品 B 之評價與購買意願（預算排擠）。 | 供應原料給 A，會**降低**供應資源給自身的配額或議價空間（資源分流）。 | **差異化防禦與 PARTS 變革**，避免陷入零和削價泥淖。 |

---

## 四、 實務案例對標
- **Wintel 聯盟（微軟 Windows × 英特爾 x86）**：
  PC 發展史上最強大的互補者。更強大的 Windows 軟體需要更快的 Intel 晶片；更快的 Intel 晶片推動微軟開發更強大的作業系統，兩者在橫軸上相互拉抬評價，聯手主導全球 PC 市場三十年。
