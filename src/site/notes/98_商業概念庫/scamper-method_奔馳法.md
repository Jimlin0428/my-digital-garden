# 奔馳法 (SCAMPER Method)

## 📌 概念核心定義

**奔馳法 (SCAMPER Method)** 是一套結構化的**創意思考與產品創新檢核表技術**。其思想雛形源自頭腦風暴之父亞歷克斯·奧斯本 (Alex Osborn)，後於 1971 年由教育學家鮑伯·艾伯爾 (Bob Eberle) 系統化精煉為極易記憶的「SCAMPER」七字首字母縮寫。

奔馳法的核心哲學在於：**「世上罕有憑空捏造的純粹發明，絕大多數創新皆是針對既有事物進行元素重組、屬性變形或情境轉移的產物。」** 它透過七組強制性引導提問，強制大腦打破慣性思考路徑，從不同視角切換檢視現有產品、製程或服務，是高階經理人與產品經理激發漸進式與架構性創新的實用武器。

```
                    【SCAMPER 創意思考七大維度】
┌─────────────────────────────────────────────────────────────┐
│ S - Substitute (替代)        │ 更換材料、零件、流程或人員     │
│ C - Combine    (結合)        │ 融合相異功能、產品或生態系統   │
│ A - Adapt      (調適/改編)   │ 跨界借鑑自然界或他業成熟解法   │
│ M - Modify     (修改/縮放)   │ 放大、縮小、改變形狀或顏色     │
│ P - Put to use (轉作他用)    │ 開發非目標客群或全新應用場景   │
│ E - Eliminate  (消除)        │ 剔除多餘功能、極致精簡流程     │
│ R - Reverse    (反轉/重組)   │ 顛倒順序、內外反轉、上下倒置   │
└─────────────────────────────────────────────────────────────┘
```

## 🔬 七大引導維度深度剖析與實戰提問

### 1. S - Substitute (替代)
- **引導提問**：可以用什麼更便宜、更輕盈、更環保的材料替代？可以用 AI 或自動化替代人工環節嗎？可以替換既有能源動力嗎？
- **實例**：Beyond Meat 用植物蛋白替代真實肉類；Tesla 用圓柱形鋰電池替代傳統車用內燃機。

### 2. C - Combine (結合)
- **引導提問**：可以將這兩項原本獨立的產品或服務合二為一嗎？可以將硬體與雲端訂閱結合嗎？
- **實例**：智慧型手機將相機、GPS 導航儀、音樂播放器與電腦結合；瑞士刀的多功能整合。

### 3. A - Adapt (調適 / 改編)
- **引導提問**：其他行業有什麼現成成熟方案可以搬過來借用？大自然（仿生學）是如何解決這個問題的？
- **實例**：日本新幹線車頭藉由模仿翠鳥長喙入水結構，徹底消除了列車進入隧道時的巨大音爆；汽車生產線借鑑屠宰場的吊掛流水線反向運作。

### 4. M - Modify / Magnify / Minify (修改 / 放大 / 縮小)
- **引導提問**：把這個特徵放大到極限會怎樣？把體積縮小到極致會怎樣？加強頻率或改變外觀包裝會產生什麼新市場？
- **實例**：
  - **放大 (Magnify)**：三星 Galaxy Note 引領大螢幕智慧型手機風潮。
  - **縮小 (Minify)**：Sony Walkman 將笨重的收錄音機縮小至口袋隨身聽；微型助聽器。

### 5. P - Put to another use (轉作他用)
- **引導提問**：這個廢棄物或副產品能賣給誰？現有技術能否解決完全不同領域的問題？小孩、老年人或寵物能如何使用它？
- **實例**：威而鋼 (Viagra) 最初作為治療心絞痛的心血管藥物，臨床意外發現轉作男性勃起障礙治療；微軟 Kinect 原為遊戲體感設備，被廣泛轉用於醫療手術手勢控制與機器人視覺。

### 6. E - Eliminate (消除)
- **引導提問**：如果拿掉這個最昂貴的零件會怎樣？能消滅哪些繁瑣的審核審批步驟？能拿掉物理實體介面嗎？
- **實例**：廉價航空（如西南航空）消除免費機上餐點、消除劃位與消除免費託運行李；戴森消除吸塵器集塵袋；iPhone 消除實體鍵盤。

### 7. R - Reverse / Rearrange (反轉 / 重組)
- **引導提問**：如果把操作順序完全顛倒會怎樣？由顧客來做原本由員工做的事會怎樣？由賣斷轉為租賃反向操作？
- **實例**：IKEA 讓顧客自行組裝家具（反轉傳統家具出廠即組裝完成的流程）；Dell 接單後生產 (BTO) 反轉「先造後賣」為「先買後造」。

## 📊 奔馳法工作坊運作矩陣範本

高階團隊進行產品迭代工作坊時，可運用標準 SCAMPER 矩陣展開系統性腦力激盪：

| SCAMPER 維度 | 現有產品/服務現狀 | 引發質疑之核心問題 | 產出之潛在創新提案 | 評估可行性與優先順序 |
| :--- | :--- | :--- | :--- | :--- |
| **S (替代)** | 塑膠外殼包裝 | 能否改為可生物分解海洋材料？ | 採用菌絲體或甘蔗渣壓製外殼 | 高 (符合 ESG 採購趨勢) |
| **C (結合)** | 單一健身設備 | 能否結合遠端連線教練？ | 聯網飛輪車 + 互動訂閱螢幕 (Peloton) | 極高 (創造持續經常性營收) |
| **A (調適)** | 醫院兒科核磁共振 (MRI) | 孩童極度恐懼儀器噪音，如何克服？ | 借鑑迪士尼樂園的海盜船探險塗裝與冒險故事 | 高 (顯著降低孩童鎮靜劑使用率) |
| **M (修改)** | 傳統洗衣粉 | 洗衣粉笨重且容易灑落，能否縮小？ | 濃縮高倍洗衣凝膠球 (P&G 洗衣球) | 已驗證 (利潤率大幅提升) |
| **P (轉作他用)** | 閒置家庭空房 | 僅供親友偶爾借住 | 開放給全球旅人短租 (Airbnb) | 顛覆性巨頭誕生 |
| **E (消除)** | 傳統銀行臨櫃開戶 | 耗費 1 小時填寫紙本合約與排隊 | 消除實體分行，純網銀手機開戶 | 產業標準主流 |
| **R (反轉)** | 軟體先付數萬元購買光碟 | 買斷軟體風險極高 | 改為軟體免費使用，按月租賃 (SaaS) | 全球軟體典範轉移 |

## 🏢 企業實戰案例：麥當勞的「快速服務系統 (Speedee Service)」

### 1. 商業背景
1940 年代，麥當勞兄弟經營傳統汽車餐廳 (Drive-in)。當時的痛點在於：菜單有數十種餐點、需要雇傭大量服務生端餐盤至車旁，出餐緩慢、餐具時常破損丟失，獲利微薄。

### 2. 奔馳法在營運上的極致反轉
麥當勞兄弟實質上運用了 SCAMPER 進行營運大革命：
- **Eliminate (消除)**：消除 80% 的冷門菜單，只保留漢堡、薯條與飲料；消除實體陶瓷餐盤與刀叉，全數改為紙袋一次性拋棄；消除服務生侍應服務。
- **Reverse (反轉)**：反轉點餐流程，顧客必須自己走出車子來到櫃檯窗口排隊先付款、後取餐。
- **Substitute (替代)**：用流水線規格化烤肉架與醬料定量壓榨機，替代傳統大廚的個人廚藝。
- **成果**：出餐時間由 30 分鐘極限壓縮至 **30 秒**，成本暴降，成就了後續 Ray Kroc 複製擴張至全球數萬家連鎖快餐的商業奇蹟。

## ⚠️ 經理人常見盲點與治理陷阱

1. **僅視為「靈感清單」缺乏後續收斂篩選**：SCAMPER 能快速產出數百個點子，若未設定清晰的商業可行性 (Viability) 與技術可行性 (Feasibility) 評估標準，工作坊將流於空談，無疾而終。
2. **為改而改的「功能過載 (Feature Creep)」**：過度使用 Combine 與 Modify，在原本優雅的產品上盲目堆疊各種無人使用的雞肋功能，反而讓產品變得臃腫複雜。
3. **忽視 Reverse 帶來的法規與社會文化阻力**：顛倒既有利益分配格局（如優步反轉計程車牌照模式）時，未預先評估行業工會與政府監管的強烈反撲。

## 🎯 高階經理人決策檢核清單

- [ ] 本季度的產品與服務改善會議，是否已經系統化跑過一次完整的 SCAMPER 七大維度提問？
- [ ] 在產品設計上，我們是否勇敢嘗試了「消除 (Eliminate)」非核心功能，以追求極致簡單？
- [ ] 我們的核心技術或專利資產，是否存在尚未被發掘的「轉作他用 (Put to another use)」全新商機？
- [ ] 當遭遇供應鏈斷料或價格暴漲危機時，採購與研發部門是否啟動了「替代 (Substitute)」檢核程序？
- [ ] 公司的商業營運流程，是否有任何環節可以藉由「反轉 (Reverse) 順序」創造出指數級的交付速度？
