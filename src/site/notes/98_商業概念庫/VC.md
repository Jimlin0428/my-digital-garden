# 風險投資 (Venture Capital, VC)

## 📌 概念核心定義

**風險投資 (Venture Capital, 簡稱 VC)**，亦稱**創業投資**，是一種專門向**具備極高市場不確定性、極高失敗風險，但同時擁有顛覆性創新技術、非線性指數級增長潛力之未上市早期或成長期新創企業**，提供長期股權資本 (Equity Capital) 與高增值賦能服務的專業私募金融中介機制。

風險投資是整個矽谷與全球第四次工業革命的心臟泵血機。VC 與傳統商業銀行貸款存在本質差異：
- **商業銀行**：厭惡一切風險，要求充足的有形抵押品（如土地、廠房）與穩定利息收入，追求「安全性第一」；
- **風險投資 (VC)**：**擁抱極限風險，不要求任何抵押品，容忍 80% 的投資組合全額破產**，全力追求剩下少數超級明星企業所帶來的百倍甚至千倍的股權資本增值回報。

## 🔬 理論架構：VC 組織治理與冪律分佈法則

### 1. 創投基金的底層組織架構：LP-GP 雙層合夥制

```
┌─────────────────────────────────────────────────────────────┐
│ 【有限合夥人 (Limited Partners, LPs)】 (出資 99%)           │
│  • 退休基金 (Pension Funds)   • 大學捐贈基金 (Endowments)   │
│  • 主權財富基金 (SWFs)        • 家族辦公室 (Family Offices) │
│  (僅承擔出資義務與有限責任，完全不干預基金日常投資決策)      │
└──────────────────────────────┬──────────────────────────────┘
                               │ 提供資本，每年支付 2% 管理費
                               ▼
┌─────────────────────────────────────────────────────────────┐
│ 【普通合夥人 (General Partners, GPs) / 創投管理團隊】 (出資 1%) │
│  • 尋找優質專案 (Deal Sourcing)   • 盡職調查與決策 (DD)       │
│  • 投後賦能 (Post-investment)    • 輔導上市與併購退場 (Exit) │
│  (獲取 20% 超額收益績效提成 Carried Interest ◄── 核心利潤來源)│
└──────────────────────────────┬──────────────────────────────┘
                               │ 投資股權
                               ▼
┌─────────────────────────────────────────────────────────────┐
│ 【投資組合新創企業 (Portfolio Startups)】 (30 ~ 50 家)      │
└─────────────────────────────────────────────────────────────┘
```

- **經典「2/20 費用規則」**：LP 每年向 GP 支付基金總規模的 **2%** 作為管理費 (Management Fee，支應用餐、差旅與薪酬)；當基金退場回本後，GP 分得全基金淨利潤的 **20%** 作為績效提成 (Carried Interest / Carry)。
- **基金存續週期 (Fund Life)**：通常為 **10 年（5 年投資期 + 5 年收割退場期）**，經全體 LP 同意可延長 1~2 年。

### 2. 冪律分佈法則 (The Power Law / 80-20 Rule on Steroids)

著名投資人彼得·泰爾 (Peter Thiel) 在《從 0 到 1》中精闢指出：**「創投世界最核心的秘密，就是回報遵循極端的冪律分佈，而非正態常態分佈！」**

$$\text{Total Fund Return} \approx \text{Return of the Single Best Investment}$$

在典型的 30 家新創投資組合中：
- **15 ~ 20 家 (50%~60%)**：徹底倒閉清算，投資價值歸零 ($0\times$)；
- **6 ~ 8 家 (20%~30%)**：勉強打平或產生微利 ($1\times \sim 3\times$)；
- **1 ~ 2 家 (5%)**：成為改變世界的超級獨角獸 ($100\times \sim 1,000\times$)！
- **治理啟示**：**頂級 VC 的整檔基金總收益，幾乎全數由這單一一家全壘打企業 (Fund Returner) 獨力貢獻！** 因此，VC 投資決策時只在乎「你成功時能長到多大」，完全不在乎「你失敗的機率有多高」。

## 📊 投資條款清單 (Term Sheet) 核心治理條款

當 VC 決定投資時，會出具 Term Sheet，其中四大條款直接決定了企業的控制權與利益分配：

| 核心條款名稱 | 法律機制與運作方式 | 經理人防禦與談判重點 |
| :--- | :--- | :--- |
| **清算優先權<br>(Liquidation Preference)** | 當公司被出售或清算時，特別股 VC 有權在普通股（創辦人與員工）之前先拿回本金。<br>• **Non-participating (1x 不參與分配)**：拿回 1x 本金或按普通股比例二選一。<br>• **Participating (參與分配)**：先拿回本金，剩下的錢再按比例分一次！ | **堅決拒絕 Participating 與高於 1x 的優先權**，否則公司賣得不夠高時創辦人將一分錢也拿不到。 |
| **防稀釋條款<br>(Anti-dilution)** | 當未來發生降輪融資 (Down Round) 時，保護 VC 股權不被過度稀釋。<br>• **Full Ratchet (完全棘輪)**：極其苛刻，轉換價直接降至下輪最低價。<br>• **Weighted Average (加權平均)**：依新發行股份數量溫和調整。 | **強制要求採用 Broad-based Weighted Average (廣義加權平均)**，徹底杜絕 Full Ratchet。 |
| **保護性否決權<br>(Protective Provisions)** | 列舉重大事項（如出售公司、更改章程、發行新股、重大資本支出），VC 在董事會擁有一票否決權。 | 嚴格限定否決權範圍，防止投資人干涉日常微觀營運。 |
| **拖售權與隨售權<br>(Drag-Along & Tag-Along)** | • **隨售權 (Tag-Along)**：創辦人賣老股時，VC 有權按比例一起賣。<br>• **拖售權 (Drag-Along)**：多數股東同意賣公司時，有權強制少數股東一起出售。 | 設定拖售權啟動門檻（例如需經創始團隊同意，或出售估值必須達到原始投資的 3x 以上）。 |

## 🏢 企業實戰案例：紅杉資本 (Sequoia Capital) 的傳奇造王者

### 1. 商業地位
創立於 1972 年的紅杉資本是全球創投界無可爭議的皇冠明珠。其投資組合企業總市值佔納斯達克總市值的 20% 以上，包括 Apple、Cisco、Google、PayPal、Airbnb、Stripe 與 OpenAI。

### 2. 洞悉冪律的典範實踐
2004 年，紅杉資本合夥人 Roelof Botha 頂住內部質疑，向剛被哈佛大學退學的 Mark Zuckerberg 投資了 50 萬美元；在 WhatsApp 僅有幾名工程師時，紅杉作為唯一的機構投資人累計注資 6,000 萬美元。
- **成果**：2014 年 Facebook 以 190 億美元天價收購 WhatsApp，紅杉資本單筆獲得超過 **30 億美元（超過 50 倍淨回報）**，一筆投資直接將整檔基金回報拉升至傳奇級別，完美展現了風險投資對超級全壘打的終極追求。

## ⚠️ 經理人常見盲點與治理陷阱

1. **盲信「VC 的錢越多越好」**：盲目追求過高的紙面估值 (Paper Valuation)。估值被灌水得越高，下一輪融資所需的業績標準越苛刻；一旦業務增長稍有放緩，立刻引發災難性的降輪融資 (Down Round)，觸發防稀釋條款將創始團隊股權洗劫一空。
2. **忽視 VC 的「基金週期清算壓力」**：VC 基金有 10 年到期退場的剛性約束。當基金進入第 7~8 年時，即使公司業務健康且適合長期自立，VC 董事亦會施加巨大壓力強迫公司出售或草率上市。
3. **誤將 VC 當作「慈善家或導師」**：在順境時 VC 是提供資源的盟友；但在逆境中，VC 代表的是其背後 LP 的信託責任，在危機關頭撤換執行長、執行清算條款時絕不手軟。

## 🎯 高階經理人決策檢核清單

- [ ] 我們的商業模式是否真的具備在 5~7 年內實現「百倍增長」的潛力以匹配 VC 的冪律期望？
- [ ] 投資人給予的 Term Sheet 中，清算優先權是否為標準的「1x Non-Participating」？
- [ ] 董事會席位配置是否合理？創始團隊是否依然牢固掌握董事會多數表決權？
- [ ] 我們選擇的 VC 合夥人，除了資金之外，究竟能為公司帶來哪些具體的產業客戶與戰略資源？
- [ ] 我們是否有清晰的現金跑道意識，始終在帳面上保留足夠支撐到「下一個估值跳升節點」的充沛資金？
