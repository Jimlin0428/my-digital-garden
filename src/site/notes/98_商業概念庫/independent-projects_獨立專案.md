# 獨立專案 (Independent Projects)

## 📌 概念核心定義

在企業資本預算 (Capital Budgeting) 與長期資本配置決策中，**獨立專案 (Independent Projects)** 指一組**現金流量相互完全獨立、互不干擾的投資方案**。也就是說，企業採納或拒絕其中任何一個專案，在物理工程、法規條件或商業營運上，**完全不會影響到另一個專案的採納可行性或其未來的現金流量**。

與「互斥專案 ([[98_商業概念庫/mutually-exclusive-projects_互斥專案\|mutually-exclusive-projects_互斥專案]])」只能二選一的排他性衝突不同，獨立專案在理論上具備「並行共存性」。在企業不受資本限額約束 (Unconstrained Capital) 的理想資本市場中，經理人只需針對每一個獨立專案進行單獨的價值檢驗：凡是能夠為股東創造淨經濟價值的專案，企業皆應同時批准立項。

---

## 🔬 理論架構與標準決策法則

### 1. 無資本限額下的三大黃金決策法則

在資金供給充足的條件下，針對獨立專案的評估，主流評價指標具備高度一致的收斂性：

```
                    【獨立專案決策檢驗體系】
┌─────────────────────────────────────────────────────────────┐
│ 1. 淨現值法 (NPV Rule) ◄── (理論最高準繩)                    │
│    • 若 NPV > 0 ──► 接受 (Accept) ──► 增進股東財富          │
│    • 若 NPV < 0 ──► 拒絕 (Reject) ──► 摧毀股東價值          │
├─────────────────────────────────────────────────────────────┤
│ 2. 內部報酬率法 (IRR Rule)                                  │
│    • 若 IRR > WACC (資本成本) ──► 接受                      │
│    • 若 IRR < WACC (資本成本) ──► 拒絕                      │
├─────────────────────────────────────────────────────────────┤
│ 3. 獲利指數法 (PI Rule)                                     │
│    • 若 PI > 1.0 ──► 接受                                   │
│    • 若 PI < 1.0 ──► 拒絕                                   │
└─────────────────────────────────────────────────────────────┘
```

> [!IMPORTANT]
> **理論等價定理**：對於常規現金流（初期為淨流出、後續全為淨流入）的獨立專案，**$NPV > 0$、$IRR > WACC$ 與 $PI > 1.0$ 三者在數學邏輯上完全等價！** 經理人無論採用哪一個指標，得出的「採納或拒絕」結論百分之百相同。

### 2. 面臨硬性資本限額 (Capital Rationing) 時的決策轉化

在現實商業世界中，企業董事會往往設定年度資本支出上限 (CapEx Budget Ceiling)。此時，即便所有獨立專案的 $NPV > 0$，企業亦無法全數投資，獨立專案實質上轉化為**「有限資金池內的資源爭奪戰」**：
- **錯誤作法**：依據 NPV 絕對金額直接挑選（容易被單一巨型專案吞噬全部預算，錯失多個高效率中小型專案）；
- **正確作法**：依據**獲利指數 ([[index_獲利指數]])** 由高至低排序，或運用**整數線性規劃 (Integer Linear Programming)**，在預算約束內求解使得 $\sum NPV$ 最大化的專案組合：

$$\max \sum_{i=1}^{n} x_i \cdot NPV_i \quad \text{s.t.} \quad \sum_{i=1}^{n} x_i \cdot I_{0,i} \le \text{Capital Budget}, \quad x_i \in \{0, 1\}$$

## 📊 獨立專案 vs. 互斥專案之決策維度對照

| 評估構面 | 獨立專案 (Independent Projects) | 互斥專案 ([[mutually-exclusive-projects_互斥專案]]) |
| :--- | :--- | :--- |
| **決策性質** | **「通過/否決」決策 (Go / No-Go)**：各自獨立受審。 | **「比較排序」決策 (Ranking)**：二選一或多選一。 |
| **現金流關聯** | 彼此無關（專案 A 的存在不影響專案 B 的回報）。 | 彼此替代或共用同一資產（採納 A 則 B 自動作廢）。 |
| **指標衝突** | **NPV 與 IRR 結論永遠一致**（無矛盾可能）。 | **NPV 與 IRR 經常爆發衝突**（必須以 NPV 為準）。 |
| **採納數量** | 理論上可全部採納（只要各自 $NPV > 0$）。 | 嚴格只能採納單一最優方案（或特定組合）。 |

## 🏢 企業實戰案例：台積電 (TSMC) 先進製程與先進封裝的獨立專案並進

### 1. 商業情境
隨著摩爾定律逼近物理極限，半導體產業迎來生成式 AI 帶來的算力海嘯。台積電在年度資本支出 (CapEx) 規劃中，同時面臨數百億美元的投資決策。

### 2. 獨立專案的資本配置實踐
台積電內部評估了兩大旗艦專案：
1. **專案 A（新竹 2 奈米寶山晶圓廠建置）**：初始投資 150 億美元，評估晶圓代工產能與良率折現，預估 $NPV = 80\ \text{億美元}, IRR = 22\%$。
2. **專案 B（嘉義 CoWoS 先進封裝廠擴建）**：初始投資 30 億美元，評估輝達等客戶對 2.5D/3D 晶圓級封裝的急迫需求，預估 $NPV = 25\ \text{億美元}, IRR = 28\%$。
- **決策邏輯**：先進製程製造與先進後段封裝在物理廠房上各自獨立，且兩者在 AI 晶片生態系中互不排斥、高度互補。台積電並未在兩者之間二選一，而是將兩者視為標準的**獨立專案**，憑藉充沛的營業現金流與國際融資信用額度，同時全額批准立項！

## ⚠️ 經理人常見盲點與治理陷阱

1. **忽視「隱性資源爭奪」導致獨立專案被動互斥**：帳面上財務資金充足，兩個專案看起來相互獨立；但企業內部的核心研發架構師或高階專案經理數量有限，同時推動兩個專案引發關鍵人才被稀釋，導致兩者皆陷入延宕泥淖。
2. **非常規現金流引發的多重 IRR (Multiple IRRs) 陷阱**：若獨立專案在中期或期末存在巨額除役清理成本（如核電廠或採礦專案，現金流正負符號變更超過一次），IRR 方程將出現多個實數解，導致指標失效，此時必須嚴格以 NPV 或修正內部報酬率 (MIRR) 為準。
3. **部門經理切香腸式避開審查**：事業群主管為了規避董事會對大額專案的嚴格審批，刻意將一個大型專案拆解為 5 個微型「獨立專案」分批送審，掩蓋了系統性的總體投資風險。

## 🎯 高階經理人決策檢核清單

- [ ] 本專案的現金流預測，是否真正獨立於公司其他現行專案？是否存在未被計入的共用資產折舊？
- [ ] 在計算各獨立專案的折現率時，是否依據各專案自身的**資產風險屬性 (Project Beta)** 調整，而非一律套用總部統一的 WACC？
- [ ] 若公司當期面臨資本支出配額上限，我們是否已運用「獲利指數 (PI)」完成全組織專案的邊際效益排序？
- [ ] 執行團隊是否具備足夠的工程與管理帶寬，同時承擔這些獨立專案的並行推進？
- [ ] 專案立項後，是否建立了定期後續審計 (Post-audit) 機制，追蹤實際現金流與當初立項 NPV 預測的偏差？
