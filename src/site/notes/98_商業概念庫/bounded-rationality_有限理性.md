# 有限理性 (Bounded Rationality)

## 一、 核心概念與理論源流

### 1. 理論奠基：從「經濟人」到「行政人」
**有限理性 (Bounded Rationality)** 由 1978 年諾貝爾經濟學獎得主赫伯特·西蒙 (Herbert A. Simon) 於其經典著作《管理行為》（*Administrative Behavior*, 1947）與《組織》（*Organizations*, 1958，與 March 合著）中正式提出。

在古典經濟學的標準典範中，假設決策者為全知全能的「經濟人 (Economic Man / Homo Economicus)」——具備完備的資訊、無限的認知計算能力、清晰穩定的偏好排序，並始終追求「效用最大化 (Utility Maximization)」或「利潤最佳化 (Profit Maximization)」。

西蒙批判了古典經濟學的脫離現實，指出真實組織環境中的經理人本質上是「行政人 (Administrative Man)」：
1. **資訊不完備性 (Incomplete Information)**：環境高度複雜且具隨機性，經理人無法取得市場與競爭者的全域資訊。
2. **認知運算極限 (Cognitive Limitations)**：人類大腦的神經運算頻寬有限，工作記憶、注意力與計算能力無法窮盡未來所有可能狀態與機率分佈。
3. **時間與成本約束 (Time & Cost Constraints)**：決策搜集資訊與運算推演均需消耗資源，面臨緊迫的時間窗口與不可逆的決策成本。

因此，決策者不可能達到絕對理性，只能在認知能力的邊界與環境條件的約束下，展現出「有限理性」；其決策目標不是追求數學上的全局最佳解 (Optimization)，而是尋找符合心理預期的「[[98_商業概念庫/satisficing-decision_滿意決策\|滿意解 (Satisficing)]]」。

```
【古典全知理性：經濟人 (Economic Man)】
完備資訊 ──> 無限算力 ──> 窮舉所有替代方案 ──> 全局效用最大化 (Optimization)

               VS.

【真實情境約束：行政人 (Administrative Man)】
有限認知能力 ┐
不完備資訊   ├──> 啟發式搜尋 (Heuristics) ──> 達到期望水準即停止 ──> 滿意決策 (Satisficing)
時間成本邊界 ┘
```

## 二、 決策架構與數理機制

### 1. 搜尋成本與邊際效用停止準則
西蒙指出，有限理性下的決策過程是一個「啟發式搜尋 (Heuristic Search)」程序。設決策者尋找更優方案的搜尋成本為 $C(s)$，方案帶來的預期價值為 $V(s)$，其中 $s$ 為搜尋步驟：

$$
	ext{Net Payoff}(s) = V(s) - C(s)
$$

由於大腦注意力與外部資訊搜集的邊際成本遞增 ($rac{\partial C}{\partial s} > 0, rac{\partial^2 C}{\partial s^2} > 0$)，而發現顯著更優方案的邊際效益遞減 ($rac{\partial V}{\partial s} < 0$)，當邊際搜尋成本等於邊際預期增量價值時，或當方案價值達到決策者的動態「期望水準 (Aspiration Level, $\alpha$)」時，搜尋即告終止：

$$
V(s^*) \ge \lpha \implies \text{Stop Search & Adopt } s^*
$$

### 2. 古典全知理性 vs. 西蒙有限理性對照

| 比較維度 | 古典全知理性模型 (Classical Rationality) | 西蒙有限理性模型 (Bounded Rationality) |
| :--- | :--- | :--- |
| **決策主體假設** | 經濟人 (Economic Man) | 行政人 (Administrative Man) |
| **資訊結構** | 完全資訊、對稱透明、零搜尋成本 | 不完全資訊、不對稱、顯著搜尋成本 |
| **認知計算能力** | 無限計算能力、精準貝氏機率推演 | 認知頻寬有限、依賴[[cognitive-bias_認知偏誤|啟發式捷徑 (Heuristics)]] |
| **目標函數** | 全局最佳化 (Maximization / Optimization) | 達到抱負水準的滿意化 (Satisficing) |
| **方案評估方式** | 同步窮舉所有可能替代方案並比較 | 循序評估 (Sequential Search)，發現滿意解即停止 |
| **環境適應機制** | 靜態均衡分析 | 動態學習、心智模式調整與組織程序 (SOP) |

### 3. 組織結構作為「有限理性」的制度解方
西蒙進一步指出，企業組織存在的根本目的，正是為了補足個人有限理性的缺陷：
- **分工與部門化 (Specialization)**：將複雜的宏觀問題拆解為狹窄的微觀子問題，使個體認知資源聚焦。
- **標準作業程序 (SOP & Heuristics)**：將過去驗證過的滿意解固化為組織常規，降低每次決策的運算負荷。
- **資訊通訊階層 (Hierarchical Communication)**：透過上下游階層過濾雜訊，控制進入高階經理人注意力漏斗的資訊流。

## 三、 企業真實實務個案

### 1. 諾基亞 (Nokia) 智慧型手機轉型的認知受限
在 2007 年至 2010 年蘋果 iPhone 與 Google Android 崛起之際，諾基亞擁有全球最強大的硬體研發團隊與巨額研發預算。然而，諾基亞高層深受有限理性的結構性束縛：
- **注意力窄化 (Attention Funneling)**：高管團隊長期將認知運算聚焦於「硬體耐用度」、「通話品質」與「全球供應鏈規模經濟」，而忽略了「行動應用生態系 (App Store & Ecosystem)」的典範轉移。
- **內部 SOP 慣性**：Symbian 作業系統架構老化，但組織層級為了在有限時間內達到季報考核標準（滿意解），持續在 Symbian 上縫縫補補，而非決心重構現代作業系統。
- **代價**：諾基亞的有限理性使其未能將全域資訊納入決策模型，最終在全球智慧型手機市占率從超過 50% 崩跌至邊緣化，被微軟收購其手機部門。

### 2. 亞馬遜 (Amazon) 貝佐斯的「單向門 vs. 雙向門」決策治理
傑夫·貝佐斯 (Jeff Bezos) 深刻理解人類決策的有限理性，因此在亞馬遜內部建立了對抗有限理性與決策拖延的制度架構：
- **Type 1 決策 (單向門 / One-Way Door)**：不可逆、高代價的重大決策（如進軍雲端運算 AWS、重組履約網絡）。此類決策必須投入高昂搜尋成本、進行多維度壓力測試與反面論證。
- **Type 2 決策 (雙向門 / Two-Way Door)**：可逆、低失敗成本的日常營運決策。貝佐斯主張在僅掌握約 **70% 資訊** 時即應迅速拍板，若等到掌握 90% 資訊通常為時已晚。
- **制度化解方**：透過區分決策類型，亞馬遜避免了在低風險決策中浪費稀缺的認知算力，同時防止組織因追求「全知最佳化」而陷入分析癱瘓 (Analysis Paralysis)。

## 四、 經理人反思與行動檢核清單

```
                               經理人有限理性防禦架構

│     1. 資訊邊界審查     │     2. 認知偏差警訊     │     3. 組織治理糾偏     │
│ 評估資訊完備度與搜尋邊際│ 識別注意力窄化與慣性解  │ 建立紅隊反思與決策分類  │
└─────────────────────────┴─────────────────────────┴─────────────────────────┘
```

### Executive Decision Checklist
- [ ] **搜尋邊際評估**：我們是否為了追求不存在的「100% 完備資訊」，而陷入邊際成本遠超邊際效益的分析癱瘓？
- [ ] **期望水準檢驗**：目前的方案是真正達到戰略目標的「高標準滿意解」，還是團隊為了規避衝突而妥協的「平庸解」？
- [ ] **認知盲區排查**：高管會議上是否存在「注意力隧道 (Tunnel Vision)」，將產業定義窄化為既有競爭者，而忽視跨界顛覆？
- [ ] **決策分類定性**：當前面對的議案屬於「單向門 (Type 1)」還是「雙向門 (Type 2)」？是否落實了 70% 資訊決策法則？
- [ ] **紅隊挑戰機制**：重大併購或擴張案是否指派了無利益衝突的獨立「紅隊 (Red Team)」或「惡魔代言人」，突破管理層的有限認知框架？
