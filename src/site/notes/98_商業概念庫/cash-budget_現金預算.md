# 現金預算 (Cash Budgeting & Liquidity Forecasting)

> **【核心決策摘要】**
> **現金預算（Cash Budget）** 是企業財務長（CFO）與資金調度部門用以**預測與控制特定未來期間（通常按週、月或季度滾動編製）真金白銀流入與流出的核心量化管理工具**。現金預算完全拋開權責發生制下的會計帳面損益，**純粹以「現金實際收付時點」為基準**，精確計算出每個時段的「現金盈餘（Cash Surplus）」或「現金赤字（Cash Deficit）」。現金預算的主要目標在於確保企業始終保有**最低安全現金存量（Minimum Cash Balance）**，提前數週預警流動性缺口以安排銀行短期信用額度借貸，或在現金充沛時及時安排短期金融投資以提升資金收益率。

---

## 1. 現金預算標準編製流程 (Standard Mechanics)

現金預算按標準四個連續模組推進：

```
                    ┌─────────────────────────────────────────────────────────┐
                    │               現金預算標準編製架構                      │
                    └────────────────────────────┬────────────────────────────┘
                                                 ▼
        ┌────────────────────────────────────────────────────────────────────────┐
        │ 1. 現金收現預測 (Cash Receipts)                                        │
        │    • 當期現銷收入 + 前期賒銷在當期之應收帳款回收                       │
        │    • 其他業外現金收入 (投資收益、處分資產)                             │
        ├────────────────────────────────────────────────────────────────────────┤
        │ 2. 現金支出預測 (Cash Disbursements)                                   │
        │    • 支付原物料採購款 (應付帳款兌現)                                   │
        │    • 支付直接人工薪資、水電租金與營業費用                              │
        │    • 支付資本支出 (CapEx)、償還利息本金、所得稅與現金股利              │
        ├────────────────────────────────────────────────────────────────────────┤
        │ 3. 淨現金收支 (Net Cash Flow)                                          │
        │    • 當期淨現金流量 = 現金收現總額 - 現金支出總額                      │
        │    • 未融資之期末現金 = 期初現金餘額 + 當期淨現金流量                  │
        ├────────────────────────────────────────────────────────────────────────┤
        │ 4. 資金調度與融資融通 (Financing & Investment Planning)                │
        │    • 設定「最低目標現金餘額 (Minimum Target Balance)」                 │
        │    • 若期末現金 < 最低目標 ──▶ 啟動短期借款或動用循環信貸 (Revolver)   │
        │    • 若期末現金 > 最低目標 ──▶ 償還舊債或買入國庫券等短期貨幣市場工具  │
        └────────────────────────────────────────────────────────────────────────┘
```
