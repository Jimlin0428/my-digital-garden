# 投資風險 (Investment Risk)

## 📌 概念核心定義

在資本預算與企業資本配置決策中，**投資風險 (Investment Risk)** 指企業在承諾投入初始資本後，**該專案在未來實際產生的現金流量與經濟報酬率，負向偏離預期估計水準（甚至引發資本全額永久虧損）的客觀波動性與不確定性**。

古典金融學強調「風險與報酬的對稱性 (Risk-Return Trade-off)」，但在高階經理人的實務視角中，投資風險的核心絕非數學上的雙向對稱波動，而是**「下行風險 (Downside Risk)」**——即專案失敗時對企業資產負債表健全度、信用評等乃至生存存續所帶來的破壞潛力。評估投資風險的根本目的，在於精準定價不確定性，並透過風險調整折現率 (RADR) 與實質選擇權機制，確保股東所承擔的每一分風險皆獲得足額的超額溢酬補償。

---

## 🔬 理論架構：資本預算的三層風險維度模型

在現代公司理財理論中，單一投資專案的風險必須依據「誰來承擔風險」嚴格劃分為三大維度：

```
                    【專案投資風險的三層同心圓】
┌─────────────────────────────────────────────────────────────┐
│ 【第三層：市場系統性風險 (Market / Beta Risk)】              │
│  站在「充分分散投資的外部股東」視角！                       │
│  • 無法透過資產多元化消除，由宏觀經濟 (利率/通膨/景氣) 主導  │
│  • 以專案貝他值 (Project Beta β) 衡量，唯一決定專案資本成本  │
├─────────────────────────────────────────────────────────────┤
│ 【第二層：企業內部組合風險 (Corporate / Within-Firm Risk)】 │
│  站在「企業全體員工、供應商與債權人」視角！                 │
│  • 考量該專案與公司其他既有業務的相關性 (Correlation ρ)    │
│  • 決定企業整體破產倒閉機率與債務信用評等                   │
├─────────────────────────────────────────────────────────────┤
│ 【第一層：專案獨立風險 (Stand-Alone Risk)】                 │
│  將該專案視為「全天下唯一的孤立資產」！                     │
│  • 不考慮任何分散化，純粹衡量該專案自身現金流的波動幅度     │
│  • 透過標準差 (σ) 與變異係數 (CV) 衡量                      │
└─────────────────────────────────────────────────────────────┘
```

### 1. 風險調整折現率法 (Risk-Adjusted Discount Rate, RADR)
當專案的市場風險高於或低於企業現有平均風險時，**嚴格禁止直接套用全公司的加權平均資本成本 (WACC)**！必須針對專案自身的市場貝他值 ($\beta_{\text{project}}$) 量身定制折現率：

$$r_{\text{project}} = R_f + \beta_{\text{project}} \times [E(R_m) - R_f]$$

- 若高風險研發專案採用了過低的平均 WACC 折現，會導致專案被**高估誤採**；
- 若低風險節能改造專案採用了過高的平均 WACC 折現，會導致專案被**低估錯殺**。

## 📊 評估專案獨立風險的三大定量工具光譜

| 風險評估工具 | 核心運作機制 | 產出成果與優勢 | 局限性與治理盲區 |
| :--- | :--- | :--- | :--- |
| **[[analysis-2_敏感度分析]]**<br>*(Sensitivity Analysis)* | 每次僅變動一個關鍵變數（如售價 $\pm 10\%$），其餘變數保持不變。 | 產出蜘蛛圖與龍捲風圖，快速識別**最敏感的致命變數**。 | 忽略變數之間的內在關聯性（如售價上漲通常伴隨銷量下跌）。 |
| **情境分析**<br>*(Scenario Analysis)* | 同時改變多個變數，設定「悲觀 (Bear)、基準 (Base)、樂觀 (Bull)」三大情境。 | 計算預期 NPV 與標準差，評估極端悲觀情境下的虧損底線。 | 僅考慮離散的三種情境，現實世界是連續變動的。 |
| **蒙地卡羅模擬**<br>*(Monte Carlo Simulation)* | 為所有不確定變數設定機率分佈，由電腦進行 10,000 次隨機抽樣計算。 | 產出完整的 **NPV 連續機率分佈圖**，精準得出「專案虧損機率為 14.2%」。 | 垃圾進、垃圾出 (GIGO)，高度依賴對底層機率分佈與相關係數的主觀假設。 |

## 🏢 企業實戰案例：波音 787 夢幻客機的全球外包供應鏈風險失控

### 1. 商業背景與大膽的風險轉移架構
2003 年波音啟動 787 夢幻客機 (Dreamliner) 專案，預計投資 60 億美元。為了降低獨立投資風險，波音採取了前所未見的**「一級全球夥伴外包模式 (Tier-1 Global Outsourcing)」**：
- 將機身、機翼、航電等核心模組分包給日本、義大利與美國的 50 家一級供應商；
- 要求供應商自行承擔研發資本支出，波音僅負責最終組裝。

### 2. 供應鏈風險的災難性連鎖引爆
波音在財務模型上看似「分散了初始資本風險」，卻徹底低估了**「營運與整合風險」**：
1. **公差與軟硬體不相容**：各國供應商製造的碳纖維機身模組運抵西雅圖組裝廠時，出現公差超標、螺栓短缺與線路不合；
2. **鋰電池過熱起火**：日本供應商的電池管理系統引發多起機上冒煙起火事件，導致全球機隊被 FAA 強制勒令停飛；
3. **後果**：專案交付延宕超過三年半，研發與賠償成本暴增至 **320 億美元（超支逾 500%）**！原本試圖轉移風險的金融架構，演變成重創波音數十年信譽的歷史巨災。

## ⚠️ 經理人常見盲點與治理陷阱

1. **以「主觀樂觀偏誤 (Optimism Bias)」操縱現金流數據**：專案發起部門為了爭取預算，系統性高估未來營收 20%、低估建造成本 30%，使模型產出完美的 NPV 假象。
2. **錯把「無法量化」當作「零風險」**：面對地緣政治制裁、法規反壟斷審查等難以精確建模的軟性風險，直接在模型中略過不計，直到危機爆發引發全額資產註銷。
3. **缺乏「停損機制 (Kill Criteria)」**：專案啟動後，即使前期指標已全面報警，經理人受承諾升級 (Escalation of Commitment) 與沉沒成本偏誤驅使，持續追加投資「以賭翻盤」，最終將整個公司拖入深淵。

## 🎯 高階經理人決策檢核清單

- [ ] 本專案的折現率，是機械式採用公司統一 WACC，還是已依據專案市場風險進行了貝他調整 (RADR)？
- [ ] 財務模型是否已完成「敏感度分析與龍捲風圖」，明確找出決定專案成敗的前三大關鍵變數？
- [ ] 在極端悲觀情境下，若專案虧損達最壞上限，是否會引發公司整體債務違約或信用評等降級？
- [ ] 我們是否為該專案設計了分階段里程碑注資機制（實質選擇權 Real Options），而非一次性全額撥款？
- [ ] 董事會是否預先設定了明確的「停損撤退觸發條件 (Kill-switch triggers)」？
