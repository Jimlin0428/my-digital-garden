# 種子初創期 (Seed Stage)

## 📌 概念核心定義

**種子初創期 (Seed Stage)**，在創業生命週期與股權投資領域，指新創企業自完成概念發想後，**正式啟動公司營運、組建初始核心團隊、開發最小可行性產品 ([[98_商業概念庫/MVP最小可行產品\|MVP最小可行產品]])，並全力在真實市場中探索「產品-市場契合度 ([[98_商業概念庫/PMF_產品市場契合度 Product-Market Fit\|PMF_產品市場契合度 Product-Market Fit]])」的第一個實體商業階段**。

種子期是整個商業世界中**死亡率最高（通常超過 80%~90%）、風險最極端、但也是潛在倍數回報最驚人**的階段。在此階段，企業通常沒有歷史財務數據、沒有成熟的客戶群體，甚至沒有完整的產品。創業者在此時期的唯一核心戰略任務，就是**在初始種子資金燃燒殆盡之前，跨越「死亡之谷 (Valley of Death)」，找到能證明這是一門真實好生意的實證鐵證 (Traction)**。

## 🔬 理論架構與種子期融資工具

在種子初創期，由於公司缺乏歷史營收且未來高度不可預測，傳統的現金流量折現法 (DCF) 或本益比評價法完全失靈。矽谷創業投資體系演化出一套專門的種子融資工具：

```
                    【種子期融資工具演進】
                              │
         ┌────────────────────┴────────────────────┐
【可轉換公司債 (Convertible Notes)】       【未來股權簡單協議 (SAFE)】
   本質為「債權」，設定到期日與利息。          由 Y Combinator 於 2013 年開創。
   下一輪合格融資時轉換為特別股。              非債務、無到期日、無利息負擔！
         │                                         │
         └────────────────────┬────────────────────┘
                              │
                   【關鍵定價條款核心機制】
      ├─ 估值上限 (Valuation Cap)：保障早期投資人的最低股權折算底線
      └─ 轉換折扣 (Discount Rate)：通常給予 15% ~ 20% 的下一輪折扣優待
```

### 1. 估值上限 (Valuation Cap) 的保護運作機制
假設天使投資人在種子期以 **SAFE (Valuation Cap = 500 萬美元)** 投資 50 萬美元：
- 若公司在一年後 A 輪融資估值高達 **2,000 萬美元**；
- 該種子投資人依然能以 **500 萬美元的上限** 折算股權，實際取得高達 $50 / 500 = 10\%$ 的股權（若無 Cap 則只能拿到 2.5%）；
- 估值上限是對種子期承擔破產滅頂風險投資人的核心利益保障。

### 2. 創辦人股權成熟機制 ([[98_商業概念庫/equity-vesting_股權成熟機制\|equity-vesting_股權成熟機制]])
在種子輪融資中，正規機構投資人必定強制要求所有共同創辦人簽署股權成熟協議：
- **標準 4 年成熟期 + 1 年懸崖期 (4-Year Vesting with 1-Year Cliff)**：
  - 創辦人全職工作滿 1 年，方能解鎖 25% 股權；
  - 剩餘 75% 股權在後續 36 個月按月等額成熟解鎖；
  - 防止共同創辦人在融資後 3 個月鬧翻離職，卻帶走 30% 核心股權，直接導致公司因股權死局 (Cap Table Deadlock) 猝死。

## 📊 種子期團隊的三大資源分配死線

在種子初創期，資金運用必須極度冷酷且聚焦：

```
                  【種子期資本燃燒的三大去處】
┌─────────────────────────────────────────────────────────────┐
│ 1. 核心產品開發 (Product Engineering) ──────────────►  60% │
│    (僅保留能寫代碼、做原型的核心技術骨幹薪酬與伺服器費用)   │
├─────────────────────────────────────────────────────────────┤
│ 2. 獲取第一批種子用戶 (Customer Discovery) ────────►  25% │
│    (走出辦公室，進行深度訪談、小規模精準投放獲取反饋)       │
├─────────────────────────────────────────────────────────────┤
│ 3. 基礎法規、專利與維持生存底線 ───────────────────►  15% │
│    (公司設立、核心智財保護、極簡辦公空間)                   │
└─────────────────────────────────────────────────────────────┘
```

## 🏢 企業實戰案例：Instagram 的極簡種子期神話

### 1. 商業背景與大膽轉向
2010 年，Kevin Systrom 與 Mike Krieger 獲得 50 萬美元種子融資，原本開發一款名為 Burbn 的 HTML5 簽到打卡社交 App。該 App 功能龐雜，既能打卡、賺積分又能拍照。

### 2. 種子期極致精簡的典範
創辦人深入分析種子期少數用戶的行為數據，發現了一個驚人事實：**用戶根本不喜歡打卡，但極度著迷於上傳照片與套用復古濾鏡！**
- **果斷斷捨離**：兩位創辦人毅然砍掉 Burbn 中 90% 的功能，僅保留「拍照、濾鏡、分享」三個核心動作，將產品重構並更名為 **Instagram**。
- **極致精幹團隊**：在整個種子期與早期，公司總共只有 **13 名員工**，全部精力投入於擴展底層伺服器架構以應對數百萬爆發湧入的用戶。
- **成果**：正式上線首日吸引 2.5 萬名用戶，一年半後以 13 人團隊、零行銷廣告預算的奇蹟，被 Facebook 以 **10 億美元** 巨額收購，寫下種子期精實運作的永恆傳奇。

## ⚠️ 經理人常見盲點與治理陷阱

1. **「功能完美主義 (Feature Creep)」拖死公司**：創辦人總覺得產品還不夠完美、不敢推向市場，在地下室閉門造車一年半，把種子資金全數耗在自己幻想的功能上，錯失真實市場窗口。
2. **在尚未獲得 PMF 之前過早擴招**：在產品留存率低迷時，誤以為「業績不好是因為沒有業務員」，匆忙招募業務與公關團隊，導致每月固定燒錢率暴增三倍，提早撞上現金枯竭牆。
3. **接受掠奪性天使的「毒丸股權結構」**：為了 10 萬美元種子資金，出讓 40% 股權且附帶董事會一票否決權，使創始團隊淪為打工仔，導致後續主流 VC 全面放棄投資。

## 🎯 高階經理人決策檢核清單

- [ ] 我們當前打造的產品是否已經具備極致簡單的 MVP 核心，能讓用戶在 1 分鐘內體驗到「驚豔時刻 (Aha Moment)」？
- [ ] 公司的股權結構表 (Cap Table) 是否乾淨健全？共同創辦人是否皆已簽署「4 年成熟期 + 1 年懸崖期」條款？
- [ ] 我們的種子資金跑道是否能確保至少維持 **18 個月** 的深度探索與轉向空間？
- [ ] 我們每週是否至少與 10 位真實種子用戶進行一對一深度訪談，挖掘未言明的改進痛點？
- [ ] 團隊是否建立了以「留存率與推薦率」為核心的週迭代追蹤看板，而非自欺欺人的總下載量？
