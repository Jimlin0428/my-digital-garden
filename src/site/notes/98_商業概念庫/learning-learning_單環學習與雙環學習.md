# 單環學習與雙環學習 (Single-Loop and Double-Loop Learning)

## 一、 核心概念與理論源流

### 1. 理論奠基：阿吉里斯與舍恩的組織學習革命
**單環學習與雙環學習 (Single-Loop and Double-Loop Learning)** 是哈佛大學教授克里斯·阿吉里斯 (Chris Argyris) 與麻省理工學院教授唐納德·舍恩 (Donald Schön) 於 1974 年在名著《實踐中的理論》(Theory in Practice) 及 1978 年《組織學習》(Organizational Learning) 中創立的經典認知框架。該理論被公認為當代組織學習、變革管理與心智模式重構的最高理論基準之一。

阿吉里斯指出，人類與組織在採取行動時，均受內在的 **「行動理論 (Theory of Action)」** 所驅動。行動理論包含三個核心環節：
1. **主導變數 / 底層假設 (Governing Variables / Master Programs)**：組織未受檢驗的底層信念、世界觀、價值觀與戰略假定。
2. **行動策略 (Action Strategies)**：為達成目標所採取的具體營運流程、手段、規範與計畫。
3. **結果 (Consequences)**：實際產生的客觀營運產出與外部市場反饋。

### 2. 單環學習 vs. 雙環學習的核心拓撲對比

```
+---------------------------------------------------------------------------------+
|                       單環學習與雙環學習反饋控制迴路架構                        |
+---------------------------------------------------------------------------------+
                         【雙環學習迴路 (Double-Loop)】
             +----------------------------------------------------+
             |                                                    |
             v                                                    |
     [ 主導變數與底層假定 ]                                        |
     (Governing Variables)                                        |
     * 商業模式核心假設                                           |
     * 企業文化核心信條                                           |
     * 競爭邊界與價值觀                                           |
             |                                                    |
             | (重塑與質疑)                                       |
             v                                                    |
     [ 行動策略與操作手段 ]                                       |
     (Action Strategies)   <-----------------+                    |
     * 營運流程、定價策略                     | (策略修正)          | (質疑假定)
     * 行銷方案、產品規格                     |                    |
             |                               |                    |
             | (執行)                        |                    |
             v                               |                    |
     [ 客觀結果與市場產出 ]                  |                    |
     (Consequences / Results)                |                    |
             |                               |                    |
             +---- (比對發現落差 / 錯誤) ----+                    |
                         【單環學習迴路 (Single-Loop)】           |
             |                                                    |
             +----------------------------------------------------+
```

- **單環學習 (Single-Loop Learning)**：
  - **恆溫器機制 (Thermostat Metaphor)**：如同室內恆溫器，當室溫低於設定的 20 度時，啟動暖氣加熱，將結果導回預設常軌，但**恆溫器絕不會質疑「為什麼設定在 20 度？這個溫度合理嗎？」**。
  - 當營運結果出現偏差時，單環學習僅在「現有的規則與目標架構內」調整行動策略（如：加大折扣力度、加班趕工、加強流程審批），**絕不質疑既有的主導變數與戰略假定**。
- **雙環學習 (Double-Loop Learning)**：
  - 當結果出現偏差時，組織能主動跳脫表層操作，**回溯並質疑決定該策略的底層主導變數與根本假定**（如：「我們的產品定位是否已經與顧客真實需求脫節？這套商業模式本身是否存在致命缺陷？」）。
  - 雙環學習要求領導者勇於推翻自身的「神聖不可侵犯假定」，是企業實現破壞式創新與策略轉折點突破的根本動力。

## 二、 心理學深層根源：宣稱理論 vs. 使用理論與防衛性推理

### 1. 宣稱理論 (Espoused Theory) 與 使用理論 (Theory-in-Use) 的斷層
阿吉里斯在長達數十年的高階主管診斷中發現，人類普遍存在認知分裂：
- **宣稱理論 (Espoused Theory)**：經理人公開宣稱並深信自己遵循的價值體系（如：「我們鼓勵全員創新、我們歡迎任何不同意見、我們從失敗中學習」）。
- **使用理論 (Theory-in-Use)**：經理人在面臨實際危機、不確定性或人際威脅時，實際主導其行為的潛意識心智程式。

### 2. 第一型使用理論 (Model I) 的防衛性思維
令人震驚的是，阿吉里斯發現全球不論文化背景，絕大多數高管在潛意識中使用理論均屬於 **第一型模型 (Model I Theory-in-Use)**：
1. **單方面控制環境與任務 (Unilateral Control)**：絕不允許局勢脫離個人掌控。
2. **追求個人勝出、避免失敗 (Maximize Winning, Minimize Losing)**：將意見分歧視為非輸即贏的權力鬥爭。
3. **壓抑負面情緒 (Suppress Negative Feelings)**：表面維持客氣，私下排除異己。
4. **極力表現得理性 (Be Rational)**：掩蓋自身的不安全感與恐懼。

> **組織惡果**：第一型模型驅動了強大的**「防衛性推理 (Defensive Reasoning)」**與**「組織防衛常規 (Organizational Defensive Routines)」**——團隊對顯而易見的系統性危機心照不宣，形成「皇帝的新衣」集體盲從，使組織徹底喪失雙環學習能力。

## 三、 商戰歷史對照：柯達膠卷的單環死結 vs. 富士軟片的雙環浴火重生

```
+-----------------------------------------------------------------------------------+
|               數位海嘯下的命運分水嶺：柯達 (單環) vs. 富士軟片 (雙環)              |
+-----------------------------------------------------------------------------------+
|  [柯達的單環學習死結]                             [富士軟片的雙環學習破局]          |
|  * 底層假定：膠卷依然是全球最暴利的護城河         * 底層假定：傳統膠卷市場將永久歸零 |
|  * 策略反應：改進膠卷沖印速度、收購數位專利       * 策略反應：質疑存在本質，重構核心能力|
|    但堅決壓制數位相機推廣，避免自我蠶食           * 將膠卷抗氧化專利應用於抗衰老保養品|
|  * 結局：2012 年申請破產清算                      * 跨界醫療、高機能材料與製藥大獲成功|
+-----------------------------------------------------------------------------------+
```

### 1. 柯達公司 (Kodak)：教科書級別的單環學習悲劇
柯達並非死於技術落後——全世界第一台數位相機正是 1975 年由柯達工程師史蒂夫·薩森 (Steve Sasson) 發明的。
- **單環式的防衛性修正**：柯達的主導變數是「膠卷耗材的剃刀與刀片暴利模式」。當數位相機興起威脅利潤時，柯達高管進行了無數次單環學習：提高傳統相紙生產良率、降低供應鏈成本、推出能聯網但依然需要沖洗照片的混合亭（Kiosk）。
- **拒絕質疑底層假定**：柯達董事會拒絕質疑「膠卷是否終將滅亡」這一根本問題，將數位相機視為不可言說的內部威脅進行壓制，最終在 2012 年黯然破產。

### 2. 富士軟片 (Fujifilm)：勇於摧毀底層假定的雙環重生
面對同樣的數位毀滅海嘯，富士軟片執行長古森重隆 (Shigetaka Komori) 展現了極致的雙環學習：
- **徹底推翻神聖假定**：古森重隆在 2000 年代初向全公司宣告：「膠卷市場將以每年 20%~30% 的速度永久蒸發，我們的核心業務即將歸零。」這徹底粉碎了組織的防衛性幻想。
- **重塑主導變數與跨界重構**：富士對自身積累近百年的核心專利進行底層解構，發現膠卷技術的三大本質：**膠原蛋白化學、抗氧化奈米技術、光控精密塗層**。富士毅然跨界創立 Astalift 頂級護膚品牌（用抗氧化技術抗皮膚衰老）、研發 LCD 偏光保護膜，並併購跨足生物製藥領域，成功實現第二曲線爆發。

## 四、 單環學習與雙環學習的營運維度全景對照

| 比較維度 | 單環學習 (Single-Loop) | 雙環學習 (Double-Loop) |
| :--- | :--- | :--- |
| **本質問題意識** | 「我們如何**把事情做對**？(Are we doing things right?)」 | 「我們是否在**做對的事情**？(Are we doing the right things?)」 |
| **變更對象** | 執行手段、作業程序、預算配置、戰術細節。 | 策略假設、組織價值觀、商業模式本質、成功定義。 |
| **組織心智特徵** | 符合既有常規、避免衝突、追求局部效率。 | 開放探詢 (Inquiry)、容忍混亂、挑戰既得利益。 |
| **適用情境** | 確定性高、環境穩定、流程標準化的營運優化。 | 顛覆性變革、新技術衝擊、策略轉折點與轉機轉型。 |
| **學習障礙** | 技術性失誤、員工怠惰、工法未熟練。 | [[cognitive-dissonance_認知失調|認知失調]]、[[confirmation-bias_確認偏誤|確認偏誤]]、組織防衛常規、既得利益抵制。 |

## 五、 經理人決策檢核清單 (Executive Checklist)

- [ ] **失敗覆盤的深度檢驗**：在召開專案失敗檢討會時，會議時間是否 80% 都花在「追究執行細節與流程補漏（單環）」，而無人敢質疑「專案立項初期的市場假設是否已經完全錯誤（雙環）」？
- [ ] **房間裡的大象 (Elephant in the Room)**：團隊內部是否存在某些每個人心知肚明、私下議論紛紛，但在正式會議上被列為「不可討論」的禁忌議題或神聖專案？
- [ ] **宣稱與使用的行知合一審計**：公司牆上掛著的「誠信、創新、擁抱失敗」，在真實業務遭遇危機時，是否立即被「隱瞞壞消息、推諉卸責、嚴懲犯錯者」的使用理論所踐踏？
- [ ] **第二型探詢機制建立**：我是否建立了結構化的反對者機制（如指定專人扮演「魔鬼代言人」或導入外部獨立審計），合法化對高管權威戰略的公開質疑？
- [ ] **主導變數的定期壓力測試**：企業每半年是否針對當前最賺錢的「現金牛業務」進行一次歸零假設演練：「如果支撐該業務的三大前提（如高關稅保護、客戶轉移成本、專利壁壘）在明天全部消失，我們該如何自處？」
