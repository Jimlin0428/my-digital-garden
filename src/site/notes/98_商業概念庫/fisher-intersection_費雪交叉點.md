# 費雪交叉點 (Fisher Intersection / Crossover Rate)

## 📌 概念核心定義

**費雪交叉點 (Fisher Intersection)**，在公司理財與資本預算理論中亦稱為**交叉折現率 (Crossover Rate)**，由美國近代經濟學宗師歐文·費雪 (Irving Fisher) 首度系統化推演。它指在評估兩項互斥投資專案時，**在淨現值輪廓圖 (NPV Profiles) 上，使得這兩項專案的淨現值恰好完全相等 ($NPV_A = NPV_B$) 的特定臨界折現率 (以 $r^*$ 表示)**。

費雪交叉點是資本配置決策中的「戰略分水嶺」：它精確界定了資本成本 (WACC) 在何種水準下，專案的優劣排序會發生**「大逆轉 (Ranking Reversal)」**。理解費雪交叉點，能讓財務長與董事會在央行升息或降息的總體經濟週期波動中，清晰看透不同資本密集度與不同生命週期專案的真實抗震韌性。

```
淨現值 NPV ($)
   ▲
   │  NPV_A (長天期 / 資本密集專案)
   │  ＼
   │     ＼
   │        ＼     NPV_B (短天期 / 快速回本專案)
   │           ＼   ／
   │            【★ 費雪交叉點 (Crossover Rate r*)】
   │             ／ ＼
   │          ／       ＼
   │       ／             ＼
   0 ────┴─────────┴───────┴──────────────► 折現率 (r)
     【低利率區間】 r*  【高利率區間】
     (選擇專案 A)         (選擇專案 B)
```

---

## 🔬 數理模型與求解推導

### 1. 費雪交叉點的代數求解本質

假設專案 A 與專案 B 在各期的預期現金流分別為 $CF_{A, t}$ 與 $CF_{B, t}$。令兩專案之 NPV 相等：

$$NPV_A(r^*) = \sum_{t=0}^{n} \frac{CF_{A, t}}{(1 + r^*)^t} = \sum_{t=0}^{n} \frac{CF_{B, t}}{(1 + r^*)^t} = NPV_B(r^*)$$

移項整理後：

$$\sum_{t=0}^{n} \frac{CF_{A, t} - CF_{B, t}}{(1 + r^*)^t} = 0$$

> [!IMPORTANT]
> **深層數理本質**：**費雪交叉點 ($r^*$)，本質上就是「差額專案現金流量 ($CF_{\Delta} = CF_A - CF_B$)」的內部報酬率 ($IRR_{\Delta}$)！**

### 2. 數值範例推導
- **專案 A (重資產綠能電廠)**：$I_0 = -1,000$，第 1 年至第 5 年每年流入 $+350$；
- **專案 B (輕資產燃氣電廠)**：$I_0 = -400$，第 1 年流入 $+300$，後續每年流入 $+80$；
- **差額專案 ($A - B$)**：$I_{0, \Delta} = -600$，第 1 年 $+50$，第 2~5 年每年 $+270$；
- 透過財務計算器或 Excel 公式 `=IRR(...)` 求解該差額現金流之零淨現值折現率，所得之數值即為費雪交叉點 $r^*$。

## 📊 利率敏感度與專案排序逆轉法則

費雪交叉點之所以存在，根源於兩項專案的**現金流量時序 (Timing)** 或**資本規模 (Scale)** 對折現率的非對稱敏感度：

| 資本市場情境 | 資本成本 (WACC) 與費雪交點關係 | 最佳互斥決策 | 決策底層邏輯 |
| :--- | :--- | :--- | :--- |
| **寬鬆低利率時期** | **$WACC < r^*$ (座落於交叉點左側)** | **毫不猶豫選擇專案 A** | 資金成本極低，遠期巨額現金流經低折現率貼現後依然價值連城，規模優勢主導價值。 |
| **臨界無差異點** | **$WACC = r^*$ (恰好位於交叉點上)** | **兩專案無差異 ($NPV_A = NPV_B$)** | 兩者創造的股東財富增額完全相同，依非財務策略戰略因素裁決。 |
| **緊縮高利率時期** | **$WACC > r^*$ (座落於交叉點右側)** | **果斷轉向選擇專案 B** | 資金成本昂貴，遠期現金流被高折現率嚴重侵蝕，初期快速回本的抗風險能力主導價值。 |

## 🏢 企業實戰案例：離岸風電 (低碳重資產) vs. 燃氣發電機組的資本博弈

### 1. 商業情境
某國營跨國電力集團在評估新增 500MW 發電容量時，面臨兩項互斥工程方案：
- **方案 A（離岸風力發電）**：初始建置 CapEx 高達 20 億美元，但後續 20 年幾乎無燃料變動成本，現金流長達 25 年；
- **方案 B（天然氣複循環發電）**：初始建置僅需 6 億美元，但後續每年需承擔高額天然氣採購成本，現金流在初期快速回收。

### 2. 費雪交叉點的動態指引
財務團隊計算出兩項方案的 NPV 曲線交點：**費雪交叉點 $r^* = 7.5\%$**：
- **在 2021 年前（超低利率環境，WACC 僅約 4.5%）**：$WACC < 7.5\%$，離岸風電方案 A 的 NPV 達到 8.5 億美元，遠超燃氣機組的 5 億美元，集團全力推進綠能重資產；
- **2022 年全球升息潮爆發（借款利率飆升，專案 WACC 攀升至 9.0%）**：$WACC > 7.5\%$，專案排序發生**「大逆轉」**！燃氣機組因初期投資小、受高利率折現侵蝕較輕，其 NPV 逆勢超越了風電專案，迫使集團重新調整綠能投資步伐。

## ⚠️ 經理人常見盲點與治理陷阱

1. **誤將「費雪交叉點」當作「單一專案的最低報酬門檻」**：費雪交叉點只代表兩專案 NPV 相等的臨界點，它本身既不代表專案賺錢，也不代表符合投資標準（即使兩專案在某利率下皆為負 NPV，依然可能存在費雪交叉點）。
2. **在無交叉點情境下盲目硬套**：當專案 A 在所有折現率下的 NPV 全面壓制專案 B（NPV 輪廓線完全平行或不相交），代表專案 A 具備絕對主導優勢 (Absolute Dominance)，此時不存在費雪交叉點，無須浪費時間進行差額 IRR 分析。
3. **忽視通貨膨脹對現金流與折現率的雙重扭曲**：在計算費雪交叉點時，若現金流未扣除通膨率，而折現率採用名目利率，將引發交叉點的位置嚴重偏移，誤導長期資本決策。
