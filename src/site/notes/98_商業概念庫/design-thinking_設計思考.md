# 設計思考 (Design Thinking)

## 📌 概念核心定義

**設計思考 (Design Thinking)** 是一套以**「以人為本 (Human-Centered)」**為核心哲學的非線性、迭代式問題解決與創新方法論。它將設計師長期培養的同理洞察、發散聯想、動手實作與快速測試等心智模式，系統化轉化為商業管理人員探索未知市場、定義深層痛點與打造破壞性產品的策略性工具。

設計思考強調創新並非單純仰賴科技突破或商業模式計算，而是座落於**三大維度的黃金交集**：
1. **人性渴望 (Desirability)**：解決顧客真實存在且迫切的痛點（人們真正想要的是什麼？）；
2. **技術可行 (Feasibility)**：在現有或可預見的工程技術能力內得以實現（技術上做得到嗎？）；
3. **商業存續 (Viability)**：具備可獲利且可長期規模化的財務商業模式（商業上能持續賺錢嗎？）。

```
                    【設計思考創新交集 (The Sweet Spot)】
                                  人性渴望
                                (Desirability)
                                     ╱ ╲
                                   ╱     ╲
                                 ╱   ★    ╲
                       【真正的創新】
                               ╱             ╲
                             ╱                 ╲
                       技術可行 ─────────────── 商業存續
                     (Feasibility)           (Viability)
```

## 🔬 理論架構與核心運作模型

### 1. 英國設計委員會之「雙菱形模型 (Double Diamond)」

雙菱形模型由英國設計委員會 (Design Council) 於 2004 年提出，清晰界定了創新過程中的**兩次「發散-收斂」動態循環**：

```
      【第一個菱形：探索對的問題】                 【第二個菱形：打造對的解法】
  (Doing the Right Things)                   (Doing Things Right)
      發散           收斂                         發散           收斂
       ▲              ▼                            ▲              ▼
     ／  ＼         ／  ＼                       ／  ＼         ／  ＼
   ／      ＼     ／      ＼                   ／      ＼     ／      ＼
 ／          ＼ ／          ＼               ／          ＼ ／          ＼
【探索 Discover】 【定義 Define】 ──────────► 【研發 Develop】  【交付 Deliver】
同理觀察用戶生活   洞察核心痛點POV               腦力激盪多樣點子  原型測試快速迭代
```

### 2. 史丹佛大學 d.school 之五階段迭代流程

史丹佛設計學院 (Stanford d.school) 將設計思考具體化為五個相互回饋的動態步驟：
1. **同理心 (Empathize)**：走出辦公室，透過深度訪談、沉浸式影子觀察 (Shadowing) 與使用者旅程地圖，感受使用者的情緒與未言明需求 (Unmet Needs)。
2. **需求定義 (Define)**：將蒐集到的巨量定性資訊進行聚類，提煉出**觀點陳述 (POV, Point of View)**，並將痛點轉化為激發性的問題句式：**「我們如何能夠...？ (HMW, How Might We...?)」**。
3. **創意發想 (Ideate)**：暫緩批判、鼓勵瘋狂點子、追求數量，運用 [[98_商業概念庫/scamper-method_奔馳法\|scamper-method_奔馳法]] 或跨界借鑑，打破既定思考框架。
4. **製作原型 (Prototype)**：以極低成本、粗糙快速的實體模型（紙卡、樂高、線框圖 Wireframe），將抽象概念具象化，落實「思考不如動手做 (Think with your hands)」。
5. **實地測試 (Test)**：將原型帶回真實使用者面前觀察其互動反應，驗證假設並汲取反饋，迅速回到前面階段進行樞軸轉向 (Pivot)。

## 📊 傳統分析性思維 vs. 設計思考心智模式

| 比較構面 | 傳統商業分析思維 (Business Analytical Thinking) | 設計思考心智模式 (Design Thinking) |
| :--- | :--- | :--- |
| **底層邏輯** | 演繹 (Deduction) 與歸納 (Induction)，依賴歷史數據。 | 溯因推論 (Abduction)：「如果世界是這樣，將會如何？」 |
| **出發點** | 企業內部資源、技術規格、現有市調報告。 | 用戶真實情感、隱性未滿足痛點、生活極端情境。 |
| **對待失敗** | 視失敗為績效指標瑕疵，竭力透過縝密計畫避免風險。 | **「早點失敗、頻繁失敗、低成本失敗 (Fail Fast, Fail Cheap)」**。 |
| **運作流程** | 線性瀑布式 (Waterfall)：規格定義 $\rightarrow$ 開發 $\rightarrow$ 上市。 | 循環迭代式 (Iterative)：快速建立原型 $\rightarrow$ 測試 $\rightarrow$ 重構。 |

## 🏢 企業實戰案例：IDEO 為高露潔重塑電動牙刷

### 1. 商業挑戰與市場盲點
全球口腔護理巨頭高露潔 (Colgate) 試圖為兒童開發全新電動牙刷。傳統市場研究團隊認為：兒童的手比成人小很多，因此牙刷握柄應該設計得「更細、更短、更小巧」，但產品上市後銷量極其慘淡。

### 2. 設計思考的同理觀察
IDEO 團隊並未仰賴問卷調查，而是帶著攝影機進駐數十個家庭，現場觀察 4~8 歲孩童早晨刷牙的真實行為：
- **關鍵痛點洞察 (In-depth Insight)**：成人刷牙是以手指關節靈活轉動握柄，因此握柄需要扁平纖細；但幼童的手部精細小肌肉尚未發育完全，他們刷牙是用**整隻手握拳抓握**！過細的握柄在孩子手中不斷打滑旋轉，讓刷牙變得極度挫折痛苦。
- **原型與測試**：IDEO 團隊立刻以軟泥捏出極粗、具備凹凸防滑軟膠的「胖胖握柄 (Fat Grips)」，並讓孩童現場試刷。孩童立刻能穩固抓握並自主刷牙。
- **成果**：高露潔推出厚實握柄的 Actibrush 兒童牙刷後，第一年銷量突破數千萬支，成為全美最暢銷的兒童電動牙刷。

## ⚠️ 經理人常見盲點與治理陷阱

1. **「便利貼劇場 (Post-it Theater)」形式主義**：將設計思考簡化為週末工作坊的頭腦風暴與貼滿會議室的便利貼，工作坊結束後一切回歸官僚體系，既不打造實體原型，亦未在組織內部授權跨功能團隊進行試錯。
2. **陷於「人性渴望」而忽視「商業可行與單位經濟」**：設計出顧客交口稱譽、體驗極致但製造成本高達天價或商業模式無法打平的產品，最終因違反 Viability 而走向破產。
3. **過度將「同理心」等同於「直接聽顧客說什麼」**：亨利·福特曾言：「若當年我問顧客想要什麼，他們只會說想要一匹更快的馬。」設計思考的同理是發掘顧客深層的未言之需（更快速便捷的交通），而非直接抄襲顧客提出的表面解方。

## 🎯 高階經理人決策檢核清單

- [ ] 本公司的研發與產品團隊，每月是否花費足夠時間在第一線觀察真實用戶的實際行為與痛點？
- [ ] 專案團隊是否能清晰定義出具備洞察力的 POV 與「我們如何能夠 (HMW)」陳述？
- [ ] 組織文化是否允許並鼓勵員工在 48 小時內打造粗糙原型進行低成本測試，而非花費半年撰寫冗長的企劃書？
- [ ] 新產品概念是否同步通過了 Desirability (用戶渴望)、Feasibility (技術可行) 與 Viability (財務存續) 的三重檢驗？
- [ ] 是否已打破部門穀倉 (Silo)，讓工程、行銷、財務與設計人員共同組成跨敏捷團隊進行協同創新？
