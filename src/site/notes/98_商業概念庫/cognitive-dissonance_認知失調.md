# 認知失調 (Cognitive Dissonance)

## 一、 核心概念與理論源流

### 1. 理論奠基：費斯汀格 (Leon Festinger) 的劃時代學說
**認知失調 (Cognitive Dissonance)** 由美國著名社會心理學家里昂·費斯汀格 (Leon Festinger) 於 1957 年在其經典著作《認知失調理論》（*A Theory of Cognitive Dissonance*）中提出。

該理論指出：
> **當個體同時持有兩種在心理上相互矛盾、互不相容的認知（如信念、價值觀、態度、已知客觀事實），或者個體的行為與其內在信念發生衝突時，會產生一種極度不愉悅的心理緊張與情緒衝突狀態，稱為「失調 (Dissonance)」。由於這種緊張感令人難以忍受，個體會具備極強烈的動機去主動「消除、減少或合理化」這種失調，以重獲心理平衡。**

費斯汀格在其著名的「1 美元 vs. 20 美元」經典實驗中證實：只拿到 1 美元微薄報酬去做枯燥任務的受試者，為了消除「我出賣良心說謊」與「我只拿了 1 美元」之間的劇烈認知失調，大腦主動扭曲自己的信念，向別人宣稱「這項任務其實滿有趣的」；反觀拿到 20 美元的受試者，因有足夠的外在金錢補償（外在歸因充分），反而坦率承認任務確實無聊透頂。

```
【認知失調調解心智路徑】
認知 A：「我是一位卓越精明的 CEO」
          ↕ [產生強烈失調緊張感 (Dissonance Tension)]
認知 B：「我剛主導了一項虧損 50 億的失敗併購」
          │
          ▼
【大腦本能消除途徑】（通常選擇代價最小的路徑）：
1. 改變行為：承認失敗並停損（心理痛苦代價最高，經理人往往避開）
2. 改變認知：否認客觀事實（「這筆投資現在虧損，但放眼十年是戰略佈局」）
3. 增加諧和認知：尋找外在替罪羊（「若非俄烏戰爭爆發，這項收購早已獲利」）
```

## 二、 決策架構與數理機制

### 1. 決策後失調 (Post-Decision Dissonance) 與承諾升級
在商業決策中，認知失調是造成經理人深陷**[[sunk-cost_沉沒成本|沉沒成本謬誤]]**與**承諾升級 (Escalation of Commitment)** 的底層心理驅動力。

設決策者在兩個難分高下的方案 $X$ 與 $Y$ 中作出了不可逆的重大選擇（選 $X$ 棄 $Y$）：
1. **失調量大小模型**：費斯汀格指出，決策後失調的總量 $D$ 與以下變數成正比：
   
$$
D = \frac{\sum \text{重要性} \times \text{未選方案 } Y \text{ 的優點} + \sum \text{重要性} \times \text{已選方案 } X \text{ 的缺點}}{\sum \text{已選方案 } X \text{ 的優點}}
$$

2. **自欺與自圓其說 (Spreading of Alternatives)**：為了降低失調量 $D$，決策者在決策後會主動提升對方案 $X$ 的正面評價，同時在心理上貶低被放棄方案 $Y$ 的吸引力。
3. **加碼下注的惡性循環**：當方案 $X$ 在執行過程中面臨虧損時，承認錯誤意味著全盤否定先前的自我認同（引發極致失調）。為了保護自尊，經理人選擇持續注資追加預算（Doubling Down），企圖透過「最終翻盤」來證明自己最初的英明。

### 2. 經理人面對商業失調的四種心理防禦機制

| 防禦機制形態 | 心理運作模式 | 企業高管典型話術 | 組織營運危害 |
| :--- | :--- | :--- | :--- |
| **主動合理化 (Rationalization)** | 重新框架失敗的定義，將虧損美化為學費 | 「這不叫虧損，這叫為未來生態系繳交的戰略門票。」 | 專案無法停損，資源被持續黑洞式吞噬 |
| **淡化與縮小 (Trivialization)** | 將關鍵危機指標貶低為微不足道的小事 | 「離職員工只是抗壓性不足，不影響大局。」 | 忽視核心人才大量流失的警訊 |
| **反向尋求驗證 (Selective Reassurance)** | 主動尋找同溫層專家為自己背書 | 「某某大師在演講中也強調了長期主義的價值。」 | 與客觀市場數據徹底脫節，深陷[[confirmation-bias_確認偏誤|確認偏誤]] |
| **自我肯定補償 (Self-Affirmation)** | 在其他無關領域炫耀成就以掩蓋失落 | 「雖然這個新產品沒賣好，但我們的 ESG 評級全美第一。」 | 模糊商業競爭的本質焦點 |

## 三、 企業真實實務個案

### 1. 柯達 (Kodak) 面對數位攝影專利的認知失調悲劇
1975 年，柯達工程師史蒂夫·薩森 (Steve Sasson) 發明了全球第一台手持數位相機。然而，柯達高層卻陷入了長達數十年的認知失調：
- **致命的認知衝突**：
  - 認知 A：「柯達是全球化學膠卷的霸主，膠卷與相紙毛利率高達 70% 至 80%。」
  - 認知 B：「數位技術將消滅實體膠卷，且不依賴化學沖洗耗材。」
- **消除失調的自欺行為**：柯達管理層無法接受自己畢生經營的膠卷帝國將化為烏有。為了消除失調，高層將數位相機視為「無膠卷低畫素的昂貴玩具」，並告訴發明人：「這項技術很酷，但千萬不要告訴任何人。」
- **結果**：柯達利用傳統相機的巨額獲利持續掩蓋失調，延誤了轉型數位感光元件與雲端影像的先機，最終於 2012 年申請破產。

### 2. 惠普 (HP) 以 111 億美元收購 Autonomy 的巨額減記
2011 年，惠普時任 CEO 李艾科 (Leo Apotheker) 為了擺脫低利潤的 PC 硬體業務，宣布以 111 億美元（溢價高達 79%）收購英國軟體公司 Autonomy：
- **交易後的失調壓力**：交易完成不久，內部審計與告密者揭露 Autonomy 涉嫌嚴重的財務造假與營收灌水。
- **管理層的自圓其說**：新任管理層初期為了維護惠普聲譽與收購的正當性，極力粉飾太平，宣稱雙方正在實現「龐大的大數據軟硬整合價值」。
- **被迫清算**：僅僅一年後，惠普不得不認列高達 **88 億美元的商譽與資產減記**，其中 50 億美元直接歸咎於會計詐欺。認知失調導致管理層在盡職調查與初期整合中對顯而易見的財報破綻視而不見。

## 四、 經理人反思與行動檢核清單

```
                               對抗認知失調的治理架構
┌─────────────────────────┬─────────────────────────┬─────────────────────────┐
│     1. 決策與覆盤分離   │     2. 預設停損安全閥   │     3. 擁抱心理安全感   │
│ 審核者不得是當初立案者  │ 簽約時白紙黑字寫死停損點│ 鼓勵認錯，獎勵及時止血  │
└─────────────────────────┴─────────────────────────┴─────────────────────────┘
```

### Executive Decision Checklist
- [ ] **決策與審計人格隔離**：評估重大專案是否該終止或追加投資時，主持覆盤委員會的高管是否「完全未曾參與當初的立案與投資決策」？
- [ ] **事前停損門檻 (Pre-committed Stop-Loss)**：在專案啟動時，是否白紙黑字寫明客觀停損指標（如「若兩年後 MAU 未達 50 萬或虧損逾 3,000 萬立即關閉」），防止事後心理失調自圓其說？
- [ ] **心理安全感與認錯獎勵**：組織內部是否真正營造出允許「公開承認錯誤」的文化？當主管坦承決策失誤並即時止血時，是遭到懲處還是獲得理性治理讚譽？
- [ ] **沈沒成本切割訓練**：在評估後續注資時，團隊是否嚴格遵循「**不考慮已花費的一分一毫，僅比較未來增額現金流與增額成本**」的財務紀律？
- [ ] **外部客觀估值定錨**：對於長期虧損的轉投資子公司，是否定期聘請第三方獨立會計師與投行進行無偏見的公允價值審計，打破內部高管的自欺幻象？
