# 燒錢率 (Burn Rate)

## 📌 概念核心定義

**燒錢率 (Burn Rate)**，在企業財務管理與創業投資中，指一家尚未實現現金流自我平衡的新創企業或成熟企業的新事業部，在特定期間內（通常以**「每月」**為計量單位），**淨消耗其銀行帳戶現金儲備的流出速度**。

燒錢率直接決定了企業的生命長度——**現金跑道 (Cash Runway)**。對於高成長企業而言，創立初期本質上就是一場「現金消耗速度與價值創造速度的極限賽跑」：企業必須在現金跑道消耗殆盡、撞上「歸零死線 (Zero Cash Date, ZCD)」之前，成功跑通獲利的商業模式，或達成能夠說服下一輪投資人進場注資的關鍵業務里程碑。

```
           【現金存量與燒錢率水箱模型】
┌──────────────────────────────────────────────┐
│  銀行現金儲備 (Cash Reserves)                 │
│  (例: $3,000,000 USD)                        │
└──────────────────────┬───────────────────────┘
                       │
       毛支出流量      │  銷貨收現流入 (Inflow)
      (Gross Burn)     ▼  (例: $50,000 / 月)
      ($200,000 / 月)  │
                       │
                       ▼ 淨流出差額
┌──────────────────────────────────────────────┐
│  【淨燒錢率 (Net Burn Rate)】                 │
│  = $200,000 - $50,000 = $150,000 / 月        │
└──────────────────────┬───────────────────────┘
                       │
                       ▼ 決定生存極限
┌──────────────────────────────────────────────┐
│  【現金跑道 (Cash Runway)】                   │
│  = $3,000,000 / $150,000 = 20 個月           │
└──────────────────────────────────────────────┘
```

## 🔬 數理模型與核心計算公式

### 1. 毛燒錢率 vs. 淨燒錢率

#### (1) 毛燒錢率 (Gross Burn Rate)
企業每個月實際發生的**全體營業現金支出總和**（完全不考慮任何營收流入）：

$$\text{Gross Burn Rate} = \text{當月薪資支出} + \text{租金} + \text{雲端伺服器} + \text{行銷廣告} + \text{其他營運開銷}$$

> [!NOTE]
> 毛燒錢率衡量的是企業的**「剛性成本結構承諾」**。即使當月營收瞬間崩跌為零，企業每個月仍必須硬性支付的最低生存付現成本。

#### (2) 淨燒錢率 (Net Burn Rate)
企業每個月帳面現金的**實質淨減少額**：

$$\text{Net Burn Rate} = \text{Gross Burn Rate} - \text{當月實體銷貨現金流入 (Cash Inflows)}$$

### 2. 現金跑道 (Cash Runway) 與歸零死線 (Zero Cash Date)

$$\text{Cash Runway (Months)} = \frac{\text{當前可用現金及約當現金總額}}{\text{平均月淨燒錢率 (Monthly Net Burn)}}$$

$$\text{Zero Cash Date (ZCD)} = \text{當前日期} + \text{Cash Runway}$$

## 📊 矽谷教父保羅·格雷厄姆 (Paul Graham) 的生存二元矩陣

Y Combinator 創辦人 Paul Graham 提出了震撼創投界的「預設狀態」判斷法：

```
       營收增長速度 (Growth Rate)
             ▲
             │
   【預設存活 (Default Alive)】
   按照當前營收增長斜率，
   在現金燒盡前即可實現現金流打平！
─────────────┼────────────────────────► 現金跑道 (Runway)
   【預設死亡 (Default Dead)】
   即使保持增長，但在打平之前
   現金就會先行燒乾！必須仰賴下一輪融資！
             │
```

| 狀態類別 | 判斷準則 | 經理人戰略主動權 |
| :--- | :--- | :--- |
| **預設存活 (Default Alive)** | 現有現金跑道足以支撐到公司跨過損益平衡點。 | **具備完全定價權**。可以從容與 VC 談判，甚至拒絕不平等條款，按自身節奏成長。 |
| **預設死亡 (Default Dead)** | 按照目前軌道，在達到收支平衡前現金必將耗盡。 | **喪失談判籌碼**。若資本市場遭遇寒冬無法及時融資，公司將在幾個月內瞬間暴斃。 |

## 🏢 企業實戰案例：2022 年資本寒冬與全球科技業「斬斷燒錢率」

### 1. 商業背景
2020 至 2021 年疫情寬鬆期間，全球科技新創沉浸於「零利率與狂熱估值」的派對中。新創公司普遍維持著每月數百萬美元的巨額淨燒錢率，瘋狂擴招工程師、補貼使用者。

### 2. 聯準會升息與燒錢率急凍
2022 年全球央行暴力升息，VC 募資驟降 70%，融資窗口全面關閉：
- **紅杉資本緊急發布《適應與生存 (Adapt to Survive)》警告**：明確告知所有投資組合企業——「資本派對已經結束，沒有人會來拯救你們，立刻削減燒錢率，確保至少擁有 **24 至 36 個月** 的現金跑道！」
- **Meta (Facebook) 的實踐**：Mark Zuckerberg 宣布 2023 年為「效率之年 (Year of Efficiency)」，果斷裁撤 21,000 名冗餘員工，大幅削減非核心元宇宙研發開銷，每月燒錢率驟降數十億美元。
- **成果**：Meta 自由現金流創歷史新高，股價自低谷暴漲超過 300%；而數百家未能及時縮減燒錢率的中小型新創則在 2023 年排隊宣布破產清算。

## ⚠️ 經理人常見盲點與治理陷阱

1. **混淆「會計損益 (P&L Loss)」與「現金淨燒錢率 (Net Burn)」**：損益表上的虧損包含非現金折舊，且未包含資本支出 (CapEx) 與營運資金佔用。經理人若只看損益表，往往忽視了應收帳款拖延與伺服器預付硬體正在以兩倍速度燒乾銀行現金。
2. **在跑道僅剩 3 個月時才啟動融資**：機構創投從接觸、初審、盡職調查到款項入帳，平均需時 **4 至 6 個月**。若創辦人等到現金僅剩 3 個月才開始找錢，投資人將嗅到死亡氣息，開出苛刻的「降輪 (Down Round)」甚至逼迫賤賣。
3. **過度樂觀假設「下個月營收就會暴增」**：在計算跑道時，使用幻想中的營收預測來人為縮小未來的淨燒錢率，直到現金見底才驚覺營收未達標。

## 🎯 高階經理人決策檢核清單
