# 基本歸因謬誤 (Fundamental Attribution Error)

## 一、 核心概念與理論源流

### 1. 理論奠基：羅斯 (Lee Ross) 的社會心理學經典
**基本歸因謬誤 (Fundamental Attribution Error, FAE)** 由社會心理學家李·羅斯 (Lee Ross) 於 1977 年在其論文《直覺科學家及其缺點：歸因過程中的扭曲》（*The Intuitive Psychologist and His Shortcomings*）中正式命名並系統化。

該理論揭示了人類認知中的一種深層、系統性的歸因偏差：
> **在解釋他人行為或績效結果時，人們傾向於過度高估「內在特質、人格、能力、動機（Dispositional Factors）」的影響，而嚴重低估外部「情境、體系、組織制度、運氣與環境約束（Situational Factors）」的作用。**

羅斯的經典問答秀實驗（Quiz Game Experiment）充分證實了這點：受試者被隨機指派為「提問者」或「參賽者」。提問者利用自己的專業盲區撰寫冷僻難題，使參賽者頻頻答錯。然而，無論是旁觀者還是參賽者本人，均一致評估提問者「智商極高、知識淵博」，完全忽視了提問者之所以顯得聰明，純粹是源於**隨機分配的角色情境特權**。

### 2. 行動者-觀察者不對稱 (Actor-Observer Asymmetry)
當基本歸因謬誤與自身的失敗交織時，進一步演化為著名的**行動者-觀察者偏誤**：
- **當我看別人失敗時（我是觀察者）**：「他業績沒達標，是因為他不夠努力、專業能力不足、溝通有問題。」（特質歸因）
- **當我自己失敗時（我是行動者）**：「我業績沒達標，是因為市場突然升息、供應鏈斷鏈、跨部門支援不力。」（情境歸因）

```
                     解釋他人結果 (觀察者視角) ──> 過度歸因於「內在特質與能力」
行為與績效結果 ──┤
                     解釋自身結果 (行動者視角) ──> 過度歸因於「外部情境與運氣」
```

## 二、 決策架構與數理機制

### 1. 凱利共變歸因模型 (Kelley's Covariation Model)
社會心理學家哈羅德·凱利 (Harold Kelley) 提出理性歸因應同時審查三個獨立維度，唯有經過結構化比對，才能精準定性問題：

設事件為「員工 A 在專案 X 遭遇失敗」：
1. **區別性 (Distinctiveness)**：該員工在其他專案表現如何？
   - 若在其他專案均表現優異（高區別性），則問題很可能源於專案 X 的**情境/外部難題**。
2. **一致性 / 共識度 (Consensus)**：其他員工面對專案 X 時是否同樣遭遇失敗？
   - 若所有人都無法搞定（高一致性），則顯然是**環境/系統性缺陷**而非個人能力不足。
3. **一貫性 (Consistency)**：該員工在類似情境下是否總是失敗？
   - 若僅此一次突發失常（低一貫性），應歸因於**特殊偶發事件或運氣**。

在企業實務中，深陷 FAE 的經理人往往跳過這三維度的客觀共變檢驗，直接將任何失敗快速貼上「態度不端正」或「能力不適配」的簡化標籤。

### 2. 基本歸因謬誤在企業治理中的危害矩陣

| 管理情境 | FAE 典型管理盲區 | 錯誤管理處方 | 制度性危害 |
| :--- | :--- | :--- | :--- |
| **績效考核 (Performance Review)** | 將部門業績落後完全歸咎於部門主管領導不力 | 頻繁撤換主管，不解決核心產品與定價問題 | 治標不治本，組織動盪，核心人才流失 |
| **品質與工安事故** | 事故發生後認定是「一線操作員粗心違規」 | 懲處個別員工，要求全員「加強注意」 | 忽視防呆機制 (Poka-Yoke) 與疲勞排班漏洞，事故必然重演 |
| **研發創新專案受挫** | 認定專案負責人缺乏進取心與創業精神 | 扣減獎金，公開批評失敗者 | 摧毀組織創新文化，導致全員走向[[risk-return_風險與報酬權衡|風險厭惡]]與防禦性自保 |
| **高管造神與偶像化** | 將企業短期牛市中的獲利暴增完全歸功於明星 CEO 天才 | 發放天價股票期權，解除董事會監管制衡 | 滋生執行長獨裁與[[self-serving-bias_自利偏誤|自利偏誤]]，最終釀成重大爆雷 |

## 三、 企業真實實務個案

### 1. 波音 737 MAX 空難初期的「駕駛員特質歸因」甩鍋
2018 年印尼獅航 610 號班機與 2019 年衣索比亞航空 302 號班機相繼發生空難，造成 346 人死亡：
- **初期的 FAE 應對**：波音管理層與公關在初期將調查焦點引向「發展中國家飛行員培訓不足、未遵循手冊標準程序」，企圖將悲劇定性為特定飛行員個人的技術與應變特質問題。
- **真相大白**：美國 FAA 與各國航空安全委員會深入調查後發現，核心問題在於波音追求與舊款 737 共通認證以節省成本，在軟體中設計了具備災難性單點故障的機動特性增強系統 (MCAS)，且在手冊中對飛行員刻意隱瞞該系統的存在。
- **代價**：波音過度仰賴特質歸因推卸責任，不僅未能及時停飛檢修避免第二起空難，更引發全球監管機構信任危機，面臨數百億美元賠償與數年全球停飛。

### 2. 奇異公司 (GE) 廢除強制活力曲線 (Vitality Curve) 的反思
傑克·威爾許時代著名的「活力曲線」（強制將員工劃分為 20% 頂尖、70% 中堅、10% 淘汰的末位淘汰制）：
- **深陷 FAE 假設**：該制度假設一個團隊的產出落後，純粹是因為其中包含 10%「能力低下或態度怠惰」的人員，只要年年換血，團隊就能持續卓越。
- **系統性反噬**：在軟體工程與高複雜度專案中，許多後 10% 的員工往往是因為被指派承接歷史技術負債極重、維護困難的基建模組，或是因跨部門協同被卡死。
- **廢除與轉型**：在傑夫·伊梅特 (Jeff Immelt) 執政後期，GE 最終於 2015 年正式廢除該制度，轉向重視「持續回饋」與「系統障礙清除」，承認環境協同體系對個人產出的決定性影響。

### Executive Decision Checklist
- [ ] **歸因平衡測試**：當下屬未達成 KPI 時，我的第一反應是「他能力不行/不夠積極」，還是先檢查「市場環境、供應鏈支援與跨部門資源是否到位」？
- [ ] **無指責覆盤 (Blameless Post-Mortem)**：發生重大營運故障或客戶客訴時，覆盤會議是否嚴格禁止「追究個人責任」，而是聚焦於「我們當前的系統流程為何會允許這項錯誤發生？」
- [ ] **共變橫向檢驗**：在對業務主管開刀前，是否檢視了同產業其他競爭對手同期業績表現？若整個產業均衰退 30%，該主管下滑 10% 實為相對卓越表現。
- [ ] **高管激勵去個人化**：在給予高階管理層巨額分紅時，是否排除了「宏觀景氣順風（如原物料暴漲、降息潮）」所帶來的非主觀增量利潤？
- [ ] **防呆與賦能設計**：管理層是否將心力投入於「打造犯錯成本極低的防呆體系與工具賦能」，而非單純寄望於員工個人的道德自律與超凡警惕？
