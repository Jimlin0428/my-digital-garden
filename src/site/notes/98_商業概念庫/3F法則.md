# 3F法則 (Friends, Family, and Fools)

## 📌 概念核心定義

在創業金融學與早期天使投資領域，**3F法則 (Friends, Family, and Fools，即朋友、家人與天使狂熱者)** 指新創企業在僅有初步商業構想或粗糙雛形、尚未獲得任何機構創投 (VC) 或專業天使投資人青睞的**概念發想與極早期種子階段 (Pre-Seed)**，最主要且最具可取得性的**非正式股權融資管道**：
1. **家人 (Family)**：基於血緣親情與無條件信任，願意出資支持子女或親屬追逐夢想，對財務回報期待最低；
2. **朋友 (Friends)**：基於長期同儕情誼、人品認同與社交網絡關係提供小額資本；
3. **狂熱者 / 盲目信任者 (Fools)**：對該行業的底層技術與商業殘酷性缺乏專業認知，純粹被創辦人的熱血激情與宏大敘事所感染，追求高風險暴富幻想的非專業散戶投資人。

3F 資金通常是創業者邁出車庫的第一桶金。然而，它是一把極度危險的雙刃劍——若未透過現代公司法規進行嚴格的契約治理，**極易引發家庭倫理崩塌、友誼破裂，甚至製造出將後續機構 VC 嚇跑的「有毒股權結構 (Toxic Cap Table)」**。

│ 【原始 3F 資金來源】                                        │

└──────────────────────────────┬──────────────────────────────┘
                               │
                               ▼ 必須透過專業法律工具「消毒」！
┌─────────────────────────────────────────────────────────────┐
│ 【專業架構工具：未來股權簡單協議 (SAFE) 或 可轉換債券】     │

│  2. 簽署【投票權委託協議 (Voting Proxy)】                   │
│     (所有 3F 股東之股東會表決權 100% 委託創辦人行使)         │
│  3. 限制資訊揭露權 (避免親友干預日常微觀營運)               │
└──────────────────────────────┬──────────────────────────────┘
                               │

┌─────────────────────────────────────────────────────────────┐
│ 【乾淨健全的股權結構表 (Clean Cap Table)】                  │
│  機構創投 (VC) 願意進場，創辦人保持 100% 公司控制權        │
└─────────────────────────────────────────────────────────────┘

### 1. 拒絕「直接給予普通股」，採用 SAFE 延後定價
- **致命陷阱**：在公司剛成立時，父母給了 30 萬新台幣，創辦人隨意口頭承諾「給你們 20% 股權」。這意味著公司估值僅有 150 萬元，且股東名冊上多了一位完全不懂業務卻擁有 20% 否決權的親戚！
- **治理工具**：全數採用 Y Combinator 標準的 **SAFE (Simple Agreement for Future Equity)** 或可轉換公司債 (Convertible Notes)。明確約定：這筆資金在未來獲得專業機構 VC 投資時，自動按照「下一輪機構估值的八折 (20% Discount)」折算為無表決權特別股，完全消除早期定價的尷尬與親友衝突。

### 2. 投票權委託 (Voting Proxy) 與單一實體封裝 (SPV)
- 若有 10 位親友每人投資數萬元，在設立股權表時，絕不能讓這 10 個人各自成為直接登記股東；
- 正確做法是設立一家**「特殊目的實體 (SPV，如一家閉鎖性合夥企業)」**，將 10 位親友的資金封裝於該實體內部，由創辦人擔任唯一普通合夥人 (GP) 代表行使表決權，或在合約中明定所有 3F 股東將表決權無條件全權委託創辦人行使。

## 📊 3F 資金 vs. 專業天使 / 機構創投對照

| 評估維度 | 3F 融資 (Friends, Family & Fools) | 專業天使與機構創投 ([[98_商業概念庫/VC\|VC]]) |
| :--- | :--- | :--- |
| **投資動機** | 情感信任、人際關係、親情支持。 | 冷酷的商業回報、冪律分佈倍數期望。 |
| **盡職調查 (DD)**| 幾乎為零（不看財務模型、不審查代碼）。 | 深度盡調（查驗專利、訪談客戶、法律合規審核）。 |
| **附加價值** | 無法提供產業資源與管理智慧。 | 引入頂級客戶網絡、協助招募高管、指導戰略。 |
| **失敗後果** | **人情破裂、家庭反目、年夜飯反目成仇。** | 商業破產認賠、提列投資虧損，不影響個人情感。 |
| **平均單筆金額** | 數萬至數十萬新台幣（小額居多）。 | 數百萬至數千萬美元（機構級資本）。 |

## 🏢 企業實戰案例：傑夫·貝佐斯父母的 30 萬美元世紀豪賭

### 1. 商業背景
1995 年，貝佐斯辭去華爾街副總裁職位，準備在西雅圖車庫創立亞馬遜 (Amazon)。當時沒有任何一家傳統創投相信網路上能賣書，融資遭遇慘重打擊。

### 2. 父母的 3F 投資與專業防護
貝佐斯的母親 Jackie 與繼父 Mike Bezos 拿出了一生積蓄中的 **30 萬美元** 支持兒子：
- **創辦人的誠實警示**：貝佐斯在接受父母支票前，嚴肅且直白地告訴父母：**「這筆錢有 70% 的機率會徹底打水漂、全額歸零，請確保即使這筆錢賠光，也不會影響你們的晚年退休生活！」**
- **合規契約保護**：貝佐斯聘請專業律師起草正規的股權合約，確保父母享有法定股權份額，同時完全由貝佐斯全權掌控公司營運表決權。
- **神話級回報**：隨著亞馬遜成為全球電商與雲端萬億巨擘，其父母持有的股權價值一度膨脹至 **數百億美元**，名列全美最富有的家族之一，成為 3F 融資史上最成功且最溫馨的傳奇典範。

## ⚠️ 經理人常見盲點與治理陷阱

1. **「把公款當家產」的財務不分陷阱**：接受父母資金後，未將其存入嚴格監管的企業專用帳戶，創辦人個人開銷與公司營運開銷混為一談，違反公司法規定，引發嚴重的稅務稽查風險。
2. **「有毒股權表 (Toxic Cap Table)」嚇退後續 VC**：親友團持有高達 30% 以上的普通股，且在合約中要求「每筆超過 50 萬元的合約需經叔叔簽字同意」，導致機構創投進行法務盡職調查時直接將其列為不可投資標的。
3. **過度樂觀承諾「穩賺不賠」**：創辦人為了向非專業朋友募資，誇大其詞保證「保證一年翻三倍、絕對不會虧損」，一旦公司面臨清算，直接觸犯刑法之背信詐欺罪。

## 🎯 高階經理人決策檢核清單

- [ ] 我們在向親友募集資金前，是否已經明確警示該筆投資存在 **80% 以上全額歸零** 的極高風險？
- [ ] 親友投入的資金，是否是其「即使全部虧損也不會影響基本生活」的閒置資金？
- [ ] 所有 3F 資金是否皆採用了 **SAFE 或可轉換公司債** 等標準法律工具，完全避免早期股權定價糾紛？
- [ ] 股東名冊上是否落實了「表決權集中架構（Voting Proxy 或 SPV）」，確保創辦人擁有 100% 絕對經營主導權？
- [ ] 我們是否已經與親友劃清界限，約定不將公司的商業經營摩擦帶入私人家庭社交場合？
