# 折舊 (Depreciation)

## 📌 概念核心定義

在財務會計與公司理財中，**折舊 (Depreciation)** 指企業針對具有有限耐用年限的**有形固定資產（包含廠房、機器設備、運輸工具、伺服器機房等）之取得成本，在其估計經濟耐用年限內，依循系統性與合理的方法進行分期攤提與費用化的會計程序**。

在實務中，非財務背景經理人最常產生的根本誤解，就是以為折舊「伴隨著現金流出」或「折舊提列代表企業正在存錢買新設備」。在現代公司理財與資本預算中，折舊的本質是一項**「純粹的非現金費用 (Non-Cash Expense)」**；其對企業最具爆發力的財務價值，在於其作為合法的稅前扣除項目，為企業帶來了龐大的**「折舊抵稅效應 (Depreciation Tax Shield)」**，直接增強了企業的營運活動現金流量 (CFO) 與專案淨現值 (NPV)。

```
【折舊的財務本質與現金流傳導機制】

             固定資產採購支出 (CapEx) ◄── (在 t=0 發生【唯一一次】真實現金流出！)
                       │
                       ▼ 資本化進入資產負債表
             固定資產帳面原值 (PP&E)
                       │
                       ▼ 每年系統性攤提 (無任何現金流出！)
┌─────────────────────────────────────────────────────────────┐
│ 【每年損益表列報：折舊費用 (Depreciation)】                 │
│  • 扣減當期營業利潤 (EBIT)                                   │
│  • 使得應納所得稅減少：【折舊抵稅額 ＝ Dep × 所得稅率 t】    │
└──────────────────────────────┬──────────────────────────────┘
                               │
                               ▼ 實體現金流增額
┌─────────────────────────────────────────────────────────────┐
│ 【實質營業現金流增加 (CFO Boost)】 ＝ ＋ (Depreciation × t) │
└─────────────────────────────────────────────────────────────┘
```

## 🔬 折舊方法論對照與折舊抵稅模型

### 1. 兩大核心折舊計算方法

#### (1) 直線折舊法 (Straight-Line Method)
將資產的可折舊總額（原始成本 $-$ 預期期末殘值）在耐用年限內平均分攤：

$$\text{Annual Depreciation} = \frac{\text{原始成本 (Cost)} - \text{預估殘值 (Salvage Value)}}{\text{估計耐用年限 (Useful Life } n)}$$

- **特點**：計算極度簡單、各年度損益負擔平穩，為全球大多數上市公司財務報表編製的首選。

#### (2) 雙倍餘額遞減法 (Double-Declining Balance, DDB) / 加速折舊法
以直線折舊率的兩倍，乘以每期期初的「資產帳面淨值 (Book Value)」（前期不扣除殘值，直至最後幾年調整）：

$$\text{Depreciation Rate} = \frac{2}{n}$$

$$\text{Annual Depreciation}_t = \text{期初帳面淨值}_t \times \left( \frac{2}{n} \right)$$

- **特點**：在資產使用壽命的前半段提列極大額度的折舊，後期折舊額迅速遞減。

### 2. 資本預算折舊抵稅模型 (Depreciation Tax Shield Formula)
在計算專案的營業活動現金流量 (OCF) 時，標準頂級底層公式為：

$$OCF = (\text{Revenue} - \text{Cash Expenses}) \times (1 - t) + \underbrace{\text{Depreciation} \times t}_{\text{折舊抵稅效應 (Tax Shield)}}$$

> [!IMPORTANT]
> **加速折舊的現值優勢定理**：雖然在資產的整個生命週期中，直線法與加速折舊法的「總折舊金額完全相同」；但由於**貨幣時間價值 ([[time-value-2_貨幣時間價值]])**，**加速折舊法將巨額抵稅現金流大幅提前至前幾年實現 (Front-loading)**，經折現後所創造的稅盾現值遠高於直線法，能實質顯著提升專案的淨現值 (NPV)！

## 📊 直線折舊 vs. 加速折舊 (MACRS) 之財務影響對比

| 評估維度 | 直線折舊法 (Straight-Line) | 加速折舊法 (Accelerated / MACRS) |
| :--- | :--- | :--- |
| **會計盈餘表現** | 前期帳面淨利較高、較平穩，有利於美化財報 EPS。 | 前期帳面淨利大幅被壓低，後期淨利才逐步回升。 |
| **所得稅繳納節奏** | 前期繳納較多所得稅，後期繳稅平穩。 | **前期大幅合法節稅延後繳稅**，後期繳稅增加。 |
| **實質現金流量現值** | 稅盾現金流分布均勻，折現現值較低。 | **前期釋放充沛現金流，稅盾折現現值最大化 (NPV 最佳)**。 |
| **實務應用定位** | 廣泛用於**對外公開財務報告 (Financial Reporting)**。 | 廣泛用於**政府法定稅務申報 (Tax Return)** 與資本預算。 |

## 🏢 企業實戰案例：台積電 (TSMC) 的高額折舊壓力與現金流神話

### 1. 商業情境
晶圓代工是典型的極端重資產設備密集產業。台積電每年的資本支出高達 300 億至 400 億美元，資產負債表上累積了數兆元新台幣的先進半導體機台與無塵室。

### 2. 折舊會計的實務運作
台積電在會計政策上採取保守且審慎的折舊年限：
- 大多數昂貴的半導體生產設備採用 **5 年直線折舊法**（ASML EUV 機台即使能運轉 10 年，台積電亦在 5 年內全額提列折舊完畢）。
- **每年折舊規模**：台積電每年的折舊費用高達 **新台幣 4,000 億至 5,000 億元**！
- **財務雙面效應**：
  1. 每年數千億元的巨額折舊費用，使得帳面營業利益受到沉重壓抑；
  2. 但在現金流量表上，這 5,000 億元折舊**全額被加回至營業活動現金流 (CFO)**，搭配其龐大的折舊抵稅效應，讓台積電每年產生的實質現金流甚至遠超其帳面本期淨利，支撐其無須借貸即可持續進行下一代 2 奈米廠房的連續重置。

## ⚠️ 經理人常見盲點與治理陷阱

1. **「延長折舊年限」操縱短期盈餘 (Earnings Manipulation)**：某些陷入虧損的企業經理人，透過更改會計估計，將原本 5 年折舊的機器強行延長為 10 年，使每年的折舊費用腰斬，人為粉飾帳面淨利。但這種把戲不產生任何一分實質現金流，反而遞延了稅盾效益。
2. **在專案評估中將折舊「當作現金流出」扣除**：在估算專案未來現金流時，既扣除了期初的設備購買 CapEx，每年又把非現金折舊當作費用扣除，犯下致命的**雙重計算陷阱 ([[double-counting-fallacy_雙重計算陷阱]])**。
3. **忽視殘值與處分資產稅務的互鎖**：在折舊年限終了時，若設備實際出售價格高於帳面殘值，產生的處分利得必須補繳稅款，經理人若未預先計入期末稅負，將高估期末殘值現金流。
