# 股東價值增加法 (Shareholder Value Added, SVA)

## 一、 核心定義與理論淵源
- **理論提出**：由西北大學凱洛格商學院教授阿爾弗雷德·拉帕波特（Alfred Rappaport）於其經典著作《創造股東價值》（Creating Shareholder Value）中奠定。
- **核心哲學**：傳統會計利潤（EPS、淨利）極易受到存貨評價、折舊攤提與一次性資產處分的人為操作；**真正的股東價值唯有基於「未來現金流量現值」方能真實衡量**。
- **數學定義**：
  $$	ext{SVA} = \Delta 	ext{預期未來營業現金流量現值} - \Delta 	ext{達成該預期所需投入之增額資本}$$

## 二、 七大關鍵價值驅動因子（The Seven Value Drivers）
拉帕波特將宏觀的價值創造拆解為微觀的經營指針：
1. **銷售額成長率（Sales Growth Rate）**：推升整體營收池。
2. **營業利潤率（Operating Profit Margin）**：本業定價權與成本控制。
3. **所得稅率（Cash Income Tax Rate）**：實質現金稅負與合法稅務籌劃。
4. **營運資金投資增額（Working Capital Investment）**：壓縮現金轉換週期（CCC），減少應收帳款與庫存積壓。
5. **固定資產投資增額（Fixed Capital Investment）**：謹慎控制資本支出（CapEx），追求高投資效益。
6. **加權平均資金成本（WACC）**：最優化資本結構，極小化貼現率。
7. **價值成長期（Value Growth Duration, VGD）**：企業競爭優勢能抵擋對手競爭並創造超額報酬的持久年限。

## 三、 經理人管理意涵
- SVA 將抽象的資本市場目標轉化為各事業部日常可追蹤的營運指標，是推行價值導向管理（Value-Based Management, VBM）的最佳量化工具。
