# 每日結算制度 (Daily Settlement / Mark-to-Market)

## 一、 核心概念與理論源流

### 1. 理論定義：消除信用累積的動態清算機制
**每日結算制度 (Daily Settlement System)**，在金融工程與衍生品實務中又稱為**逐日盯市 (Mark-to-Market, MTM)** 或**按市值計價制度**。它是現代期貨與集中結算衍生品市場運行的基石架構。

其核心制度邏輯在於：
> **「在每日交易結束後，集中清算所 (Clearinghouse / CCP) 依據全市場統一公佈的『結算價格 (Settlement Price)』，重新評估所有未平倉合約部位的當日浮動損益，並在當晚將浮動損益轉化為實際的現金損益劃撥，從帳戶現金餘額中直接扣除虧損或劃入盈餘。」**

這一制度從根本上重塑了信用風險的結構：
- **截斷跨期信用風險累積**：傳統的場外遠期合約 (Forward Contract) 通常等到數月乃至數年後的到期日才一次性結算損益，這使得違約風險隨著合約期間與市場波幅無限累積。
- **重塑合約起點**：每日結算制度將一份長天期的期貨合約，實質拆解為**一系列每日到期並依結算價重新開倉的「一日合約」**，每天將合約潛在違約曝險歸零。

---

### 2. 集中結算所 (CCP) 與合約更替 (Novation)
每日結算制度的有效運作依賴於**集中交易對手清算所 (Central Counterparty, CCP)** 的存在。清算所透過法律上的 **合約更替 (Novation)** 程序介入市場交易：

```
+---------------------------------------------------------------------------------+
|                         合約更替 (Novation) 運作架構                            |
+---------------------------------------------------------------------------------+
  [原始交易狀態]：雙邊交易與複雜網狀信用曝險
      買方 (Buyer) <---------------- (雙向信用風險曝險) ---------------> 賣方 (Seller)
                                         |
                                         v
  [合約更替後]：集中結算所化身為「買方的賣方，賣方的買方」
      買方 (Buyer) <--- (買入合約) ---> [ 集中結算所 CCP ] <--- (賣出合約) ---> 賣方 (Seller)
                                         |
                       +-----------------+-----------------+
                       |                                   |
                       v                                   v
             [ 逐日盯市 MTM 結算 ]               [ [[margin-system_保證金制度|保證金動態防禦池]] ]
             每日現金淨額交割浮動損益            原始/變動保證金 + 違約互助基金
```

透過此機制，買方無需擔憂賣方的償債信用，賣方亦無需調查買方的財務背景。市場所有參與者僅需對清算所負責，將雙邊[[risk-2_交易對手風險|交易對手風險]]徹底轉化為標準化的結算所信用。

## 二、 數理模型與現金流清算演算

### 1. 每日損益計算與現金流方程式
設交易者持有第 $k$ 種期貨合約的多頭部位（Long Position）數量為 $Q$ 口，合約乘數為 $M$。
在第 $t$ 個交易日收盤時，結算所公告的官方結算價為 $P_t^{\text{settle}}$，前一交易日的結算價為 $P_{t-1}^{\text{settle}}$（若為當日新開倉合約，則為成交價 $P^{\text{trade}}$）。

當日浮動轉已實現損益（Mark-to-Market P&L, $\Pi_t$）計算公式為：
- **多頭部位損益**：
  $$\Pi_{t}^{\text{long}} = Q \times M \times (P_t^{\text{settle}} - P_{t-1}^{\text{settle}})$$
- **空頭部位損益**：
  $$\Pi_{t}^{\text{short}} = Q \times M \times (P_{t-1}^{\text{settle}} - P_t^{\text{settle}})$$

當日結算後的期末帳戶權益總額 ($E_t$) 演算為：
$$E_t = E_{t-1} + \Pi_t - \text{手續費及稅費} + \text{入金} - \text{出金}$$

### 2. 變動保證金 (Variation Margin) 的流動性移轉
若 $E_t < MM$（維持保證金），結算所會向經紀商及投資人索取**變動保證金 (Variation Margin, VM)**：
$$VM_t = IM - E_t$$
變動保證金的支付具有嚴格的剛性約束：
- **現金劃撥**：不同於原始保證金可使用高等級國債、外幣資產充抵，變動保證金通常**必須全額以法定現金 (Cash) 結算**。
- **清算時限**：通常在次日早晨銀行清算系統開放時（如美東時間 07:00 或台北時間 08:30 前）直接由專戶借記扣款。

> **財務意涵**：逐日盯市制度成功消滅了「信用違約風險」，但代價是**將長期的價格變動風險轉化為即時的「極短期現金[[risk-3_流動性風險|流動性風險]]」**。

## 三、 商戰歷史風暴：2020 年 WTI 原油「負油價」與逐日盯市穿倉慘劇

```
+-----------------------------------------------------------------------------------+
|               2020 年 4 月 20 日 WTI 原油期貨歷史性「負油價」事件                  |
+-----------------------------------------------------------------------------------+
|  [供需極度失衡]              [交割庫容量耗盡]             [結算價暴跌穿透地心]       |
|  全球疫情引發原油需求崩跌    庫欣 (Cushing) 儲油庫告急    5 月合約結算日前夕         |
|  沙俄價格戰產量激增       -> 實物交割成本高於原油價值  -> 多頭踩踏無力接貨           |
|  市場庫存逼近物理極限        每桶貼水倉儲費高昂           結算價收於 -37.63 美元/桶  |
+-----------------------------------------------------------------------------------+
                                         |
                                         v
+-----------------------------------------------------------------------------------+
|  [每日結算機制的破壞性展現]                                                       |
|  1. CME 提前修改交易系統代碼，允許負值交易與負值結算。                             |
|  2. 當晚 MTM 結算按 -37.63 美元執行：多頭投資人不僅本金全部虧光，反欠經紀商巨款。  |
|  3. 中國銀行「原油寶」產品因未在正常交易時間移倉，在 -37.63 結算價被強平，穿倉數十億元。|
+-----------------------------------------------------------------------------------+
```

### 1. 負價格的結算合法化
2020 年 4 月 20 日，WTI 原油 5 月期貨合約即將到期交割。由於全球新冠疫情封鎖導致航空與交通燃油需求停擺，美國俄克拉荷馬州庫欣地區的商業儲油罐已達物理極限，接貨實物原油的儲存成本高得難以想像。
芝加哥商業交易所 (CME) 提前一週調整交易系統參數，公告支持**「負價格報價與負價格結算」**。

### 2. 逐日盯市機制下的毀滅性穿倉
在結算日前最後兩小時，缺乏實物交割設施的金融多頭遭遇無情拋售，買盤斷層。合約價格跌破 0 美元後一路下墜，最終收盤結算價被釘死在**每桶 -37.63 美元**。
- **逐日盯市的殘酷執行**：當晚 CME 清算所嚴格依據 -37.63 美元的結算價執行 Mark-to-Market 現金劃撥。多頭部位的結算損失不僅吞噬了全部 100% 的原始保證金，更讓多頭投資者每桶倒貼近 40 美元現金。
- **中行「原油寶」穿倉慘案**：中國銀行發行的散戶結構化理財產品「原油寶」，因協議約定在合約到期日晚上 22:00 停止交易並依據 CME 官方結算價轉倉，未能及時在日內正值價位平倉。當 CME 結算價公告為 -37.63 美元時，系統自動依該價執行結算，導致數萬名投資者保證金全損，更背負數十億人民幣對銀行的穿倉欠款，引發重大金融監管調查與集體訴訟。

## 四、 遠期合約 (Forward) 與期貨合約 (Futures) 結算機制對比

企業在制定外匯與原物料避險策略時，經理人必須在「場外遠期」與「場內期貨」的結算特徵間進行權衡：

| 評估維度 | 場內期貨 (Futures) | 場外遠期 (Forward) |
| :--- | :--- | :--- |
| **清算與結算方式** | **每日結算制度 (Mark-to-Market)**，每日現金劃撥損益。 | **到期單一結算 (Settlement at Maturity)**，期間無現金流。 |
| **[[risk-2_交易對手風險|交易對手風險]]** | **極低**；由集中清算所 (CCP) 提供合約更替與信用擔保。 | **較高**；完全仰賴交易對手（商業銀行或企業）的單一信用。 |
| **[[risk-3_流動性風險|流動性與現金流管理]]** | **高度敏感**；需隨時準備流動現金因應每日變動保證金追繳。 | **極佳**；在合約存續期間不會產生盤中或盤後意外現金抽離。 |
| **會計與財報處理** | 每日市價波動直接反映於金融資產帳戶，公允價值損益透明。 | 需定期進行折現公允價值評價，但無實際現金流流出。 |
| **合約客製化彈性** | 低；交易規模、交割月份、計價幣別均為交易所標準化。 | 高；可完全根據企業採購與出貨收匯日期量身定制。 |

## 五、 經理人決策檢核清單 (Executive Checklist)

- [ ] **結算價確定規則覆核**：財務長與避險操盤手是否確切掌握交易標的在清算所的每日結算價計算規則（如：是收盤最後 1 分鐘加權平均價、最後 30 分鐘 VWAP，或是特定撮合價）？
- [ ] **T+0 / T+1 現金劃轉路徑通暢度**：企業開立於期貨經紀商的結算專戶，其外幣與本幣的即時劃撥通路（銀期轉帳系統）是否享有夜盤與極端時段的應急綠色通道？
- [ ] **合約到期移倉 (Rollover) 預警**：在期貨合約進入交割月前，是否有嚴格的自動移倉排程，以防因遺忘平倉而被捲入實物交割或非流動性結算泥淖？
- [ ] **穿倉責任保險與防禦條款**：委託外部資產管理機構或家族辦公室操作衍生品時，委外契約是否明確約定穿倉損失（Negative Equity）的風險分擔上限？
- [ ] **會計避險有效性動態測試**：根據 IFRS 9 / ASC 815 準則，每日盯市產生的未實現評價損益是否符合「高度有效避險」條件，以避免對季度損益表造成無謂的巨幅波動？
