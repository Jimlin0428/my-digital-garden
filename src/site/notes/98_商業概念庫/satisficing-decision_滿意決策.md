# 滿意決策 (Satisficing Decision)

## 一、 核心概念與理論源流

### 1. 理論提出：追求「夠好」而非「最佳」
**滿意決策 (Satisficing)** 一詞由諾貝爾經濟學獎得主赫伯特·西蒙 (Herbert A. Simon) 於 1956 年在其論文《理性選擇與環境結構》（*Rational Choice and the Structure of the Environment*）中創造。該詞是由英語單詞 **"Satisfy"（滿意）** 與 **"Suffice"（足夠）** 複合而成。

在真實世界的商業環境中，面對資訊不完全、時間限制與認知運算邊界的約束（即[[98_商業概念庫/bounded-rationality_有限理性\|有限理性]]），決策者無法如[[98_商業概念庫/rational-decision-model_理性決策模型\|古典理性模型]]所假設那樣，將全部可行方案一一列出並計算出數學上的「全域最佳解 (Global Optimal Solution)」。

因此，經理人依循「滿意化原則 (Satisficing Principle)」：
1. **設定抱負水準 (Aspiration Level)**：根據企業現況與戰略底線，預先設定一組明確的「可接受最低標準（Threshold / Criteria）」。
2. **循序搜尋方案 (Sequential Search)**：一次尋找並評估一個替代方案，而非同步比較所有可能方案。
3. **即時停止準則 (Stopping Rule)**：一旦發現某個方案能夠同時滿足預設的各項門檻標準，立即停止進一步搜尋，並採納該方案作為決策解（Satisficing Solution）。

```
【滿意決策執行流程】
設定抱負水準門檻 (Aspiration Level) 
       │
       ▼
啟發式循序搜尋方案 A_1 ──> 評估是否跨越門檻？ ──[否]──> 啟發式搜尋方案 A_2
       │ [是]
       ▼
立即停止搜尋 (Stop Search) ──> 採納 A_1 執行落地
```

## 二、 決策架構與數理機制

### 1. 抱負水準與終止搜尋數學模型
設決策問題包含 $m$ 個評估維度（如淨現值 $\text{NPV}$、投資回收期 $\text{Payback}$、策略適配度 $\text{Fit}$ 等）。決策者的抱負水準向量定義為：

$$
\mathbf{A} = (\lpha_1, \lpha_2, \dots, \lpha_m)
$$

當依序產出替代方案 $X_k = (x_{k1}, x_{k2}, \dots, x_{km})$ 時，方案採納準則為：

$$
\text{Adopt } X_k \iff x_{kj} \ge \lpha_j, \quad \forall j \in \{1, 2, \dots, m\}
$$

若當前環境找不到滿意解（即 $X_k$ 均無法達標），西蒙模型指出決策者將啟動**動態學習調整機制**：
- **下調抱負水準**：當長期搜尋失敗且成本急劇上升時，$\lpha_j(t+1) = \lpha_j(t) - \Delta \lpha$。
- **上調抱負水準**：當滿意解過於容易被找到時，決策者往往會提高門檻，促使未來追求更高標準。

### 2. 最大化者 (Maximizer) vs. 滿意者 (Satisficer) 心理與績效矩陣

根據哥倫比亞大學心理學家巴里·施瓦茨 (Barry Schwartz) 的研究，不同決策風格對經理人績效與幸福感具有顯著差異：

| 評估面向 | 最大化決策者 (Maximizers) | 滿意化決策者 (Satisficers) |
| :--- | :--- | :--- |
| **決策哲學** | 必須找到絕對最好的方案 (Only the Best) | 只要符合標準就足夠好 (Good Enough) |
| **方案搜尋廣度** | 竭盡全力窮盡所有選擇，反覆比對 | 依序搜尋，達標即止 |
| **決策時間與成本** | 極高，常陷入「分析癱瘓 (Analysis Paralysis)」 | 極低，具備高度敏捷性與執行力 |
| **事後後悔傾向** | 極高，反覆思索「是否有未選的更優解」 | 低，對符合標準的成果感到平靜與肯定 |
| **環境適應力** | 適合確定、封閉、靜態且變數極少的系統 | 適合高動態、不確定性高、快速變革的市場 (VUCA) |
| **管理風險** | 錯失市場先機、組織過度疲憊、機會成本沉沒 | 可能錯失潛在極限價值、容易落入平庸標準陷阱 |

## 三、 企業真實實務個案

### 1. 創投 (VC) 投資評估與募資篩選的滿意化機制
在頂級創投機構（如紅杉資本、Andreessen Horowitz）中，合夥人每年收到數千份商業計畫書，但投資人力與時間資源極其有限：
- **不可能的最佳化**：VC 絕不可能將全美數千家種子期新創進行全面的財務建模與橫向拉榜排序。
- **滿意化過濾門檻**：設定 3 項硬性抱負水準（Aspiration Levels）：
  1. 創辦團隊背景是否具備 10x 技術或產業經驗？
  2. 總體潛在市場 ([[TAM]]) 是否大於 10 億美元？
  3. 產品是否有驗證過的初期牽引力 (Traction) 或高用戶留存？
- **實務運作**：只要新創項目跨過這三個指標，即刻推入合夥人會議深入盡職調查；未達標者在 3 分鐘內予以淘汰。這正是滿意決策在資本配置上的經典應用。

### 2. 科技巨頭工程招募的「男管家門檻 (Bar Raiser)」
亞馬遜 (Amazon) 在高速擴張期，每年需招聘數萬名工程師與經理人：
- **最大化陷阱**：若試圖在全市場中找到「最頂尖的那一位天才」，招聘將徹底停擺。
- **滿意化制度**：建立「抬槓者 (Bar Raiser)」制度，規定候選人必須「至少在 50% 以上的領導力準則中優於目前團隊同級人員的平均水準」。
- **決策結果**：一旦面試委員會認定候選人跨過該門檻，即發放 Offer，而不去無休止地猜測下個月是否會出現履歷更漂亮的候選人。該機制支撐了亞馬遜數十萬員工的高速擴張而未稀釋人才密度。

## 四、 經理人反思與行動檢核清單

```
                               滿意決策動態平衡模型
┌─────────────────────────┬─────────────────────────┬─────────────────────────┐
│     1. 門檻標準清晰化   │     2. 動態抱負調整     │     3. 防平庸防線建立   │
│ 拒絕模糊直覺，明文化指標│ 根據環境反饋及時升降門檻│ 區分核心戰略與日常營運  │
└─────────────────────────┴─────────────────────────┴─────────────────────────┘
```

### Executive Decision Checklist
- [ ] **門檻量化明文化**：在啟動招募、供應商遴選或併購評估前，團隊是否已明訂清晰、不妥協的最低接受標準 (Thresholds)？
- [ ] **邊際成本警覺**：團隊是否正為了提升額外 5% 的方案完美度，而耗費了 80% 的額外時間與管理精力？
- [ ] **防範「平庸妥協」**：當前達標的方案，究竟是體現了高標準的滿意解，還是團隊因為厭倦搜尋而隨意調低抱負水準的產物？
- [ ] **戰略分層實踐**：在涉及核心企業競爭優勢的「非對稱核心專案」中，是否適度保留最大化思維；而在 80% 的執行層面落實滿意決策？
- [ ] **即時終止紀律**：當方案已完全符合既定條件時，管理層是否具備「按下執行鍵」的勇氣，堅決杜絕無效比價與推諉？
