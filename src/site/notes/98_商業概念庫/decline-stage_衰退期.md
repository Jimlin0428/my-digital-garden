# 衰退期 (Decline Stage & Strategic Endgame)

> **【核心決策摘要】**
> **衰退期（Decline Stage）** 是[[98_商業概念庫/product-life-cycle_產品生命週期\|產品生命週期]]與[[98_商業概念庫/industry-life-cycle_產業生命週期\|產業生命週期]]的終局階段。衰退的引爆點通常非源於同業競爭，而是源於**技術典範轉移（Technological Paradigm Shift）、消費者基本生活型態轉變或法規政策禁令**（如數位相機取代膠卷、電動車替代燃油車、串流影音取代實體 DVD）。管理學者凱瑟琳·哈里根（Kathryn Harrigan）與麥可·波特（Michael Porter）指出，面對衰退期，企業並非只能消極等死，而應在四大終局戰略中做出理性決策：**領導地位戰略（Leadership）**、**利基聚焦戰略（Niche）**、**收割收縮戰略（Harvesting）** 與 **迅速撤退變現戰略（Divestiture）**。

---

## 1. Harrigan & Porter 衰退期四大終局戰略 (The 4 End-Game Strategies)

```
                       產業殘存需求結構
                       有利 (仍有利基口袋)           不利 (全面斷崖式崩跌)
                     ┌─────────────────────────────┬─────────────────────────────┐
   企業在產業中      │ 【1. 領導策略 (Leadership)】│ 【3. 收割策略 (Harvesting)】│
   擁有核心優勢      │ • 收購退出者的資產與客戶    │ • 停止一切 CapEx 與研發投入 │
                     │ • 成為最後唯一寡占霸主      │ • 大幅提高毛利率, 榨乾現金  │
                     ├─────────────────────────────┼─────────────────────────────┤
   企業在產業中      │ 【2. 利基策略 (Niche)】     │ 【4. 迅速撤退 (Divest)】    │
   缺乏競爭優勢      │ • 放棄主流大眾市場          │ • 在資產徹底一文不值前賤價賣│
                     │ • 盤踞特定忠實死忠客群      │ • 將資本與人力轉移至新戰場  │
                     └─────────────────────────────┴─────────────────────────────┘
```

1. **領導策略（Leadership Strategy）**：
   若企業成本最低且資產負債表強韌，可透過降價驅逐對手，或以極低價格收購競爭者的客戶名單與維修業務，成為市場上「最後的生還者」，在縮小的市場中獨享壟斷利潤。
2. **利基策略（Niche Strategy）**：
   退出主流大眾競爭，專注於對價格不敏感、具有深厚情懷或特殊工藝需求的利基市場（如黑膠唱片在數位串流時代的逆勢翻紅）。
3. **收割策略（Harvesting Strategy）**：
   徹底凍結任何維護性資本支出與行銷預算，僅維持現有設備運轉，利用客戶的轉換黏性維持高定價，在最短時間內榨取最大自由現金流，隨後關廠。
4. **迅速撤退（Divest Strategy）**：
   在衰退初期、外部買方尚未充分意識到崩跌嚴重性時，及早將業務折價出售給樂觀買家，將套現資金轉移至高成長新興領域。
