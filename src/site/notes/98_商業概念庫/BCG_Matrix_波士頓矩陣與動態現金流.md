# 波士頓矩陣與動態現金流 (BCG Growth-Share Matrix)

> **商管核心價值**：波士頓顧問公司（BCG）提出的經典分析工具。其真正精髓不在於靜態的四象限劃分，而在於揭示不同事業單位間的「動態現金流循環傳導機制」，指導企業如何運用成熟金牛哺育未來明星。

---

## 一、 核心四象限架構

```text
  市場成長率 (Market Growth Rate)
      ▲
      │    【問號 (Question Marks)】           【明星 (Stars)】
      │    • 低市占 ✕ 高成長                  • 高市占 ✕ 高成長
  高  │    • 現金淨流出極大 (大失血)          • 營運現金高但 CapEx 巨大
      │    • 決策：選擇性大舉注資或處分        • 現金流大體平衡，奠定未來霸權
      │
      │    【狗 (Dogs)】                      【金牛 (Cash Cows)】
      │    • 低市占 ✕ 低成長                  • 高市占 ✕ 低成長
  低  │    • 虧損或微薄獲利                   • 產能折舊完畢，CapEx 遞減
      │    • 決策：清算、縮減或撤退           • ★ 源源不絕輸出自由現金流 ★
      └─────────────────────────────────────────────────────────────►
      低                                 高 (Relative Market Share)
                                         相對市場占有率
```

---

## 二、 動態現金流傳導法則

$$\text{自由現金流 (FCF)} = \text{營業活動現金流入 (OCF)} - \text{資本支出 (CapEx)}$$

1. **金牛 ➔ 哺育問號與明星**：金牛處於成熟期，超額 OCF 無須再大量投資擴產，應將資金無息調撥予成長期的「明星」與具潛力的「問號」；
2. **明星 ➔ 隨市場放緩蛻變為新一代金牛**；
3. **失血問號與衰退狗 ➔ 嚴格停損清算**，防止拖垮整體企業流動性。
