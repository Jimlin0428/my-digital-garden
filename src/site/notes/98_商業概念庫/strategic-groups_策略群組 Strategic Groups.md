# 策略群組 Strategic Groups

## 📌 概念定義
**策略群組**（Strategic Groups）是指在同一產業中，採用相似商業模式、戰略定位、產品範圍與資源配置組合的企業集合。策略群組分析可幫助經理人超越「全產業廣義競爭」，精準鎖定「直接競爭對手」。

---

## 🗺️ 策略群組地圖分析步驟

1. **選擇維度軸線**：挑選兩項不相關且具代表性的策略變數（如：價格/品質 vs 通路涵蓋度、R&D 投入 vs 產品線廣度）。
2. **定位企業座標**：將產業內主要玩家繪製於兩維度矩陣中。
3. **繪製氣泡圓圈**：氣泡大小代表各企業或群組的總營收市佔。
4. **識別[[98_商業概念庫/mobility-barriers_移動障礙 Mobility Barriers\|mobility-barriers_移動障礙 Mobility Barriers]]**：評估不同氣泡群組之間的跨越壁壘。
