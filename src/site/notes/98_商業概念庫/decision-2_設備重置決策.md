# 設備重置決策 (Equipment Replacement Decision)

## 📌 概念核心定義

**設備重置決策 (Equipment Replacement Decision)**，在企業資本預算與生產營運管理中，指針對現有尚在運轉但技術落後、維護維修成本高昂或產能受限的舊設備，**進行「繼續保留舊機運作 (Retain)」還是「斥資購置高效能新機汰換 (Replace)」的增額現金流量淨現值決策**。

設備重置決策是現代企業在技術迭代加速（如半導體製程演進、綠能節能減排、工廠自動化）環境下最常面臨的重資本配置場景。其核心評估哲學在於**「嚴格的增額分析法 (Incremental Cash Flow Analysis)」**——決策的唯一依據是「新方案相較於舊方案所產生的**差額現金流入與流出**」，任何與兩者選擇無關的歷史支出或既有共用開銷，皆必須被堅決排除。

---

## 🔬 增額現金流三階段數理架構

```
                       【設備重置增額現金流模型】
┌─────────────────────────────────────────────────────────────┐
│ 1. 期初淨資本流出 (t = 0)                                   │
│    新設備採購與安裝成本 (含運費/關稅)                      (-) │
│    減：出售舊設備之當期實際變現淨收入 (Net Salvage Value)    (+) │
│    加減：出售舊設備之處分資產損益稅務影響 (Tax on Sale)     (±) │
│    加減：伴隨新設備所需額外墊付之淨營運資金 (ΔNWC)          (-) │
├─────────────────────────────────────────────────────────────┤
│ 2. 營運期增額營業現金流 (t = 1 to n)                        │
│    ΔOCF = (營運成本節省額 ΔCost Savings) × (1 - t)          │
│           + (新舊折舊差額 ΔDepreciation) × t                │
├─────────────────────────────────────────────────────────────┤
│ 3. 期末殘值與營運資金回收 (t = n)                           │
│    新設備預期期末殘值 (稅後淨額)                            (+) │
│    減：舊設備若保留至期末原本可獲得之殘值 (稅後淨額)        (-) │
│    加：期初墊付之淨營運資金全額收回 (Recapture of ΔNWC)     (+) │
└─────────────────────────────────────────────────────────────┘
```

### 1. 期初出售舊設備之稅務處理 (Tax on Sale of Old Asset)
- **帳面價值 (Book Value, BV)**：舊設備原始成本 $-$ 累積折舊；
- **處分損益 (Gain/Loss on Sale)**：市場出售價格 (Market Price, MP) $-$ 帳面價值 (BV)；
- **稅務現金流效應**：
  - **若市價大於帳面價值 ($MP > BV$)**：產生處分資產利得，需繳納所得稅，產生**現金流出**：
    $$\text{Tax Liability} = (MP - BV) \times t \quad (-)$$
  - **若市價小於帳面價值 ($MP < BV$)**：產生處分資產損失，享有抵稅優惠，產生**現金流入**：
    $$\text{Tax Shield} = (BV - MP) \times t \quad (+)$$
  - 因此，舊設備出售的**稅後淨變現價值**為：
    $$\text{Net Cash from Salvage} = MP - (MP - BV) \times t$$

### 2. 折舊抵稅差額 (Depreciation Tax Shield)
新設備由於取得成本高或採用加速折舊法，通常在前期產生較高的折舊費用。折舊本身是非現金費用，但透過**折舊抵稅效應**實質節省企業現金流：

$$\Delta \text{Depreciation Tax Shield} = (\text{Dep}_{\text{new}} - \text{Dep}_{\text{old}}) \times t$$

## 📊 決策常見陷阱：沉沒成本 vs. 機會成本

在設備重置評估中，非財務背景經理人最容易混淆以下兩大成本屬性：

| 成本項目 | 項目經濟性質 | 決策處理準則 | 常見錯誤觀念 |
| :--- | :--- | :--- | :--- |
| **舊設備原始購置價格** | **沉沒成本 (Sunk Cost)** | **100% 忽略，完全無關！** | 「這台機器三年前花了 5,000 萬買的，現在賣掉只值 1,000 萬太虧了，不能換！」 |
| **舊設備當前帳面價值** | 會計歷史累積數 | 僅用於計算處分損益之稅務影響，帳面淨額本身非現金流。 | 誤以為帳面價值等於可收回的現金。 |
| **舊設備當前市場售價** | **機會成本 (Opportunity Cost)** | **計入期初現金流入 (+)**，若選擇保留舊機等於放棄變現。 | 忽略賣舊機所能即刻釋放的流動性資金。 |
| **新設備節省之人工電費** | 相關營運增額利得 | 稅後計入每期營業現金流入 (+)。 | 僅看節省毛額，忘記扣除所得稅的侵蝕。 |

## 🏢 企業實戰案例：晶圓代工廠極紫外光 (EUV) 機台汰換決策

### 1. 商業情境
某先進晶圓代工廠在評估是否以 ASML 頂級 High-NA EUV 機台，汰換現行已運轉 6 年的舊型 DUV 多重曝光機台。
- **舊機現狀**：原始成本 1 億美元，累積折舊 8,000 萬美元（帳面價值 2,000 萬美元）。若現在賣給二手市場，市價僅值 1,200 萬美元；每年維護與耗電成本高昂，且多重曝光導致良率損耗達 8%。
- **新機方案**：新購 High-NA EUV 需耗資 2.5 億美元，預計耐用 7 年。但單次曝光即可完成，每年預計節省電費、光阻劑與重工成本 4,500 萬美元，並顯著提升晶圓良率，新增年營收 3,000 萬美元。所得稅率為 20%，資本成本 WACC 為 10%。

### 2. 增額現金流核算與決策
1. **期初現金流 ($t = 0$)**：
   - 新機採購支出：$-\$25,000$ 萬美元；
   - 舊機變現：$+\$1,200$ 萬美元；
   - 舊機處分損失抵稅：$(2,000 - 1,200) \times 20\% = +\$160$ 萬美元；
   - 期初淨流出：$-25,000 + 1,200 + 160 = -\$23,640$ 萬美元。
2. **營運期增額現金流 ($t = 1 \sim 7$)**：
   - 經核算每年的稅後營業利益增額加上新舊機折舊抵稅差額，每年產生淨增額現金流高達 **+\$6,800 萬美元**。
3. **決策結果**：
   - 7 年折現後，增額淨現值 **$\Delta NPV = +\$9,460$ 萬美元，$\Delta IRR = 21.5\% > 10\%$**！
   - 董事會果斷批准重置，徹底擺脫了「舊機還能用就捨不得換」的短視思維，搶佔了下一代 AI 晶片代工霸權。

## ⚠️ 經理人常見盲點與治理陷阱

1. **「愛惜舊設備」的情感沉沒成本偏誤**：產線廠長對維護多年的舊機器充滿感情，以「設備性能依然良好」為由抗拒重置，完全忽視了新設備在能耗、良率與人力節省上的巨大差距。
2. **忽略「新舊設備生命週期不對稱」**：舊設備預期還能運轉 3 年，而新設備預期壽命長達 8 年。若未採用**等額年金法 ([[equivalent-annual-annuity_等額年金法]])**，直接粗暴比對兩者的 8 年總折現現金流，將嚴重扭曲評估結果。
3. **低估新機導入期的「學習曲線與停工成本」**：在規劃期初現金流時，僅計算了設備購買發票金額，未計入產線停工換線的營收損失、作業員培訓費用以及初期試產的報廢品成本。

## 🎯 高階經理人決策檢核清單

- [ ] 本專案的期初現金流計算中，是否已徹底剔除了舊設備的歷史採購成本（沉沒成本）？
- [ ] 舊設備若在當前出售，其市場變現淨額與處分損益的稅務影響是否經過會計師核算？
- [ ] 新設備帶來的「營運成本節省」與「產能良率提升」，是否皆已轉換為稅後增額現金流？
- [ ] 新舊設備的剩餘耐用年限是否一致？若不一致，是否已採用等額年金法 (EAA) 或重置鏈模型進行修正？
- [ ] 是否將新設備導入期間的安裝調試期、員工培訓與預期停工損失全額納入期初投資預算？
