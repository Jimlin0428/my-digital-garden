# 團體迷思 (Groupthink)

## 一、 核心概念與理論源流

### 1. 理論奠基：詹尼斯 (Irving Janis) 的政治與軍事決策研究
**團體迷思 (Groupthink)** 由耶魯大學心理學教授歐文·詹尼斯 (Irving L. Janis) 於 1972 年在其里程碑著作《團體迷思的受害者》（*Victims of Groupthink*）中正式提出。該概念源於他對美國歷史上重大災難性外交決策的深入剖析（如 1961 年古巴豬玀灣入侵慘敗、1941 年珍珠港遭偷襲時的毫無防備、韓戰中美軍跨越 38 度線導致慘重傷亡等）。

詹尼斯將團體迷思定義為：
> **當一群具備高度凝聚力、追求內部和諧的決策團隊，在面臨高度壓力與外部威脅時，其成員為了維持團體一致性與認同感，自發性地壓制批判性思考與反對意見，導致決策品質嚴重惡化、現實檢驗能力崩潰與道德判斷力失靈的集體心理病理現象。**

### 2. 團體迷思形成的四大前置條件 (Antecedents)
1. **高度團體凝聚力 (High Cohesiveness)**：團隊成員彼此熟悉、高度認同且珍惜夥伴情誼，將內部和諧置於真相之上。
2. **結構性組織隔離 (Structural Faults)**：高層決策小組與外界資訊、基層工程師及外部獨立專家長期處於物理或心理隔離狀態。
3. **指令型/專斷領導風格 (Directive Leadership)**：最高領導人在會議一開始即明確表態自己的偏好立場，使得下屬噤若寒蟬。
4. **外部高度壓力與時間緊迫 (High External Stress)**：面臨預算即將用罄、公開發布日期倒數、競爭對手逼近等高壓情境，團體成員喪失探索替代方案的耐心。

```
【團體迷思病理發展歷程】
高度凝聚力 ┐
組織隔離   ├──> 壓制異議、追求和諧 ──> 八大病徵爆發 ──> 忽視致命風險 ──> 災難性決策崩潰
專斷領導   │
高壓急迫   ┘
```

## 二、 決策架構與數理機制

### 1. 詹尼斯團體迷思八大病徵 (Eight Symptoms)

詹尼斯將團體迷思的表徵嚴謹劃分為三大類型、共八項具體症狀：

| 類型分類 | 病徵項目 | 核心心理與行為機制 | 商業會議中的典型表現 |
| :--- | :--- | :--- | :--- |
| **第一類：對團體的過度自負** | **1. 無懈可擊的幻覺 (Illusion of Invulnerability)** | 過度樂觀，堅信團隊過去的輝煌戰績能自動保證未來成功，敢於承擔毀滅性風險。 | 「我們是全球最頂尖的團隊，這項併購案絕不可能失敗。」 |
| | **2. 固有的道德信念 (Inherent Morality)** | 堅信自身團隊出發點崇高具備道德優越性，忽視決策對外部利益關係人的道德代價。 | 「為了顛覆老舊產業，打破一些法規框架是合情合理的。」 |
| **第二類：封閉的心智視角** | **3. 集體合理化 (Collective Rationalization)** | 成員合力建構一套說詞，集體打折或忽視外部所有的警訊與反對數據。 | 「那些監管機構的警告只是官僚形式主義，不用太當真。」 |
| | **4. 對外部群體的刻板偏見 (Stereotyping Out-groups)** | 將競爭對手、監管官員或質疑者貶低為「愚蠢、保守、怯懦或心胸狹隘」。 | 「傳統銀行根本不懂 FinTech，他們的反擊不足為懼。」 |
| **第三類：尋求一致性的高壓** | **5. 自我審查 (Self-Censorship)** | 成員心中雖有強烈疑慮，但因害怕破壞融洽氣氛或被孤立，選擇主動保持沉默。 | 會議中無人發言反對，私下在茶水間才互吐焦慮。 |
| | **6. 一致同意的幻覺 (Illusion of Unanimity)** | 由於眾人沉默不語，團隊錯誤地將「沉默」等同於「全體由衷贊同」。 | 主持人：「既然沒有人有意見，那我們就全票通過。」 |
| **第三類：尋求一致性的高壓** | **7. 對異議者的直接施壓 (Direct Pressure)** | 一旦有人提出質疑，立即遭到領導或同儕的質疑、嘲弄與忠誠度拷問。 | 「你現在提出這個技術疑慮，是在質疑大家的智商與心血嗎？」 |
| | **8. 自封心智衛士 (Self-Appointed Mindguards)** | 個別成員自發充當領導的護衛犬，主動攔截不利情報，防止領導受到負面雜訊干擾。 | 秘書長或幕僚主管將基層的刺耳測試報告扣押不上呈。 |

## 三、 企業真實實務個案

### 1. NASA 挑戰者號太空梭發射悲劇（Morton Thiokol 閉門會議）
1986 年 1 月 27 日，在挑戰者號發射前夕的電話會議中，固態火箭助推器製造商 Morton Thiokol 的工程師團隊明確指出：翌日清晨發射場溫度低達華氏 18 度，O-ring 橡膠密封環在低溫下將喪失彈性，極可能造成熱氣外洩引發爆炸（詳見 [[Carter_Racing_NASA_Challenger_卡特賽車與挑戰者號決策個案]]）：
- **直接施壓**：NASA 發射指揮官在電話中厲聲斥責：「我的上帝，Thiokol，你們難道要我們等到四月才發射嗎？」
- **管理層心智衛士反轉**：Thiokol 高級副總裁要求工程師離席，對總經理說出經典的管理黑話：「**摘下你的工程師帽子，戴上你的管理層帽子！**」
- **自我審查與一致性幻覺**：工程師最終被邊緣化，Thiokol 四位高管在沒有技術支持下進行表決，將原先的反對意見逆轉為「建議發射」。次日挑戰者號升空 73 秒後解體爆炸，7 名太空人罹難。

### 2. 瑞士航空 (Swissair)「飛行銀行」的集體盲從墜毀
曾被譽為「歐洲最安全、最富有的航空公司」瑞士航空，在 1990 年代末啟動名為「獵戶座 (Hunter Strategy)」的激進併購擴張策略：
- **同質化董事會**：瑞士航空的董事會全部由蘇黎世政商菁英組成，背景均為銀行家與政客，**沒有任何一位具備航空運輸產業運營經驗**。
- **無懈可擊的盲目**：高層沉醉於瑞士航空強大的信貸評級與歷史榮光，對併購諸如薩貝納航空 (Sabena) 等連年巨額虧損的劣質區域航司毫無疑慮。
- **異議抹殺**：少數提出流動性風險預警的財務人員被視為「不合群的失敗主義者」遭撤換。最終在 2001 年 911 事件後，瑞士航空現金流徹底斷裂，機隊在蘇黎世機場因付不起燃油費遭集體扣押停飛，這家擁有 70 年歷史的國家象徵宣告破產。

## 四、 經理人反思與行動檢核清單

```
                               對抗團體迷思的制度治理防線
┌─────────────────────────┬─────────────────────────┬─────────────────────────┐
│     1. 領導者後置發言   │     2. 旋轉魔鬼代言人   │     3. 二次機會覆決會   │
│ 領導隱藏立場，最後表態  │ 每場會議指派專人反方批判│ 拍板前給予 24 小時反思期│
└─────────────────────────┴─────────────────────────┴─────────────────────────┘
```

### Executive Decision Checklist
- [ ] **高管發言順序逆轉**：重大決策會議時，最高領導是否嚴格克制，讓最資淺、第一線的經理人優先發言，領導最後才發表意見？
- [ ] **制度化異議專員 (Devil's Advocate)**：是否在立案或併購小組中指派專門的「紅隊反方」，且在績效考核中評估其「提出具殺傷力批判論點的質量」？
- [ ] **二次機會會議 (Second-Chance Meeting)**：在達成初步全體共識後，是否強制推遲 24 至 48 小時召開二次會議，要求所有成員在冷靜後列出「我仍感到不安的潛在漏洞」？
- [ ] **獨立外部觀察員**：董事會或專案委員會是否定期邀請具備深厚產業專業、但無個人利益關聯的外部專家列席審查，打破封閉圈子？
- [ ] **無記名投票與盲投機制**：在涉及生死存亡的關鍵表決前，是否採用匿名電子問卷或無記名投票，徹底消除「公開舉手表決帶來的同儕道德勒索」？
