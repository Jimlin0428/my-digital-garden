# 履約價格 (Strike Price / Exercise Price)

## 一、 核心概念與理論源流

### 1. 理論奠基：選擇權權利義務的固定錨點
**履約價格 (Strike Price / Exercise Price)**，亦稱**執行價格**或**行權價**，是選擇權 (Options)、認股權證 (Warrants) 及員工股票選擇權 (ESOP) 等衍生性合約中最核心的合同約定參數。在 1973 年布萊克-斯科爾斯模型 (Black-Scholes-Merton Model) 奠定的現代衍生品定價架構中，履約價格是決定合約內在價值與現金流結構的基石。

其嚴謹定義為：
> **「選擇權買賣雙方在合約簽署時預先約定好的、選擇權買方（持有者）在未來特定期限內行使權利時，有權向賣方買入（買權 Call）或賣出（賣權 Put）標的資產的固定法定價格。」**

履約價格一經確定，在合約存續期間便固定不變（除遭遇股票分割、除權息等特殊公司行動需進行反稀釋調整外）。它如同一道橫亙在市場現價與未來期望之間的門檻，將標的資產的價格波動切割為非線性的非對稱損益空間。

```
【履約價格 (K) 對選擇權損益的非對稱切割】
  買權 (Call Option) 到期損益 = Max(S_T - K, 0) - 權利金 Premium
  賣權 (Put Option) 到期損益  = Max(K - S_T, 0) - 權利金 Premium
```

## 二、 決策架構與數理機制

### 1. 價位狀態 (Moneyness) 三重劃分體系
在任何交易時點，標的資產即期市價 ($S$) 與履約價格 ($K$) 的相對位置，定義了選擇權的**價位狀態 (Moneyness)**，直接決定了其內在價值與價格波動特徵：

| 價位狀態 | 買權 (Call Option, 享有買入權利) | 賣權 (Put Option, 享有賣出權利) | 內在價值與時間價值特徵 |
| :--- | :--- | :--- | :--- |
| **價內 (In-the-Money, ITM)** | **$S > K$**<br>(市價高於履約價) | **$S < K$**<br>(市價低於履約價) | 具備實質內在價值；對標的資產價格變動極度敏感 ($\Delta \to 1.0$)；[[option-premium_權利金|權利金]]最昂貴。 |
| **價平 (At-the-Money, ATM)** | **$S \approx K$**<br>(市價等於履約價) | **$S \approx K$**<br>(市價等於履約價) | 內在價值為零；**時間價值 (Time Value) 與 Gamma ($\Gamma$) 敏感度達到極致最高點**。 |
| **價外 (Out-of-the-Money, OTM)** | **$S < K$**<br>(市價低於履約價) | **$S > K$**<br>(市價高於履約價) | 內在價值為零；權利金完全由純時間價值構成；若到期仍處於價外，合約將如廢紙般歸零。 |

### 2. 選擇權權利金的價值分解方程式
選擇權在市場上的交易總價格（[[option-premium_權利金|權利金 Premium]]），在數學上嚴格拆解為兩大部分：

$$
\\text{Option Premium} = \\text{Intrinsic Value (內在價值)} + \\text{Time Value (時間價值 / 外在價值)}
$$

- **買權內在價值**：$\\max(S - K, 0)$
- **賣權內在價值**：$\\max(K - S, 0)$

### 3. 希臘字母敏感度：履約價格與 Delta ($\Delta$) 的映射
在布萊克-斯科爾斯偏微分方程式中，**Delta ($\Delta = \\frac{\\partial V}{\\partial S}$)** 衡量標的資產價格變動 1 元時，選擇權價格的聯動變動量：
- 深度價內買權（$K$ 遠低於 $S$）：$\Delta \\to 1.0$，行為特徵幾乎與直接持有現貨股票完全相同。
- 價平選擇權（$K \\approx S$）：$\Delta \\approx 0.5$。
- 深度價外買權（$K$ 遠高於 $S$）：$\Delta \\to 0$，類似低成本買彩券，具備極致的槓桿放大效應。

## 三、 企業真實實務個案

### 1. 矽谷世紀醜聞：高管股票選擇權「倒簽發行日 (Options Backdating)」
在 2000 年代中葉，包括蘋果、博通 (Broadcom)、UnitedHealth 在內超過 100 家矽谷科技巨頭遭到美國 SEC 與司法部的嚴密刑事調查：
- **作弊的履約價格**：高階主管獲得的員工股票選擇權 (ESOP) 原本應當以「授予當天的市場即期市價」作為履約價格 $K$（即價平期權 ATM）。
- **倒簽偷梁換柱**：高管與人力資源部門在幾個月後回溯審查過去一段時間的歷史股價走勢圖，刻意將選擇權的發行日期倒簽為「過去半年股價最低的那一天」，以此**人為設定一個極低的履約價格 $K$**。
- **後果**：等於向高管免費發送了巨額「深度價內」暴利，同時向公眾股東隱瞞了數億美元的真實薪酬費用支出。醜聞引發數十位知名科技 CEO 辭職、被起訴入獄，迫使 SEC 全面收緊 48 小時內申報規則。

### 2. 跨國企業利用「零成本項圈 (Zero-Cost Collar)」避險外匯與航油
大型航空公司（如漢莎航空、達美航空）或跨國出口企業（如台積電），廣泛運用**基於履約價格精妙配置的項圈避險結構**：
- **操作手法**：
  1. 買入一份價外賣權（設定較低的保護性履約價 $K_{\\text{put}}$，鎖定最差情況下的下行保底價格）；
  2. 同時賣出一份價外買權（設定較高的上限履約價 $K_{\\text{call}}$）。
- **零成本平衡**：透過精確精算兩個不同的履約價格，使賣出買權收取的權利金，完全抵消買入賣權所支付的權利金支出（淨權利金支出為零）。
- **成果**：企業在未花費一分錢保費的前提下，將未來營運現金流鎖定在 $[K_{\\text{put}}, K_{\\text{call}}]$ 的安全區間內，展現了履約價格在實體企業風險工程中的高級應用。

## 四、 經理人反思與行動檢核清單

```
                               履約價格設計與避險自檢模型
┌─────────────────────────┬─────────────────────────┬─────────────────────────┐
│     1. 激勵對齊真實增長 │     2. 避險保費與保護平衡│     3. 合規性透明防線   │
│ ESOP履約價絕不設為白送折價│ 依可承受損失選擇價位狀態│ 授予日市價必須具備第三戳記│
└─────────────────────────┴─────────────────────────┴─────────────────────────┘
```

### Executive Decision Checklist
- [ ] **高管激勵真實性審查**：向高階主管團隊發放的股權選擇權 (ESOP)，其履約價格是否嚴格鎖定在授予日的公允市價？是否有意圖透過超低履約價進行利益輸送的嫌疑？
- [ ] **防範「水下期權 (Underwater Options)」士氣瓦解**：當資本市場遭遇不可抗力大崩盤導致股價腰斬、既有期權深度價外 ($S \\ll K$) 喪失激勵功能時，公司是否有審慎的重新定價 (Repricing) 制度，防止核心技術骨幹大規模離職？
- [ ] **企業避險深度選擇 (Moneyness Selection)**：在採購原油或外匯選擇權避險時，我們是選擇昂貴的價內期權 (ITM)，還是選擇低保費但僅防禦極端災難的深價外期權 (Deep OTM)？
- [ ] **實質選擇權 ([[real-options_實質選擇權]]) 履約門檻**：在評估大型研發專案的二期投資擴張選擇權時，我們所設定的「啟動下一階段擴張的實質履約價格（資本支出 CapEx）」是否經過工程嚴謹測算？
- [ ] **法律合規安全戳記**：所有涉及董事與高管的股權授予契約，其履約價格的確認是否具備第三方證券交易所或轉讓代理機構不可篡改的時間戳記 (Timestamp)？
