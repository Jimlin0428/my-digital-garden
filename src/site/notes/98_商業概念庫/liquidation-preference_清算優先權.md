# 清算優先權 (Liquidation Preference)

## 一、 核心定義與意涵
- **清算優先權 (Liquidation Preference)** 是創投在認購特別股（Preferred Shares）時最核心的下行保護條款，規定在公司發生清算事件（包括破產倒閉、公司被收購出售、併購 M&A）時，特別股股東優先於普通股股東拿回資本的順序與比例。

## 二、 核心條款架構
1. **優先倍數 (Preference Multiple)**：通常為 $1	imes$ 原投資金額，高風險融資案可能達到 $1.5	imes \sim 2	imes$。
2. **受償類型**：
   - **非參與型特別股 (Non-Participating Preferred)**：投資人可在「拿回原投資倍數」與「轉換為普通股按股權比例分潤」之間擇一最佳利益（新創最健康標準）。
   - **完全參與型特別股 (Full Participating Preferred)**：投資人先拿回優先倍數金額後，剩餘資產再與普通股股東按比例共同分配（雙重得利 Double Dip）。
   - **附上限參與型特別股 (Capped Participating Preferred)**：參與分配直到總回報達到特定上限（如 $3	imes$）。
