# 雙鑽石模型 (Double Diamond Model)

> **導讀提示**：在商學管理與策略決策中，「雙鑽石模型」主要指向兩大享譽全球的經典理論框架，經理人需依據分析場景精準切換：
> 1. **國際策略與產業競爭視角**：魯格曼（Alan Rugman）與達克魯茲（Joseph D'Cruz）修正波特鑽石體系所提出的**「廣義雙鑽石模型（Generalized Double Diamond Model）」**；
> 2. **產品設計與創新思維視角**：英國設計委員會（British Design Council, 2005）提出的**「雙鑽石設計思考流程（Double Diamond Design Process）」**。

---

## 一、 策略與國家競爭力視角：廣義雙鑽石模型 (Generalized Double Diamond Model)

### 1.1 理論起源與對波特鑽石的修正
- **理論提出**：由國際商學權威魯格曼（Alan Rugman, 1993）、達克魯茲（Joseph D'Cruz）以及文輝（Hwy-Chang Moon, 1998）共同確立。
- **對麥可·波特（Michael E. Porter）的關鍵批判**：
  波特在《國家競爭優勢》（1990）中提出的經典鑽石體系（詳見 [[98_商業概念庫/Porter's Diamond Model_波特鑽石模型\|波特鑽石模型]]），其經驗實證高度立足於美國、日本、德國等**大型內需型經濟體**，假設企業的競爭優勢完全根植於「單一本土母國基地（Single Home Base）」。
- **小型開放經濟體（Small Open Economies）的現實困境**：
  對於加拿大、南韓、台灣、新加坡、瑞士等經濟體，本土內需市場狹小、自然資源或高階要素有限。若僅依賴本土鑽石，其產業根本無法支撐全球頂尖的規模經濟與前沿研發投資。

```text
【廣義雙鑽石模型 (Generalized Double Diamond Model) 架構】

           ┌─────────────────────────────┐           ┌─────────────────────────────┐
           │      本國鑽石 (Domestic)     │           │      國際鑽石 (International)│
           │                             │           │                             │
           │  • 本國生產要素 (在地人才)   │           │  • 全球高階要素 (矽谷/國際) │
           │  • 本國需求條件 (先行試驗)   │ ◄───────► │  • 全球廣大市場 (美歐/亞洲) │
           │  • 本國支援產業 (在地聚落)   │ (跨國嵌合)│  • 跨國外圍配套 (全球供應鏈) │
           │  • 本國同業競爭 (內部廝殺)   │           │  • 全球跨國巨頭競爭 (MNCs) │
           └──────────────┬──────────────┘           └──────────────┬──────────────┘
                          │                                         │
                          └────────────────────┬────────────────────┘
                                               ▼
                                 跨國企業全球化策略競爭優勢
                             (Global Competitive Advantage)
```

### 1.2 雙鑽石體系在台灣高科技產業的實證應用
- **本國鑽石（Domestic Diamond）**：
  台灣提供世界級半導體工程師、竹科密集供應鏈配套、24 小時極限良率管理文化與工研院政策催化。
- **國際鑽石（International Diamond）**：
  對接全球最嚴苛客戶（Apple、NVIDIA、高通的前導型算力需求）、引進全球頂尖設備與材料（荷蘭 ASML EUV 微影設備、日本信越化學矽晶圓）、參與全球資本市場融資與專利訴訟。
- **策略啟發**：小型經濟體的企業必須具備**「跨國邊界穿透力」**，將本國鑽石的製造執行力與國際鑽石的市場規模及技術標準深度嵌合。

## 二、 產品創新與設計思考視角：雙鑽石設計模型 (Double Diamond Design Process)

在台大 PMBA《[[_創業與企業財務策略 MOC|創業與企業財務策略]]》M1-4「創意思考工具與設計思考方法」模組中，雙鑽石模型則被廣泛應用於創新流程管理：

```text
【雙鑽石設計思考四階段模型 (British Design Council, 2005)】

          【第一顆鑽石：做對的事情】                      【第二顆鑽石：把事情做對】
             (Designing the Right Thing)                    (Designing Things Right)
      
          發散 (Diverge)    收斂 (Converge)          發散 (Diverge)    收斂 (Converge)
               ▲                  ▼                       ▲                  ▼
             ╱   ╲              ╱   ╲                   ╱   ╲              ╱   ╲
            ╱     ╲            ╱     ╲                 ╱     ╲            ╱     ╲
           ╱       ╲          ╱       ╲               ╱       ╲          ╱       ╲
          ╱ 1.探索  ╲        ╱ 2.定義  ╲             ╱ 3.開發  ╲        ╱ 4.交付  ╲
         ╱ (Discover)╲      ╱  (Define) ╲           ╱ (Develop) ╲      ╱ (Deliver) ╲
        ╱             ╲    ╱             ╲         ╱             ╲    ╱             ╲
       ▼               ▼  ▼               ▼       ▼               ▼  ▼               ▼
      問題本質探索 ────► 核心痛點鎖定 ────► 概念發想激盪 ────► 原型打樣與測試交付
     (User Research)      (Problem Framing)        (Ideation)          (MVP & Testing)
```

1. **第一階段：探索 (Discover) —— 發散思維**：
   - 走出辦公室進行田野調查、深度用戶訪談、同理心觀察（Empathy Map），廣泛收集使用者未被滿足的隱性痛點（Unmet Needs），不預設解決方案。
2. **第二階段：定義 (Define) —— 收斂思維**：
   - 聚類分析訪談數據，收斂出真正的核心問題陳述（Problem Statement / Point of View, POV），鎖定「如何才能...？（How Might We...?）」的關鍵命題。
3. **第三階段：開發 (Develop) —— 發散思維**：
   - 跨職能團隊腦力激盪（Brainstorming），跳脫框架發想多種可能的產品/服務概念、商業模式原型與使用體驗流程。
4. **第四階段：交付 (Deliver) —— 收斂思維**：
   - 製作最小可行性產品（MVP）、低保真原型（Low-Fi Prototype），進行快速迭代測試與買方反饋驗證，最終定案投入量產與上市推廣。

## 三、 兩大模型之經理人決策矩陣

| 比較構面 | 廣義雙鑽石模型 (Strategy & Trade) | 雙鑽石設計流程 (Design Thinking) |
| :--- | :--- | :--- |
| **提出者與年份** | Alan Rugman & Hwy-Chang Moon (1993/1998) | British Design Council (2005) |
| **主要學術領域** | 國際企業管理、國家與產業策略、地緣政治 | 產品設計、設計思考、精實創業、創新管理 |
