# 沉沒成本 (Sunk Cost & Decision Rationality Architecture)

> **【核心決策摘要】**
> **沉沒成本（Sunk Cost）** 是指**過去已經發生、且無法透過當前或未來的任何決策予以收回、變現或逆轉的歷史支出（Historical Expenditures）**。在理性經濟學與公司理財的[[98_商業概念庫/zeng-e-cash-flow_增額現金流量\|增額現金流量分析（Incremental Cash Flow Analysis）]]中，**沉沒成本在邊際決策中的相關性為零，應當在投資評估中被完全忽略（Bygones are bygones）**。然而，受限於人類心理的**損失規避（Loss Aversion）** 與證成效應，企業高管常陷入「**沉沒成本謬誤（Sunk Cost Fallacy / 協和號效應）**」，因為不願承認先前投資失敗而持續向虧損專案注入資源，導致嚴重的**承諾升級（Escalation of Commitment）** 與股東價值浩劫。

---

## 1. 概念核心定義與邊際分析準則 (Executive Definition & Marginal Principle)

### 1.1 核心定義
在資本預算與微觀經濟學中，沉沒成本定義為：**其發生與否已成既定事實，對任何備選未來行動方案均不產生邊際成本或邊際效益差異之沉沒資金**。

```
                    ┌─────────────────────────────────────────────────────────┐
                    │               理性決策 vs. 沉沒成本陷阱                │
                    └────────────────────────────┬────────────────────────────┘
                                                 ▼
        ┌────────────────────────────────────────────────────────────────────────┐
        │                              決策時間點 (T0)                           │
        │                                                                        │
        │   【過去：已投入 $1 億美元】                   【未來：預期追加與回報】        │
        │   • 過去支出無法改變 (Sunk Cost)               • 方案 A：追加 $5,000 萬, NPV = -$2,000 萬
        │   • 帳面虧損已實質發生                         • 方案 B：果斷止損, 轉向新專案 NPV = +$3,000 萬
        │                                                                        │
        │          ❌ 謬誤決策：因「已花費 1 億太可惜」而選擇追加 (擴大虧損)      │
        │          ✅ 理性決策：過去歸零，依據未來增額邊際效益決策 (止損轉向)    │
        └────────────────────────────────────────────────────────────────────────┘
```

### 1.2 理性投資決策黃金法則
在評估資本預算專案時，企業最高決策層必須嚴格遵守：
$$\text{Relevant Cash Flow} = \text{Future Cash Inflows} - \text{Future Incremental Costs}$$
$$\text{Sunk Cost} \equiv 0 \quad (\text{在增額評估中完全剔除})$$

- 專案是否繼續推進，**唯一取決於「從今天起追加的未來增額現金流折現值（NPV）」是否大於零**，與過去已投入 100 萬或 1 億美元毫無關聯。

## 2. 行為經濟學機理：沉沒成本謬誤為何難以克服？ (Behavioral Foundations)

依據康納曼與特沃斯基（Daniel Kahneman & Amos Tversky）的**前景理論（Prospect Theory）**，沉沒成本謬誤具有深層的心理學根源：

```
價值感受 V(x)
      ▲                     / 收益區間 (風險規避: 凹函數)
      │                    /
      │                   /
──────┼──────────────────/────────────────▶ 客觀損益 (x)
      │                /
      │               /
      │              /
      │             /   損失區間 (損失規避 & 風險偏好: 凸函數)
      │            /    S 型曲線在損失側更為陡峭 (Pain of loss is 2x~2.5x)
      ▼
```

1. **損失規避（Loss Aversion）**：
   損失 100 萬元的心理痛苦程度，約為獲得 100 萬元心理快樂程度的 2 至 2.5 倍。承認專案失敗意味著「將帳面潛在損失實質化為確定損失」，經理人寧願冒著虧損進一步擴大的風險進行賭博（Gambling on Resurrection）。
2. **自我證成與代理問題（Self-Justification & Agency Conflicts）**：
   專案發起人往往將專案成敗與個人聲譽、職涯升遷及在董事會中的話語權深度綁定。承認停止專案會向外界釋放「當初決策失誤」的信號，因此經理人存在強烈的代理人動機繼續向黑洞專案灌注公司資金。
3. **沉沒成本與承諾升級（Escalation of Commitment）**：
   心理學家斯塔夫（Barry Staw）研究指出，決策者在接收到專案受挫的負面反饋時，不但不退縮，反而會主動加碼投入更多資源，試圖力挽狂瀾以證明最初決策的正當性。

## 3. 經典商業案例：協和號客機與科技專案止損 (Benchmark Case Studies)

### 3.1 協和號超音速客機（Concorde Project）—— 國家級沉沒成本悲劇
- **歷史背景**：1960 年代，英法兩國政府簽署聯合條約，共同研發超音速客機「協和號（Concorde）」。
- **決策迷航**：專案開發過程中，研發費用因技術瓶頸與燃油危機急遽飆升，商業運營評估早已明確顯示：因耗油量過大、載客量有限且噪音無法飛越陸地，該機型在經濟上絕無盈利可能。
- **持續加碼**：但兩國政府因「已經投入過多國家預算與民族自尊心，現在放棄等於前功盡棄」，硬是持續注資長達數十年。
- **最終結局**：協和號自 1976 年投入營運至 2003 年退役，累計造成超過數十億英鎊的巨額虧損。「協和號效應（Concorde Fallacy）」遂成為全球管理學中沉沒成本謬誤的代名詞。

### 3.2 典範：Intel 放棄 DRAM 轉型微處理器 (Grove & Moore)
- **生死抉擇**：1985 年，日本半導體廠商在記憶體（DRAM）領域以規模經濟與良率發動毀滅性價格戰，Intel 在記憶體領域投入了全部心血與數億美元設備，陷入瀕臨破產的巨額虧損。
- **擺脫沉沒成本的經典對話**：
  時任執行長安迪·葛洛夫（Andy Grove）問董事長高登·摩爾（Gordon Moore）：
  > 「如果董事會把我們開除，換一個全新的執行長進來，你認為他會怎麼做？」
  摩爾毫不猶豫回答：「他會徹底放棄記憶體業務。」
  葛洛夫隨即說：「那我們為什麼不自己走出旋轉門，換成那個新執行長親手做了這件事？」
- **成果**：Intel 斷然關閉投入無數資金的 DRAM 產線，轉向微處理器（CPU），開創了雄霸全球三十年的 Wintel 帝國。

## 4. 經理人克服沉沒成本的五大治理防線 (Governance Framework)

```
─────────────────────────────────────────────────────────────────────────────
[防線 1：決策權與評估權分離 (Independent Gatekeepers)]
  • 導入獨立的投資審查委員會或第三方稽核團隊，禁止專案負責人自行主持「繼續或終止」評估。

[防線 2：里程碑對賭與硬性止損線 (Kill Gates & Stage-Gate Process)]
  • 在專案啟動時預先設立量化 KPI 門檻（如營收、DAU、良率），未達門檻則自動觸發停損退場機制。

[防線 3：獎勵負責任的失敗 (Reward Smart Failure)]
  • 建立鼓勵提早認賠的企業文化，對主動終止無效專案、為公司節省未來資金的團隊給予實質激勵。

[防線 4：定期情境重設思考 (The Grove Outside-in Test)]
  • 定期要求高階團隊進行心智實驗：「若我們今天未持有此資產，我們是否願意用同等現金將其買下？」

[防線 5：增額現金流審查專用表格 (Incremental CF Auditing)]
  • 在財務呈報中嚴禁將歷史研發費、已購廠房成本列入未來投資回報率計算公式之分母。
─────────────────────────────────────────────────────────────────────────────
```
