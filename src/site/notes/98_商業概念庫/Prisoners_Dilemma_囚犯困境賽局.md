# 囚犯困境賽局 (Prisoner's Dilemma)

## 一、 核心定義與本質
- **囚犯困境（Prisoner's Dilemma）**是賽局理論中最著名的非零和博弈模型。
- **本質與矛盾**：
  揭示了**「個別理性的最佳選擇，往往導致集體非理性的雙輸結局」**。在無法達成具法律約束力的合約前提下，參與者出於對自身利益的極大化考量（或對對手背叛的恐懼），各自選擇「背叛（降價）」，最終落入次佳的納許均衡。

---

## 二、 產業價格戰報酬矩陣

```text
【雙寡占降價決策矩陣 (廠商 A, 廠商 B)】

                     廠商 B
               維持高價 (合作)      降價求售 (背叛)
      ┌──────────────┬──────────────┐
維持  │              │              │
高價  │   (-1, -1)   │   (-5,  0)   │
(合作)│              │              │
廠商  ├──────────────┼──────────────┤
 A    │              │              │
降價  │   ( 0, -5)   │  ★ (-3, -3)  │  <── 納許均衡 (Nash Equilibrium)
求售  │              │              │      (雙方降價，利潤皆受損)
(背叛)└──────────────┴──────────────┘
```

1. **優勢策略（Dominant Strategy）**：
   - 無論廠商 B 降價與否，廠商 A 選擇降價的報酬皆優於不降價；
   - 雙方皆具備降價誘因，納許均衡鎖定於 $(-3, -3)$；
2. **困境所在**：
   - 雙方合計最佳解為 $(-1, -1)$（共同維持高價），但該狀態極其脆弱，任何一方皆有單方面降價偷襲以擴大市佔的衝動。

---

## 三、 跳脫囚犯困境的實戰解方
1. **重複賽局（Repeated Games）**：
   - 當市場參與者長期多次互動時，引入「以牙還牙（Tit-for-Tat）」策略——初期釋放合作善意，一旦對手降價立即跟進報復，迫使對手維持長期合作默契；
2. **價格跟進保證合約（Price-Matching Guarantees）**：
   - 公開承諾「買貴退差價」，使對手明白其降價無法奪取任何額外顧客，徹底消除降價誘因；
3. **提高資訊透明度與產業公會協調**：
   - 消除資訊不對稱與恐慌性猜忌。
