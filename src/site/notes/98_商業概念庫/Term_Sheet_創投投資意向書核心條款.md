# 創投投資意向書核心條款 (Term Sheet Key Provisions)

## 一、 核心定義與本質
- **投資意向書（Term Sheet）**是創投（VC）對新創完成初步盡職調查後，向創辦團隊出具記載主要投資條件之非約束性（Non-binding）架構文件（除保密與獨家排他期具約束力外）。
- **本質與防禦哲學**：
  Term Sheet 是投資人與創辦人之間關於**「錢（經濟利益 Economics）」**與**「權（公司控制權 Control）」**的契約博弈平衡點。

---

## 二、 兩大核心支柱與關鍵條款拆解

| 條款類別 | 關鍵條款名稱 | 核心條款機制與防禦重點 |
| :--- | :--- | :--- |
| **經濟性條款<br>(Economics)** | **優先清算權<br>(Liquidation Preference)** | 清算或併購時，VC 特別股有權優先於普通股收回 $1\times$ 本金；區分完全參加（Participating）與不參加（Non-participating）。 |
| | **反稀釋條款<br>(Anti-Dilution)** | 防範後續 Down Round 稀釋早期投資人；國際慣例採用「加權平均法（Weighted Average）」，極端情況採用「完全棘輪法（Full Ratchet）」。 |
| | **優先認股權<br>(Preemptive Rights)** | 後續輪次增資時，原股東有權按比例優先認購以維持持股比率。 |
| **控制性條款<br>(Control)** | **董事會席次與否決權<br>(Board & Protective Provisions)** | VC 要求取得 1~2 席董事席次；對重大資產處分、增資發債、高階人事任免擁有一票否決權。 |
| | **關鍵人條款<br>(Key Person Clause)** | 綁定核心創辦團隊（如 CTO）。若關鍵人物離職，VC 有權凍結撥款或要求贖回特別股。 |
| | **領售權 (Drag-Along)<br>與隨售權 (Tag-Along)** | 多數創投同意出售公司時可強拉創辦人一併賣股（領售權）；創辦人賣老股時 VC 有權等比例搭車出脫（隨售權）。 |

---

## 三、 實戰談判原則
創辦人在審查 Term Sheet 時，**切忌僅盯著「估值高低」，而輕易出讓「完全參加分配權」或「過度嚴苛的否決權」**；優質的 Term Sheet 應建立在平等互惠與利益對齊之上，避免在後續輪次中喪失實質營運控制權。
