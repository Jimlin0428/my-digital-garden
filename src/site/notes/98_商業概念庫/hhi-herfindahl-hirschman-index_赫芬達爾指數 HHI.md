# 赫芬達爾指數 HHI (Herfindahl-Hirschman Index)

## 📌 概念定義
**赫芬達爾-赫希曼指數**（HHI）是國際通用衡量「[[98_商業概念庫/industry-concentration_產業集中度\|industry-concentration_產業集中度]]」與市場壟斷程度之量化指標。與僅統計前四大企業之 CR4 不同，HHI 將市場上所有企業的市佔率均納入計算並取平方加總，更能反映產業中龍頭企業的優勢差距。

---

## 🧮 計算公式

$$HHI = \sum_{i=1}^{n} s_i^2 = s_1^2 + s_2^2 + \dots + s_n^2$$

* $s_i$：第 $i$ 家企業的市場佔有率百分比（如 30% 記為 30）。
* **最高值**：$10,000$（完全壟斷，單一企業市佔 100%）。

---

## 📊 國際反托拉斯與市場結構判定標準 (US DOJ / FTC)

| HHI 數值範圍 | 市場結構分類 | 競爭強度 |
| :--- | :--- | :--- |
| **$HHI < 1,500$** | 低度集中（Unconcentrated） | 高度競爭 |
| **$1,500 \le HHI \le 2,500$** | 中度集中（Moderately Concentrated） | 寡占競爭 |
| **$HHI > 2,500$** | 高度集中（Highly Concentrated） | 強力寡占 / 壟斷風險 |
