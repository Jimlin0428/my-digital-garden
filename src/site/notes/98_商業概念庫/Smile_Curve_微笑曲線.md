# 微笑曲線 (Smile Curve)

## 一、 核心定義與本質
- **微笑曲線（Smile Curve）** 由宏碁集團創辦人施振榮先生於 1992 年提出，用以直觀描述個人電腦與資通訊產業垂直分工鏈條中，各環節附加價值（Value-Added）與獲利率的非對稱分佈形態。
- **商管本質**：揭示了產業價值體系中利潤池向兩端聚集的客觀規律，指引製造代工企業向研發專利或品牌通路進行價值躍升。

## 二、 核心理論架構與形態演變
```
附加價值 / 毛利率
      ▲
  高  │   【研發設計端】                               【品牌通路端】
      │   • 關鍵智慧財產 (IP)                         • 全球品牌資產
      │   • 晶片與軟體演算法                           • 終端渠道與服務
      │        ╲                                           ╱
      │         ╲                                         ╱
      │          ╲         【製造組裝中段】              ╱
  低  │           ╰─────────────────────────────────────╯
      │                     • OEM / EMS 組裝
      │                     • 資本密集、毛三到四
      └─────────────────────────────────────────────────────────► 產業價值鏈環節
            上游 (Upstream)        中游 (Midstream)        下游 (Downstream)
```

1. **傳統微笑曲線三大區段**：
   - **左端（研發與智財）**：享有極高專利壁壘與定價主導權，附加價值極高。
   - **中段（加工製造組裝）**：標準化設備、產能容易過剩，削價競爭劇烈，附加價值最低。
   - **右端（品牌行銷與服務）**：掌握顧客心智與終端通路，享有高顧客轉換成本與品牌溢價。
2. **打破微笑曲線的歷史實證**：
   - **台積電晶圓代工模式**：台積電以極致製程良率與專利護城河，將製造端推向技術寡占，毛利率達近 60%~66%，反而超越兩端多數晶片設計與終端硬體品牌廠，重塑產業利潤池。

## 三、 產業意涵與升級路徑
- 傳統代工廠擺脫微笑曲線谷底的三大途徑：
  1. 向左躍升：跨足核心關鍵零組件與專利技術（如緯創切入 GPU 運算板）；
  2. 向右延伸：自建通路品牌與直接服務客戶（D2C）；
  3. 谷底做深：追求極限規模經濟與不可替代之良率寡占（如台積電、鴻海系統整合）。
