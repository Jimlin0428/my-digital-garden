# 認知偏差 (Cognitive Bias)

> **核心名言**：「我們的大腦是為了生存而演化，不是為了客觀的統計學機率。」  
> —— 丹尼爾·康納曼（Daniel Kahneman, 《快思慢想》）

---

## 一、 核心定義與心理機制

- **認知偏差（Cognitive Bias）**，又稱**認知偏誤**，指人類在處理資訊與進行判斷決策時，因大腦資源有限、時間緊迫或情緒干擾，本能地採用**「捷思法（Heuristics, 心理捷徑）」**，從而導致偏離客觀理性與機率法則的系統性模式化錯誤。
- **雙系統思維架構（Dual-Process Theory）**：
  - **系統一（快思，System 1）**：自動化、無意識、快速反應、耗能極低，依賴直覺與情緒，是認知偏誤的主要溫床。
  - **系統二（慢想，System 2）**：深思熟慮、受意識控制、邏輯運算、高度耗能，負責批判性檢驗與理性校正。

## 二、 商業與高階決策常見之十大認知偏誤

| 偏誤名稱 | 心理機制表現 | 商業決策案例與負面衝擊 |
| :--- | :--- | :--- |
| **[[98_商業概念庫/confirmation-bias_確認偏誤\|confirmation-bias_確認偏誤]]** | 僅關注與自身信念相符的資訊，忽視或貶低矛盾證據 | 經理人愛上自己的新專案，忽視市場訪談中顧客的不滿警訊 |
| **過度自信偏誤 (Overconfidence)** | 主觀評估之信心顯著高於客觀準確度，低估不確定性 | 樂觀估計產品上市交期與營收預測，低估 CapEx 預算超支 |
| **錨定效應 (Anchoring Effect)** | 過度依賴接收到的第一筆資訊（錨點）作為後續判斷基準 | 併購談判時被賣方最初提出的溢價開價所錨定，拉高交易成本 |
| **沉沒成本謬誤 ([[98_商業概念庫/sunk-cost_沉沒成本\|sunk-cost_沉沒成本]])** | 因過去已投入不可回收之時間金錢，持續追加資源於虧損專案 | 軟體系統或製造工廠已虧損數億，高層仍不願果斷停損認賠 |
| **可得性捷思 (Availability Heuristic)** | 依據記憶中最容易被喚起的生動或近期事件評估發生機率 | 最近發生一起供應鏈斷鏈事故，主管便過度囤積冷門零組件庫存 |
| **框架效應 (Framing Effect)** | 面對相同實質問題，因描述方式（獲利 vs. 損失）產生相反偏好 | 「90% 成功率」讓人願意冒險，而「10% 失敗率」引發規避 |
| **[[98_商業概念庫/self-serving-bias_自利偏誤\|self-serving-bias_自利偏誤]]** | 將成功歸因於內部能力，將失敗歸咎於外部環境與運氣 | 業績好自稱策略精準，業績崩盤怪罪大環境通膨或競爭對手削價 |
| **現狀偏誤 (Status Quo Bias)** | 傾向維持現狀不作為，將任何變革潛在代價放大評估 | 面對破壞式創新威脅時，既有巨頭抱守傳統商業模式遲遲不轉型 |
| **團體迷思 (Groupthink)** | 群體追求表面和諧與共識，壓制不同意見與批判性聲音 | 高管會議中無人敢反對執行長決策，導致災難性併購或投資 |
| **倖存者偏差 (Survivorship Bias)** | 僅檢視成功個案特質，忽略了採取相同行為卻失敗的大多數 | 盲目模仿蘋果、特斯拉等極端特例，誤將特例當成普適管理真理 |

## 三、 經理人除偏（Debiasing）決策工具箱

1. **紅隊演練與魔鬼代言人（Devil's Advocate）**：
   - 在重大投資會議中，正式指定特定高階主管或專案小組專職尋找該決策的「致命破綻」與反面論據。
2. **事前驗屍法（Pre-mortem Analysis）**：
   - 在專案啟動前假定：「現在是五年後，這個專案已經徹底失敗並造成公司巨額虧損，請列出導致失敗的所有可能原因。」
3. **基準機率對齊（Reference Class Forecasting）**：
   - 擺脫「內部視角（Inside View）」，主動蒐集同產業類似專案在歷史上的平均交付時間、真實預算超支率與成功機率作為外部基準。
