# 確認偏誤 (Confirmation Bias)

## 一、 核心概念與理論源流

### 1. 理論奠基：華生 2-4-6 規則發現實驗
**確認偏誤 (Confirmation Bias)** 由英國認知心理學家彼得·沃森 (Peter Cathcart Wason) 於 1960 年透過其著名的「2-4-6 任務」實驗首次嚴謹驗證。沃森給受試者一組數字「2, 4, 6」，並告知該數列符合某個特定的數學規則，要求受試者透過提出新的三個數字組合來測試並猜出背後規則。

實驗結果顯示：
- 絕大多數受試者預設規則為「連續偶數」或「每次加 2」，隨後提出的測試均為「4, 6, 8」或「10, 12, 14」等**支持其初始假設**的數列。
- 受試者幾乎從不主動提出反例數列（如「1, 3, 5」或「2, 4, 7」或「5, 3, 1」）來嘗試證偽自身假說。
- 事實上，沃森設定的底層真實規則僅為極其寬鬆的「三個遞增數字」。受試者因深陷確認偏誤，在自己建構的認知牢籠中反覆驗證假說，導致嚴重誤判。

### 2. 經理人的三重確認過濾漏斗
在企業高階策略與投資評估中，確認偏誤通常透過三道心理防線層層加固，形成自我強化的同溫層：
1. **選擇性搜尋 (Selective Search)**：只閱讀支持自身戰略直覺的產業報告，搜尋對既定專案有利的市調數據。
2. **選擇性詮釋 (Selective Interpretation)**：將模稜兩可、具有高度雜訊的市場訊號，全部自動解讀為對自身有利的「利多消息」。
3. **選擇性記憶 (Selective Recall)**：選擇性記住過去支持自身決策成功的歷史案例，而自動遺忘或合理化反面警訊。

```
【確認偏誤心智過濾漏斗】
全域客觀市場訊號 (客觀利多 + 客觀利空)
                  │
                  ▼
┌──────────────────────────────────────────────┐
│  1. 選擇性搜尋：主動規避刺耳雜音             │
│  2. 選擇性詮釋：將模糊中性數據解讀為利多     │
│  3. 選擇性記憶：淡化反面案例，強化成功幻覺   │
└──────────────────────┬───────────────────────┘
                       ▼
         鞏固原有偏見，形成組織盲區
```

## 二、 決策架構與數理機制

### 1. 貝氏推論失真模型 (Bayesian Distortion)
理性決策者在面對新證據 $E$ 時，應依據**貝氏定理 (Bayes' Theorem)** 更新對假說 $H$（如「新產品將熱銷」）的後驗機率 $P(H|E)$：

$$
P(H|E) = \frac{P(E|H) \cdot P(H)}{P(E|H)P(H) + P(E|\neg H)P(\neg H)}
$$

但在確認偏誤的心理機制下，決策者對證據的似然比 (Likelihood Ratio) 產生人為扭曲：
- 當出現支持性證據 $E^+$ 時，決策者過度放大其主觀權重：$P(E^+|H) \gg P_{\text{true}}(E^+|H)$。
- 當出現反面證偽證據 $E^-$ 時，決策者透過合理化或歸咎於偶然雜訊，將其權重趨近於零：$P(E^-|\neg H) \approx 0$。
- 結果導致後驗機率 $P(H|E)$ 無法隨外部客觀資訊收斂至真實分佈，形成極端過度自信（Overconfidence）。

### 2. 確認偏誤在企業決策各階段的典型表徵

| 決策階段 | 典型確認偏誤行為 | 典型藉口與管理話術 | 制度性解方 |
| :--- | :--- | :--- | :--- |
| **商機辨識** | 只訪談熱愛產品的早期狂熱者，忽視流失用戶 | 「那些流失的客戶本來就不是我們的目標受眾」 | 強制訪談 50% 以上流失客戶與退貨用戶 |
| **併購盡職調查** | 聘用投資銀行時，要求投行證明收購價值，而非尋找交易破綻 | 「這項併購具備巨大的戰略綜效，短期虧損不重要」 | 指派獨立審查組執行「[[Carter_Racing_NASA_Challenger_卡特賽車與挑戰者號決策個案|魔鬼代言人 (Devil's Advocate)]]」審查 |
| **產品研發投入** | 產品測試出現嚴重 Bug 時，歸咎於測試環境異常 | 「正式上線後使用者不會這樣操作」 | 建立客觀自動化質量紅線，未過門檻禁止發布 |
| **重大虧損停損** | 持續注資已瀕臨失敗的專案，深陷[[sunk-cost_沉沒成本|沉沒成本]] | 「只要再熬過這一季，市場就會迎來拐點」 | 設立獨立於專案團隊之外的「第三方清算停損委員會」 |

## 三、 企業真實實務個案

### 1. 百視達 (Blockbuster) 對串流訂閱模式的選擇性失明
2000 年，Netflix 創辦人哈斯廷斯 (Reed Hastings) 曾提議以 5,000 萬美元將 Netflix 賣給百視達，並由 Netflix 負責運營百視達的線上品牌，遭百視達執行長約翰·安蒂奧科 (John Antioco) 嗤之以鼻：
- **確認偏誤的篩選**：百視達管理層依賴高額的「逾期罰款 (Late Fees)」（佔其總營收 16% 以上）。高層只關注門市排隊人潮的數據，將其解讀為「實體門市的家庭社交儀式感不可取代」。
- **忽視反面證據**：當寬頻網路普及與 DVD 郵寄用戶暴增時，百視達高層將其貶低為「小眾利基市場」。
- **結果**：百視達在確認偏誤引發的舒適圈中錯失黃金轉型期，最終於 2010 年申請破產清算，而 Netflix 市值則突破數千億美元。

### 2. 施樂 (Xerox PARC) 對個人電腦圖形介面的致命忽視
1970 年代，施樂帕羅奧多研究中心 (Xerox PARC) 發明了現代個人電腦的核心雛形：圖形使用者介面 (GUI)、滑鼠、乙太網路與物件導向程式設計：
- **複印機帝國的心智偏見**：施樂紐約總部的管理層是銷售大型影印機出身，其心智模式堅定認為「施樂的核心是印表與複印，電腦只是昂貴的研究玩具」。
- **偏誤驗證**：高層調閱了早期微型電腦 Alto 昂貴的製造成本報告，確認了其「不可能在大規模商業市場盈利」的偏見，對 GUI 的顛覆性價值視而不見。
- **後續影響**：1979 年，賈伯斯參訪 PARC 後大受震撼，將 GUI 技術吸納並開發出 Apple Macintosh，開啟了 PC 革命，而施樂則永遠錯失了成為全球軟硬體霸主的歷史機會。

### Executive Decision Checklist
- [ ] **證偽提問 (Falsification Question)**：在重大併購或新品立案審查時，我們是否曾明確提出：「**需要出現什麼具體數據，我們才會立即叫停這項專案？**」
- [ ] **魔鬼代言人制度 (Devil's Advocacy)**：會議中是否指派專人擔任反方，給予其免責權，全力搜集反對該決策的致命事實與論據？
- [ ] **事前驗屍法 (Pre-Mortem Analysis)**：是否在專案拍板前召開全體會議，假設「專案兩年後徹底崩潰並損失億元」，請每位成員寫下導致該崩潰的可能原因？
- [ ] **紅隊審查 (Red Teaming)**：重大商業模型是否經過獨立紅隊審計，確認預測模型沒有刻意隱匿不利變數或過度樂觀假設？
- [ ] **流失用戶深度訪談**：產品委員會是否每月固定抽查並親自聆聽流失客戶、客訴個案與退費者的原始錄音，而非僅閱讀公關美化後的滿意度報告？
